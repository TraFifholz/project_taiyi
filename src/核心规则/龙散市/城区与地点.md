# 城区与地点

龙散市下辖多个城区，各区域在安防等级、产业分布和通行权限上差异显著。以下整理已知城区的核心特征，以及已进入行动范围的地标与场所。

## 故城区与旧城区

**故城区**和**旧城区**是两个独立区域，市民语境中常被混淆。

故城区为龙散的老城区行政与生活空间，保留普通街区、老街、社区和传统商业活动。本地人脉与灰色交易深植于此。

旧城区在三年前的大塌陷后被划为市政改造区域，由旧城区管委会直管。周边设有隔离墙、施工区和玄盾国际安保力量，无许可通行视为非法入侵。

在实际对话中，若有人提到"去旧城"，需确认对方指的是故城区的老街方向，还是旧城区管委会辖下的隔离区——前者通向老城区的生活网络，后者通向隔离墙、武装安保和可能无法原路返回的区域。

## 已知城区

| 区域 | 概况 |
|---|---|
| 深中新区 | 绿区核心。企业总部、金融中心和高端办公空间密集。通行秩序严格，权限识别与安检强度最高。 |
| 文星区 | 龙散大学所在区域。学生、研究机构和校园生活集中。凯芙拉的大学线由此展开。 |
| 楚岸区 | 老租界与金融传媒区域。引资银行等机构与本地有紧密业务关联。 |
| 故城区 | 老街、黄区生活、旧社区与本地人脉。白茅岗麻将房等地点位于此区域。 |
| 铁山区 | 旧工业带，重黎工业遗迹与义体/机械相关场所密集。楚钢遗址及铁铺线索均与这一带相邻或关联。 |
| 望津区 / 马东码头一带 | 港口、集装箱、物流咨询和重型运输车辆集中。常伴雾气和僻远库区，货物流向难以追踪。 |
| 北岭区 | 新兴居住与娱乐文化区域。长乐街、义体节活动与宅文化消费在此方向。 |
| 旧城灰区 | 大塌陷后的隔离区域，旧城重建与玄盾安保的核心压力区。未经许可进入，风险不可控。 |

## 已出现地点

### 龙散东站

龙散市主要高铁枢纽。外地人进入龙散的第一站——秩序井然、接驳高效、新闻屏与安防提示无处不在。

### 威格广场与长乐街

威格广场为黄区流行文化、娱乐电子与二次元消费地标。长乐街一带曾作为重黎/义体节的活动地点，CPI 等级影响参展与入场权限。

### 重黎工业展台

重黎工业在义体节上展示了新一代义眼、接口及相关义体技术。阿尔坎曾以体验者身份参与展示，凯芙拉借此与他建立了首次接触。

### 楚钢集团遗址

楚钢相关区域处于玄盾国际和重建工程的高压管控之下。阿尔坎受云梦科技运维委托，在此处理过监控与传感节点的异常，发现了离线运行记录和异常光流。

### 月下诊所

何夜白主理的黑市/灰色医疗技术节点。业务涉及神经接口校准、非法与半合法义体维护。与阿尔坎、雷武龙和唐索的行动线均有交集。

### 白茅岗麻将房

黄区灰色场所的典型——以麻将房为外壳，实际充当消息集散和委托中转节点。黑崎欲子与唐索曾在此与接头人周凛会面。

### 马东附近码头区

望津方向港口地带，遍布集装箱、重型运输车辆和偏远的正规港口空间。凯芙拉接触过的港口质检、阿尔坎收到的坐标、李好涉及的取车线索、雷武龙的送货线均在这一带交汇。

### 龙门调度

雷武龙接收任务的目的地之一。公开信息极少，仅确认其与铁铺取货和码头方向存在关联。

### 铁铺 / 铁匠铺

铁山区取货地点，与旧工业设备、街面委托和码头方向的运输线存在联系。目前无法判断其仅为普通物流节点，还是作为某条更深层网络的前端运行。
