# 组织

龙散市的组织跨界运作是常态：企业承接城市公共服务，公共系统嵌入商业接口，灰色网络借助平台、诊所、物流和街面关系维持运转。

## 城市系统与公共基础

| 名称 | 概况 |
|---|---|
| TAIYI | 龙散市城市 AI 管理系统，调度交通、安防、能源、公共服务与数据接口。 |
| 天穹智能钱包 | 支付、身份、权限与安全信息评级的统一工具。云梦科技运营，引资银行提供金融底层。 |
| 龙腾轨道交通 | 龙散市地铁及城市轨道交通运营方。连接绿区、黄区、大学区、旧工业带与港口方向。 |

## 企业与机构

| 名称 | 概况 |
|---|---|
| 云梦科技 | TAIYI 与城市数据服务的主要技术企业。负责运维、节点管理与城市智能化接口。 |
| 引资银行 | 金融机构，天穹钱包的金融底层之一。龙散分行采用工单池与平台化业务结构。 |
| 玄盾国际 | 私人军事承包商。负责旧城、楚钢周边及高风险区域安保。巡逻人员与电子犬常见于警戒区边缘。 |
| 重黎工业 | 工业、载具与义体企业。义体节展出新一代义眼、接口及义体技术。 |
| 九渊建设 | 旧城重建、地下工程与大型施工企业。旧城重建新闻中频繁出现。 |
| 追风出行 | 网约车与出行平台。同一辆网约车可能在不同订单中先后搭载平台用户、街面委托人和灰色运输需求。 |

## 灰色网络与场所

| 名称 | 概况 |
|---|---|
| 随缘事务所 | 沈漫关联的小型事务所。公开口径为"各类委托均可受理，响应周期不定"。 |
| 月下诊所 | 神经接口、义体维护与灰色医疗技术节点。承接非法与半合法义体服务。 |
| 港口物流咨询 | 望津区/马东码头方向的港口业务入口，涉及货运与质检。 |
| 棍木会 | 在暗网与加密线索中出现过的组织名，性质与规模未公开。 |
| 信净会 / 孤儿帮助会 | 以公益与收养名义出现的线索。具备港资背景与儿童救助外壳，公开信息有限。 |
