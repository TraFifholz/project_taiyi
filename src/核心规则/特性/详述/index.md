角色因其“特性”而得以成型，属性和技能根据骰子类型划分高低，d6属于平均水平，在此之上的骰子类型则代表能力更为优秀。

属性主要是用于抵抗诸如恐惧或超自然攻击这类效果的被动或内生能力，技能用于主动行事或是影响他人。

尽管偶有例外，但上述两个概念之间在根本上有所区别。

### 属性 Attributes
属性不会直接影响技能投骰。《狂野世界》把学到的知识和训练所得视作最为重要且直接的要素。高属性能让人物得以更快地提升技能，解锁更多可选专长，后者能让两名具备相同技能的角色各有千秋。

所有角色初始时以下五个属性各自都是d4。

- **灵巧(Agility)：**衡量角色的灵活性，敏捷程度以及整体协调。
- **聪慧(Smarts)：**衡量角色的先天智力，心智灵活程度以及脑子转得有多快，常用于抵抗特定类别的心智和社交攻击。
- **心魂(Spirit)：**自信、决心以及意志力，这常用于抵抗社交、超自然攻击以及恐惧。
- **力量(Strength)：**身体力量以及健壮程度，同时这也是人物在近身战斗中的伤害基准，以及用来决定穿戴与携带东西的多寡。
- **活力(Vigor)：**代表角色对于疾病、毒药以及毒素的忍受力和抗性，以及在倒下前能承受多少物理伤害，这通常用于抵抗疲乏效果，同时也是衍生数据中坚韧的基准。

#### 使用属性 Using Attributes
属性用于：

- 在[核心规则/升级](/核心规则/升级/)时决定技能的提升速度。
- 解锁[核心规则/专长](/核心规则/专长/)限制。
- 得出诸如坚韧或是近战伤害等衍生数据。
- 抵抗效果(诸如遭到擒抱、反制法术、奇术或是嘲弄或威吓这类社交攻击)。

### 技能 Skills
人物在角色创建时有12点可用于购置技能的点数。小于关联属性(在技能名称旁边以括号标出)的技能提升起来比大于等于关键属性的技能更为便宜。参照[核心规则/角色](/核心规则/角色/)以及[核心规则/升级](/核心规则/升级/)。

核心技能有：[通用知识](/核心规则/技能/通用知识/)、[交涉](/核心规则/技能/交涉/)、[察觉](/核心规则/技能/察觉/)、[运动](/核心规则/技能/运动/)、[潜行](/核心规则/技能/潜行/)，玩家角色的这些技能初始都是d4。

角色可以尝试自身并不具备的技能，但这会难上加难，见[未受训尝试](/核心规则/未受训尝试/)。

## 创造其他技能
GM能创造自己想要或是设定需要的任何技能。若技能对用途有所定义，则应该致力于明确其如何运作。举例而言，如果你的星际冒险战役内星际航行占了一大部分，同时你认为使用航天系统不在电子学技能的范围内，那么你也许会新增一项航天学。

玩家同样能在得到GM许可的前提下新增自己的特色技能。然而，除非玩家主动找方法加以运用，否则这在大部分设定中可能都无法经常亮相。

**例子：** //Deadlands: Hell on Earth//
里，角色必须要团结整个镇子以对抗正在接近的变种群落。艾米莉有一个自己创造的技能：新闻学。她决定通过该技能去写一篇动人的文章并将其印刷出来给镇子里的每个人阅读。她获得了优良，因而GM决定让整个镇子都团结在守护者一侧。

### 技能理念
新玩家有时会更重视诸如格斗或射击这些较为宽泛的技能，同时尝试让其他所有技能也是如此。但技能系统的初衷是创造并体现角色本身。无论是狙击手或是弓兵，射手在许多设定里面都稀松平常，而且全都使用同一个能力——精确地用武器射击。在塑造这些角色时不需要同时给火器和弓矢各留一个技能。

然而，调查型角色的确需要许多不同的技能，因为他们处事方式各有不同。强硬的侦探在街头打听时需要威吓；社交名流混迹于上流社会；书虫则会钻入图书馆内；而计算机极客会使用骇客去取得想要的东西。

同时，一些技能合并起来 //并不合理// 。举例而言，驾船、驾驶和航空可以合并成“载具”技能，但当代不是每个会开车的人都能开飞机。这点在调整战役中的技能时要有所考虑。

## 综合调整值

先前版本的《狂野世界》里为诸如潜行和追踪(现已整合进生存)列出了一大票调整值。在该版本里，为了让GM能以更主观的立场放眼全局，着眼于那些无法统合在表格里的东西，我们移除了这些表格，让GM自己分配加值和减值，这通常在-4到+4之间。

这能让GM更综合地考虑所有因素，尤其是有所重复的部分(比如都影响视野的雨水和黑暗就不该叠加)，并简单快速地进行加总，而不用在紧要关头中跑去翻查表格。

## 熟悉度
如果通过展示角色不熟悉某一技能的特定用法能达到恰如其分的戏剧效果(诸如捡起一把外星武器并尝试通过射击以其进行攻击)，那么GM就应该在总值上应用减值(通常是-2到-4)。

这样做时的减值大小完全取决于状况而定。举例而言，枪手在使用弓箭时可能会遭受减值，至少直到其花上一两天进行练习为止。如果玩家特别声明其教授角色是世界闻名的
//化学家
// ，那么在GM要求他进行与古生代地理学相关的检定时，其科学投骰可能会-4。(尽管如此，若是玩家能扮演出知识匮乏，这也是奖励助力点的好时机！

反复使用下的减值持续时间则取决于实际技能。物理上的减值在经过1天或之类的练习后可能就会消失，而基于知识的技能则减值只有在角色能获取合适资料且花时间研究对应主题后才会消失，举例而言，尽管角色主修法国文学，但倘若有时间学习莎士比亚，那就不应在人文上遭受减值。

总而言之，熟悉度减值应该用于戏剧性效果，或是展示文化或科技水平的差别。即使如此，也应该保持故事流畅推进，不要纠结于细枝末节。
