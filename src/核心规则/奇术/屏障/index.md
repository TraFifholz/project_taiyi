**位阶：**行家

**奇术点：**2

**射程：**聪慧

**持续时间：**5

**特效：**火焰、冰块、荆棘、力场、骸骨、能量。

//屏障

// 会制造出一面5英寸(10码)长，1英寸(2码)高的平直墙体，构成静止墙体的材质和施放表面的材质一致。

墙体的硬度是10（优良12），而且和其他物品一样可以遭到摧毁(见破坏物体)。

法术终止或墙体遭到破坏时，其就会碎裂成灰或是消失不见，特效永远不会保留。

**调整**

- **伤害(+1)：** 对任何接触屏障的单位造成2d4伤害。
- **加固(+1)：** 墙的[硬度](../../情景规则/破坏物体/)变为12（优良14）。
- **塑形(+2)：** 屏障形态变为环形、方形或别的基本形状。
- **大小(+1)：** 屏障的长度和高度加倍。
