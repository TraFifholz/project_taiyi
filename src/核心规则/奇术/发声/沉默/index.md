**位阶：**入门

**奇术点：**1

**射程：**聪慧x5(发声); 聪慧(沉默)

**持续时间：**瞬间(发声); 5(沉默)

**特效：**魔法效果，空中的短促波纹，开始或停止鸣响的铃铛或编钟。

//发声

// 会模仿任何已知的声音或人声，并让其自射程内的某个点发出，音量最高可达大声呼喊的程度。如果用于考验，防守方则必须以聪慧[对抗](/核心规则/特性投骰/)施术投骰。

//沉默

// 则相反，其能在大型爆发盖板内压制音量最高等同于大喊的所有声音。这会让所有这会让所有效果范围内的察觉投骰-4，尝试听到范围内的声音也是如此。优良则会彻底压制盖板内的所有声音，这类察觉投骰自动失败。

**调整**

- **可动(+1)：** 施术者每一[轮](/核心规则/战斗/)可以将效果范围移动至多等同于[奥法技能](/核心规则/临时/奥法背景/)骰子类型数的距离。 
- **目标(+0)：** 施术者不再是在[效果范围](/核心规则/情景规则/范围效果攻击/)内施放沉默，而是变成每消耗1[奇术点](/核心规则/临时/奥法背景/)就能影响[射程](/核心规则/装备附注/射程/)内的一个目标，非自愿目标以[心魂](/核心规则/特性/)进行抵抗(若施术者取得[优良](/核心规则/特性投骰/)则还要-2)。
