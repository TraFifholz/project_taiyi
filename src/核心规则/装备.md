本章节简单介绍了从远古时期到近未来的各种装备。购买装备前请仔细阅读以下注释，以确保能理解每个关键词的意思。

### 费用 Costs

假定角色具备衣物以及其他个人物品。在现代设定里，他们还会具备居所和工具，可能还有一辆车，以及其他对应时代的必需品。¥3000的起始资金是针对除去这些个人物品外的”冒险装备”。价格大部分都会以现代术语来展示。对于更为古老或是先进的物品，其价格会按起始资金比例进行换算。这有时候会导致奇怪的结果——在1920年，现实世界里一套漂亮的正装需要耗费20银元，而不是这里列出的¥1200——尽管如此，起始资金仍然比一般人所拥有的要多。

某些物品因为一般是通过强迫劳动而制造得出，所以定价非常困难——诸如工兵和士兵在战场上制造的弩炮和投石机，其价格体现的是制造所需的时间和资源。

使用本书列出的价格来快速开展游戏，或是将其作为自创世界设定的基线。官方《狂野世界》设定里会列出对应时代及环境的新装备及其价格。

### 负载 Encumbrance

大多数时候无需考虑角色的负重多寡。但若是计较这点颇为重要时，则使用以下的负载等级表。若角色携带的东西超过其中列出的重量，其就会陷入过载。

过载的角色在移速(下限为1英寸)、奔跑投骰、灵巧及其关联技能，和抵抗疲乏(见100页)的活力投骰上减去2。

如果重量达到自身可承受的三倍或以上，则角色能以1移速移动等同于其活力的轮数，此后每轮其都必须成功通过一次活力投骰，否则就会遭受一级疲乏。

角色最多能负担或携带其可承受重量四倍的物品。

| 力量 | 最多可负担的重量 |
| --- | --- |
| d4 | 20磅 |
| d6 | 40磅 |
| d8 | 60磅 |
| d10 | 80磅 |
| d12 | 100磅 |
| 此后每+1 | +20磅 |
 **笨重物品：** 携带大箱子、宝箱、人体之类的大型、笨重或是不平衡的物品可能会让角色过载，无论其实际重量为何(GM判断)。
