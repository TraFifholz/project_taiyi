# 角色 Character
伟大的英雄可不仅仅只是堆砌数值，但在游戏系统里这当然也是其根基所在。按照以下步骤创建你的角色。

## 概念 Concept
已经出版的设定里面通常包含角色灵感以及预设”范型”。你能直接以其进行游戏，或是以此得出自己的想法。若这个世界是由GM所原创，和对方谈谈，看看哪种角色最能引起你的兴趣。

## 族裔 Race
默认情况下，所有玩家角色均为人类。人类在角色创建时额外获得一个新手专长。

## 负赘 Hindrances
负赘是缺陷、缺点，或是来自角色背景故事中的黑暗秘密。

可获得的负赘至多能达到6点。主要负赘价值2点，次要负赘价值1点。角色因此能同时具有三个主要负赘，或者六个次要负赘，或者最后相加总和为6点的任意搭配（若是愿意可以选取更多负赘，但最多只有6点好处！）。

选取负赘不单单能有助于定义并扮演自己的角色，而且在开始时也提供了更多可用于换取额外属性点、技能点、专长，甚至是起始装备资金的额外点数。

消耗2点可以：

* 让属性骰子类型提升一级，或是
* 获得一个专长。

消耗1点可以：

* 额外获得1点技能点，或是
* 额外获得等同于设定初始数量两倍的起始资金。

## 特性 Traits
角色藉由属性和技能得以成型，这统称为“特性”，两者的运作原理一致。属性和技能均以骰子类型划分，通常就是从d4到d12。d6是成年人类的平均水平，越高越好！

### 属性 Attributes
每个角色以下五个属性开始时都是d4：灵巧、聪慧、心魂、力量、活力。

可用于提升属性的点数有5点。举例而言，将d4提升到d6消耗1点。这些点数可以任意使用，但除非族裔能力另有说明，否则属性不能升到超过d12。倘若超过，则每超过一级就会增加+1调整值。举例而言，将d12力量提升两级，那力量值就是d12+2。

### 技能 Skills
技能乃是习得的能力，譬如开火、近身战斗、科学知识、专业能力等等。

技能较为宽泛，以确保行动简单直接。举例而言，射击技能就涵盖了各类枪械、弓箭、火箭发射器等其他远程武器。核心技能：运动、通用知识、察觉、交涉、潜行——这些是大多数成年冒险者”与生俱来”的能力。除非族裔能力、专长或是负赘另有提及，每个角色初始这五个核心技能均有d4。

**购置技能：**  核心技能确定好后，另有12点可以随意用于提升核心技能或是购置新技能的点数。

若技能骰子类型小于等于与其关联的属性（在技能列表中会以括号标注），则每升一次骰子类型（从d4开始）消耗1点技能点。若超过了关联属性，则每升一次骰子类型消耗2点。

**技能上限：**  除非角色的族裔对应初始技能为d6，否则在创建角色时任何技能都不能增加到超过d12。若初始技能就为d6，则其上限增加到d12+1。

## 衍生数值 Derived Statistics
角色卡仍有一些需要补充的其他数值，详细见下。
**移速**决定了你的角色在诸如战斗这种战术场合下能移动得多快。标准移速为6，这意味着游戏内每轮移动6英寸（每英寸在真实世界里等同于两码）。

**格挡**等同于2+角色格斗骰子类型的一半(若角色没有格斗则总值为2)，并加上盾牌或特定武器提供的任意加值。这是在近身战斗中要击中角色的目标值(Target Number，TN)。

若格斗技能高于d12(譬如d12+1)，附加其固定调整值的一半。举例而言，格斗是d12+1，格挡就是8，若格斗是d12+2，则格挡是9。

**体型：**  除非受到族裔能力、专长或是负赘调整，否则角色的默认体型是0，这不能低于-1或高于+3。

**坚韧**是角色受到伤害的门槛，伤害投骰要大于等于该数值才能造成损害。

坚韧等同于2+角色活力的一半，再加上护甲值。超过d12的活力如同上文格挡般计算。

## 专长 Edges
属性和技能是角色的基础数值，但真正使其各有所异的是专长。即使两位特性一样的士兵，根据其专长选择，玩起来也可能大相径庭。其中一个可能重视领导力专长，使其能号令同伴，而另一位则着眼于通过连击或是横扫一次性干翻大量敌人。

角色的专长来源包括选择负赘、族裔能力，以及升级。设定书中可能也会具备与该特定世界或风格相关的额外能力。

## 装备 Gear
一些设定里会为角色提供全部所需的装备。大部分设定都是简单地给予一定数量的起始资金，然后再从相关的武器、护甲以及装备列表中随意进行购置。除非设定书或者GM另有提及，标准的起始资金数量是¥3000。

根据设定不同，这既可以代表角色的一切所有物，也可以只代表“冒险”装备，其他的世俗财产则放在家里或者公寓中，后者取决于GM。在现代设定里，几乎所有人都应该具备家宅、衣物、家用电器等等。在角色表中列出的装备应该是“冒险装备”，而不是其所有物品的冗长清单。

玩家在大部分游戏中都不必考虑能携带多少东西，但如果变得有所必要，参照负载规则。

## 背景细节 Background Details
制作新角色的最后一步是为其补上设想的额外历史或是背景故事。问问自己为什么他会在这里？他的目标是什么？他在哪生活？他会不会有任何可能与游戏有关的亲朋好友？或是干脆开始游戏，稍稍代入角色思考，接着把那些变得重要的细节填补进去。

若是愿意也可以和其他玩家商量，也许角色在一开始就彼此认识。或者你们可以决定共同优化一下队伍，以此保证角色在技能和能力上实现良好分配。倘若如此，确保你是在玩自己想要的角色。如果对成为团队的治疗者不感兴趣，玩一个这样的角色也没什么意义。
