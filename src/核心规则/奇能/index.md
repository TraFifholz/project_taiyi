# 第五章：奇能

以下页面中有数十种给勇敢英雄以及恶毒反派准备的奇能，同时含有让各位得以创造数千种超能力的调整——如果将特效与奇能类型也考虑在内，那更是不计其数！接下来是阅读并使用各项奇能描述的方法：

**费用：**  每项奇能的价格都以奇术点的形式列在名称后面的括号当中。注意奇术点并非用于启动奇能——一旦购置，奇能只要启动就会生效。角色已购奇能和调整的总费用不能超过自身的奇术点上限；单个奇能的总费用也不能超过单项上限。除非另有说明，否则奇能只能选取一次，而且就首屈一指这样的专长以及单项上限而言均视同独立的奇能。

**等级：**  有些奇能会列出"等级"，这代表奇能能予以选取的次数（假定可以多次选择）。举例而言，选取五次超级属性，就意味着英雄在其中有五个等级。

**特效：**  这是关于奇能表现形式或是根本来源的点子。特效通常只有叙事性和描述性，但在决定奇能类型时颇为重要。

**奇能调整：**  这些列在每个奇能后的特定调整可以用于定制能力，同时还会带有需要消耗或是得以省下的点数。应用所有调整后，奇能费用的下限是1。

::: info 特效 Trappings
特效是奇能系统的"不传秘方"，这能让大家轻而易举地快速创造出无数种效果相似的奇能，从而无须一直去查找某个特定版本的作用。

乍一看，这可能貌似比其他游戏中的内容要少，因为没有单独针对冰爆、炎爆之类的奇能。然而所有这一切乃至于更多的内容都已经囊括其中了——如何加以表现是取决于各位和大家的想象力，而不是就相近奇能的各个方面都给出不同的规则。

本书当中，单个远程攻击奇能就能塑造出各种神通：包括火焰爆炸，黑暗能量轰炸乃至噬人的虫浪。护甲奇能则能表现为完整的身体护甲或是昆虫类的厚壳。离奇反射则可以是额外的感官示警、快速反应或是纯粹的运气。

GM和玩家要做的一切就是对此加以描述，并查找每个奇能可能具备的任何特殊调整。
:::

## 启动奇能 Power Activation

诸如护甲或是坚韧这样的被动奇能不需要通过技能投骰予以启动——其永远生效，除非角色选取了需要启动调整。启动奇能会列出启动所须的技能，诸如使用集中来启动恐惧奇能。除非另有说明，否则这永远属于一个动作。需要启动的奇能在英雄陷入无力化、被打到失去意识或是入睡时就会终止。英雄也能通过一个自由动作自行将其终止。

**大失败：**  除非奇能写了特别的效果，否则在予以启动时投出大失败就会使超能者陷入分神和脆弱。

**视线：**  奇能的描述中会写出对应射程，然而除非另有说明，否则目标人员或影响点应当始终在视线当中。若必须放置盖板，则盖板中心也要在视线之内。

## 宕机 Power Down

部分奇能写着若是超能者失去专注就会"宕机"。若是如此，只要具备这种奇能的角色遭受动摇或是震慑，其必须成功通过一次心魂投骰，否则所有能宕机的奇能都会马上宕机。角色立刻使用助力点消除动摇效果（或是化解了这次攻击造成的所有损伤）则不需要进行投骰。若是英雄陷入无力化，这类奇能也会自动终止。

## 奇能类型 Power Types

诸如能量控制等奇能需要玩家选择奇能能予以使用或产生效果的特定能量或物质，这称为"奇能类型"，而常规可以选择的种类描述如下。

| 能量 | 物质 |
|------|------|
| 寒系（霜与冰） | 气系 |
| 黑暗 | 生体（动物、人类、拳打、脚踢） |
| 电系（闪电） | 土系（玻璃、沙砾、石块） |
| 火系（高温） | 金属（子弹、小刀） |
| 原力（力场、重力、磁力） | 植物（大部分织物、绳索） |
| 光明（激光） | 合成物（塑料） |
| 魔法（灵魂、超自然） | 水系（液体） |
| 心神（催眠、灵能） | |
| 辐射 | |
| 声音 | |
| 时光（时间之力） | |
| 电子信号 | |

奇能类型并非基于现实世界中的自然科学，而是根据漫画书中的基调而设。不要过于纠结某种能量在现实中的分类——重要的是其中的基调。

## 奇能调整 Power Modifiers

大部分奇能都具备能拓展或是规限其用途的特定调整，以此会换来更高或是更低的费用。调整可以予以组合。调整永远不能将奇能的费用降到1以下。完整调整列表见[奇能调整](奇能调整)。

## 超能奇术专长 Super Powers

**需求：**  入门。每位角色初始免费具备此专长。

此专长让角色使用奇术点购置本章列出的奇能。新异能者角色的奇术点上限为 **3**。奇术点上限不会随位阶自动提升；角色必须在游戏中收集数据因子。每收集1个数据因子，奇术点上限额外+3。

角色已购奇能及调整的总费用不能超过奇术点上限。奇术点上限为15点或更低时，单个奇能最多投入5点；从奇术点上限18点开始，奇术点上限每提高3点，单个奇能的可投入上限提高1点。计算单个奇能的费用时，以该奇能加上所有调整后的总费用为准。举例而言，奇术点上限为3、6、9、12或15时，单个奇能最多投入5点；奇术点上限为18时，单个奇能最多投入6点。

每个异能者都具备某种决定了其奇能类别的特定遗传标记，并且必须在下列[四大流派](流派/)中选择其一：

- **[少司命](流派/少司命)：**  改变自身和他人DNA以及身体机能的能力。少司命者能借由其力量去治疗、增强身体能力、改变外观，乃至于控制植物和其他生命形式。
- **[烛龙眼](流派/烛龙眼)：**  通过心灵而不是寻常感官去感知事物的能力。大部分烛龙眼者可以在极远距离外视物或聆听，看见过去和未来的事件，以及增强自身感官。
- **[共工力](流派/共工力)：**  借由心灵控制物质和能量的禀赋，这涵盖了诸如浮空、移物、控火、驭电等等。
- **[云中君](流派/云中君)：**  读取或控制他人心灵以及创造心神幻象的能力，云中君者还能进行心神攻击或是让人员陷入沉睡。

每个种类都会决定角色可用的奇能、奇能调整和特效。除非异能者具备[双重秉赋](../角色/专长/背景专长_Background_Edges#双重秉赋-double-gifted)专长，否则只能具备一项奇能种类。

## 集中 Focus

集中反映了英雄驱使其他特性并未涵盖的神通的造诣，有时某些特别的奇能也需要用到，而其他时候英雄也可能将其用于GM发起的次级或是普通效果。
