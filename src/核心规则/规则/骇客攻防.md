# 骇客攻防

龙散市的冲突不只发生在街头和枪口之间。摄像头、门禁、无人机、车机系统、义体接口和城市节点均为可被入侵的战场。骇客攻防用于处理遭遇中对电子设备的快速入侵、反制和接管。

若一次骇入不需要逐轮处理，可以继续使用常规的[骇客](../角色/特性/技能#骇客-hacking)任务或[剧情任务](../冒险工具箱/剧情任务/)规则。只有当设备攻防的行动顺序、损伤、控制权或战术位置重要时，才需要使用本规则。

## 设备属性

电子设备拥有以下属性。

| 属性 | 说明 |
| --- | --- |
| 安防等级 | d4 到 d12，代表设备自身防护、系统质量和自检能力。 |
| 坚韧 | 设备抵抗骇客伤害的数值。默认由安防等级决定。 |
| 鲁棒性 | 设备可承受的损伤数。损伤超过鲁棒性时，设备瘫痪并被完全接管。 |
| 骇入难度 | 对该设备进行骇客攻击的目标值，默认 4。 |
| 算力 | 设备可装载程序的容量，只以点数记录，不用于投骰。 |
| 无线射程 | 设备无线骇客攻击的覆盖范围。没有无线模块的设备不具备无线射程。 |

安防等级决定设备的基础坚韧与算力。

| 安防等级 | 基础坚韧 | 算力 |
| --- | ---: | ---: |
| d4 | 4 | 2 |
| d6 | 5 | 4 |
| d8 | 6 | 6 |
| d10 | 7 | 8 |
| d12 | 8 | 10 |

算力只是程序容量。需要投骰时，使用操控者的骇客、设备的安防等级，或特定程序列出的 AI 等级。

## 骇客攻击

角色花费一个行动，可以使用自己操控的电子设备，对一个已连接的电子设备节点进行骇客攻击。

连接可以来自物理接口、同一设备网络、无线覆盖、已接管节点的相邻节点，或允许接入信息网络的特殊奇能。

骇客攻击流程如下。

1. 攻击者进行骇客特性检定，对抗目标设备的骇入难度。
2. 成功后，攻击者对目标造成骇客伤害，默认伤害为 2d4。
3. 若骇客检定获得优良，本次骇客伤害 +1d6。
4. 骇客伤害对抗目标设备坚韧，并按普通伤害规则造成动摇或损伤。

设备已经动摇时，若再次受到动摇结果，则如常转化为 1 点损伤。设备的损伤会影响其自检、自净和由设备自身进行的其他特性检定。

当设备损伤数超过鲁棒性时，设备瘫痪，并被骇入者完全接管。完全接管允许骇入者读取和写入数据、开启或关闭设备、操控设备原有功能、移除或装载程序，并把该设备作为网络跳板。完全接管不会让设备做到物理上不能做到的事，也不会把脑机节点的控制权扩展为精神控制。

## 动摇与防火墙

设备处于动摇时，其防火墙暂时解除。骇入者可以利用这个窗口读取开放数据、移动到相邻网络节点，或继续攻击该设备。

在设备操控者回合开始时，操控者可以进行一次骇客特性检定作为自由行动；成功则移除设备动摇，并恢复其防火墙。若无人操控，设备改用自身安防等级进行自检，且不投不羁骰。

## 自净

角色花费一个行动，可以让自己操控的设备进行自净特性检定，以移除设备损伤。检定使用设备的安防等级；若不羁角色亲自操控设备进行自净，则这是一次特性检定，按常规投掷不羁骰。

成功移除 1 点损伤，优良移除 2 点损伤。自净不能恢复已经被完全接管的设备，除非骇入者的控制权已被切断，或主持人判断设备仍有机会夺回本地控制。

## 设备网络

设备网络由联网的设备节点组成。主持人可以把网络画成简单的节点图，例如：

入口终端 -> 摄像头组 -> 门禁 -> 无人机坞 -> 主服务器

在防火墙生效时，骇入者的程序进入一个网络节点后，无法移动到其他网络节点。只有当节点动摇、瘫痪、被完全接管，或存在被主持人允许的特殊通道时，骇入者才能从该节点继续向相邻节点推进。

被完全接管的节点可以作为跳板。若跳板具备无线射程，则后续无线攻击从该节点计算射程。

## 有线与无线

骇客攻击分为有线攻击与无线攻击。

没有无线模块的设备只能进行有线骇客攻击。攻击者必须通过数据线、维护接口、芯片接口、实体终端或同一载具内部总线等方式接入目标设备或其所在网络。

有无线模块的设备可以进行无线骇客攻击，也会成为无线骇客攻击的合法目标。无线模块既是优势，也是风险。

无线骇客攻击只检查攻击源的无线射程是否覆盖目标。只要攻击者的无线射程足以抵达目标，且目标具有无线模块或天线单元，就可以发起无线骇客攻击。目标自身的无线射程不会限制它被攻击。

若目标要反向骇入、追踪、反击或主动建立连接，则再检查目标自己的无线射程是否覆盖攻击源，或是否能通过中继节点抵达攻击源。

### 无线射程

| 等级 | 范围感 |
| --- | --- |
| 视线级 | 室内级。同一房间、同一车厢或近距离室内空间。普通墙体可能允许，屏蔽墙和厚重金属结构通常阻断。 |
| 短距 | 建筑级。一栋建筑内相邻楼层、隔壁建筑、路上车辆到红绿灯。 |
| 中距 | 整栋建筑或街区节点级。基本覆盖一整栋建筑，或从一个红绿灯到下一个红绿灯。 |
| 远距 | 片区级。覆盖城市的一个片区，常见于发射塔、固定中继站、企业安防节点。 |
| 超远距 | 城市级。几乎覆盖整个城市，通常属于大型通信基础设施、TAIYI 级节点、军警或巨企骨干设施。 |

常见设备的默认无线射程如下。

| 设备 | 默认无线射程 |
| --- | --- |
| 无线耳机、微型外设、临时无线模块 | 视线级 |
| 普通手机、个人电脑、穿戴设备、家用摄像头 | 短距 |
| 无人机控制器、车机系统、安防主机、家庭网络中枢 | 中距 |
| 企业天线、警用通信设备、固定中继、移动通信车 | 远距 |
| 城市级基础设施、巨型发射塔、TAIYI 相关核心节点 | 超远距 |

## 程序

程序相当于电子设备的装备，占用算力。设备可以装载任意数量的程序，只要总算力占用不超过设备算力。

| 程序 | 算力占用 | 效果 |
| --- | --- | --- |
| 蠕虫载荷 | 见表 | 提高骇客伤害。 |
| 洪泛线程 | 3 或 6 | 提高骇客攻击的射速。 |
| 冗余镜像 | 3/级 | 每级使设备鲁棒性 +1。 |
| 哨戒 ICE | 2/级 | 每级使设备安防等级提高一级，最高 d12。 |
| 混淆 ICE | 1/级 | 每级使设备坚韧 +1。 |
| 隔离墙 | 2/级 | 每级使设备骇入难度 +2。 |
| 守门犬 AI | 见表 | 每轮一次限定自由行动，进行骇客攻击或自净。 |

蠕虫载荷使用下表。

| 骇客伤害 | 算力占用 |
| --- | ---: |
| 2d4 | 0 |
| 2d6 | 3 |
| 3d6 | 6 |
| 4d6 | 9 |
| 5d6 | 12 |
| 6d6 | 15 |

洪泛线程使骇客攻击具备射速 2 或射速 3。射速 2 占用 3 算力，射速 3 占用 6 算力。按基础射速规则处理；不羁角色仍只投一枚不羁骰。

守门犬 AI 使用下表。AI 等级只用于该程序自身行动，不提供不羁骰。

| AI 等级 | 算力占用 |
| --- | ---: |
| d4 | 3 |
| d6 | 4 |
| d8 | 6 |
| d10 | 8 |
| d12 | 10 |

守门犬 AI 每轮可以进行一次限定自由行动，选择进行骇客攻击或自净。骇客攻击使用 AI 等级投骰。自净使用 AI 等级与设备安防等级中较低者投骰。AI 只能操作其所在设备或该设备已经合法接入的节点，不能替代角色完成所有骇客任务。

## 脑机与殖装

脑机、脑芯片、数据接口、芯片接口和类似殖装默认视为有线设备。它们没有天线单元，因此不能发起远程无线骇客攻击，也不会被远程无线骇入。

若脑机通过数据接口、芯片接口、线缆、载具控件、拟感面板或其他物理连接接入外部设备或网络，该连接仍可能成为骇客攻击路径。

脑机类设备拥有安防等级、骇入难度和算力，但不提供独立鲁棒性。它们受到骇客伤害时，损伤改为角色获得疲乏。设备动摇可以表现为神经干扰、接口短路或感官过载。骇入者接管的是脑机或殖装节点，不是角色人格或身体本身；除非被接管的殖装本身能执行对应动作，否则不能直接控制角色身体。

角色可以安装殖装无线模块，让脑机或殖装获得无线连接。这样做能远程接入设备和网络，但也让该殖装成为无线骇客攻击的合法目标。

## 电子精灵

电子精灵是以奇能形成的虚拟设备。它使用集中代替骇客进行骇客攻击和网络行动，并按投入奇术点决定自身的鲁棒性、安防等级和算力。

| 奇术点 | 鲁棒性 | 安防等级 | 算力 | 无线射程 |
| --- | ---: | --- | ---: | --- |
| 1 | 0 | d4 | 2 | 视线级 |
| 3 | 1 | d6 | 4 | 短距 |
| 5 | 2 | d8 | 6 | 中距 |
| 8 | 3 | d10 | 8 | 远距 |
| 11 | 3 | d12 | 10 | 超远距 |

电子精灵可以装载程序，并可作为网络节点进入设备网络。电子精灵被瘫痪时，奇能结束，施术者承受 1 级冲击疲乏。
