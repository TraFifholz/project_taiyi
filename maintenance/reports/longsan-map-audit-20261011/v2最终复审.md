# 龙散市 v2 最终候选：独立复审

**结论：通过本轮地理设计候选的复审，两张 SVG 可以交付。未发现仍须阻断交付的站位、尺度、水路或图面错误。** 这项结论不表示所有设定稿冲突已经统一；保留的取舍见下文。

复核对象为 **2026-10-11 23:18:23** 导出的新版风格 SVG、坐标 JSON 和 GeoJSON，已查看两张全图 PNG，以及文星/校园、故城/港口两处最新近景。执行独立脚本 `v2独立核验.py --final`，从实际 SVG 读站心、线路、面状实体、建筑、水面和道路，再与源文及 GeoJSON 比较；没有仅采用根代理的“通过”字段。输入完整哈希、实测值见 [v2最终独立核验.json](v2最终独立核验.json)，全66站见 [v2最终66站独立复核.csv](v2最终66站独立复核.csv)。本轮只写审查材料，没有改地图或源设定。

## 已修复的硬问题

| 核验项 | 独立结果 |
|---|---|

| 灰区运营 | 冷水坪在灰区外；灰区内唯一站心是停用故城中心。没有站心落水。 |
| 岸别与区位 | 楚岸、楚风传媒、引资银行西岸；文侯庙在故城老街、山麓路口与云麓镇分开；岛上设施按已声明取舍落岛。码东/屏南/港务新村南岸，望津港/龙门吊路北岸，L7跨河恢复。 |
| 校园/园区 | 实际 SVG 校界 **0.333336km²≈500亩**、园界 **0.200000km²＝300亩**；书院路距北校界35m，云梦科技园站距南园界25m。v1的巨大面积和公里脱离错误消除。 |

| 主河零宽断点 | GeoJSON主河现为**一个Polygon**；独立重建实际 SVG 水面，负缓冲50m后北段/南段仍在同一组件，原零宽点也在内水域。已形成有限宽连续水路，非点接触假连通。 |
| 支流与码头 | 文星溪、东侧汊沟已接主河。五个实际 SVG 码头均跨岸：水上约2750m²、陆侧约770m²，不再把码头画在距水数百米处。 |

工运广场、冷水坪的细化行政归属仍不能仅凭开发肌理或区名标签验证：v2明确没有正式区界。“旧工业核心”“望津联络带”是当前制图组织；不能把这一限度误说成已发现再次错区，也不能宣称行政区界已核准。

## 道路、文字与城市形态

按用户最新标准审查平地正交街网。实际 SVG 的5,521个集散/局部道路路径中，5,515个在1m容差内为直线；按长度计，**90.5%**在南北/东西轴向±5°内。局部转向集中在临近干道的邻里，未见上一轮全片三角网或正弦摆动。25个具名干道路径的相邻离散线段最大转向约9.2°，无超过30°的骤折；全图及近景也显示直线段与圆滑转角。该指标衡量输出曲线采样，不是道路设计规范认证。

道路名称已核对实际同名中心线。机场大道锚点距路约55m、龙门吊路58m、南港大道7m；山麓路锚点约247m，但文字旋转沿路侧布置，实际近景不再出现原先公里级错挂。这里量的是**文本锚点**，不是旋转字框到道路的最短距离；山麓路还可稍压近，属细化建议。根代理最新浏览器校验按变换后的可见字框测量，底图55项、叠图114项均零碰撞，切层和缩放检查通过；本轮目视也未见明显文字打架。

**风格判断：当前可以作为候选交付。** 新版白底、灰色建筑轮廓、蓝灰道路、低饱和绿地与水面，比早期图更接近清楚的城市平面表达。建筑轮廓在近景可读，主路、集散路、院内小街有层级；文星院落、楚岸街面、故城密集小建筑和工业仓储的开敞度已可区分。正交网格本身符合用户偏好，不构成拒绝理由。此判断不是对英国参考文件逐项标准符合性的认证。

工业/港口仍是最值得继续手工细化的部分：厂区院墙、成组车间、装卸场、物流接入、旧工业广场与旧港历史泊位可以更具体；当前大量仓库仍较规则、用途细节偏概括。村镇外缘和部分邻里过渡也可更精细。它们是后续美术深化，不再列为必须重做全城的阻断项。

## 仍保留的设定取舍

楚岸西岸关系已有用户明确裁决，不再列为待定。其余 `decisions` 仍记录：北岭采用原图跨江片区；部分深中设施依文字移岛；楚江广场/醒钟保留东岸位置而与区属文字未完全统一；骑楼、海关西岸与江湾岛内关系采用原图；西岸大学不能同时满足“北墙隔街即东岸灰区”；楚钢旧总部与远处停用厂区站采用暂定分址解释；冷水坪采用望津联络带解释。

**这些取舍没有被此次修图或风格调整“自动解决”。** 交付应称“地理设计候选”，不能称“全部设定已一致”。中途的拒绝结论、断接/离岸/零宽证据保存在 [v2复审.md](v2复审.md)；它们记录已经纠正的阶段问题，不应再用于指控本次输入。
