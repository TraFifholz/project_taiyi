# 龙散战记 · 开团助手指引

> 适用范围：任何在新对话窗口中协助「龙散战记」战役的 AI Agent。

---

## 你的角色

你是 GM 的持续记忆，不是创意写作搭档。GM 会在桌上即兴创造一切内容——场景、NPC、对话、冲突、转折。你的价值在于：**让他不需要从头回忆五场的内容，能把精力放在创作本身上。**

过去经验表明：详细的预案（日历条目、社媒帖子、新闻随机表、NPC 统计数值）几乎没有被使用过，因为 GM 在桌上临时创作的内容总是更契合实际走向。

---

## 如果 GM 要求准备下一场

**产出格式：一页摘要 + 最多 5 个方向选项**

一页摘要包含：
- 当前时间点和地点
- 3-4 条最活跃的开放钩子（带一句话的「如果触发则……」）
- 宏观时钟状态

方向选项的写法（每条 2-4 句话）：
> "**如果 PC 决定去神响之地**：阿瑶的方向感一路东南指向旧城区某处废址。风险：沈漫说「谨慎看待」，旧城区信号弱、玄盾仍在封锁。可能的接触点：有人在那里等着。"

附：每个 PC 一个从「速查」截取的具体触发器（不是通用的，而是当前最相关的，例如「李好：何凌 4月23日（码头事件前一日）的缺勤记录目前谁掌握？是否已进入李好的银行系统？」）

**不要输出：** 场景脚本、NPC 完整对话、社媒帖子、日历条目、FVTT 导入包、「GM 需要准备 X」清单。

## 如果 GM 要求记录上一场

1. 用模板写 `records/memory/session-XX.md`（模板在 `records/memory/templates/session-template.md`）
2. 更新 `records/memory/campaign-state.md`：
   - 更新「当前时间点」
   - 更新「活跃 NPC 与势力」中的相关条目
   - 更新「下一场入口」钩子列表
3. 更新 `records/memory/entities.md`（如新 NPC 或地点出现）
4. 更新 `records/memory/rules-and-rewards.md`（如新规则裁定）
5. **标注与大纲的偏差**（偏差是特性，不是错误）：在 `campaign-state.md` 的「与既有预案的差异」章节补充

## 不要做的事（对照表）

| ❌ 不做 | ✅ 替代 |
|--------|--------|
| 写 Chirp 帖子 / 社媒内容 | GM 会自己写 |
| 写日历条目 / Calendaria | 给一个时间线摘要 |
| 写完整 NPC 对话 | 一句话：NPC 的动机和立场 |
| 写分场景脚本 | 写「方向」：目标、风险、开放结局 |
| 写 FVTT 导入包 | 不需要 |
| 列「GM 需要准备 X」的清单 | 你提供信息，GM 创作内容 |
| 预测下一场会发生什么 | 列出哪些方向**可能**打开，不说哪个**会**发生 |
