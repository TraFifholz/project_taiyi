# Smartphone 云端只读检查

检查日期：2026-09-03。目标：个人服务器 `https://fvtt.univare.icu` 的 `taiyi / TAIYI` 世界。用户授权使用已有 AssistantAgent 账号只读检查。

## 结论与建议顺序

现有 Smartphone 已有玩家持续使用，适合先修正日期、私信与手机时钟，再开放手机商城和龙散网页。无需先开发一套新的手机系统。

| 顺序 | 工作 | 当前证据 | 建议范围 |
| --- | --- | --- | --- |
| 1 | 校正时间与旧内容 | 世界日历显示 2030-05-08 22:28；当前战役记录已到 5/10；Chirp 仍有旧日期内容 | 先确定世界时间和历史帖的对应关系；逐条保留玩家互动，不批量覆盖 |
| 1 | 修复旧私信导入 | 8 条会话的键不符合现版格式；唐索账号实际渲染出 0 行会话 | 为发送者与收件人建立正确对应；普通短信、群聊与 Chirp 私信分别处理 |
| 1 | 修复手机时钟显示 | 唐索手机状态栏一直显示 00:00；同一客户端时间 API 返回 22:28 | 排查手机时钟初始化和刷新；不调整世界时间来迁就显示错误 |

## 已有数据与边界

### Chirp 与普通消息

- Chirp：20 个账号、113 条帖子、18 个趋势、8 条旧私信。
- 其中 89 条帖子来自 S4 导入包，另外 24 条属于包外内容，包含实际玩家发帖。
- 以当前备团记录下一阶段的 2030-05-11 零点为界，65 条帖子时间在其后；其中 S4 旧包 52 条、包外 13 条。应先核对历史日期映射，不能把包外内容直接判成无效数据。
- 帖子隐藏数为 0。当前云端 `loadPosts()` 直接载入全部帖子；时间线不会仅因普通 `timestamp` 尚未到达就自动隐藏它。
- 旧私信键形如 `taiyi_s4_dm_3_李好`；现版要求双方社交 ID 排序后以 `<>` 连接。现版渲染遇到无法解析的账号会跳过条目。
- 使用云端已经加载的 `renderMessagesView()`，读取真实设置并以唐索的社交账号渲染：8 条存储会话、0 条可渲染会话。此验证没有发送消息或标记会话已读。
- 普通手机消息与 Chirp 私信是两套数据：现有事务所群聊 132 条消息，另有一对一消息 8 条。
- 存在两个同名「相亲相爱事务所」群，成员数分别为 7 和 8；本次未合并或清理。

### 日期与状态栏

- 游戏时间来自 Calendaria，世界时间值为 `1904509738`。
- 浏览器可见日历为 **8 May, 2030 / 22:28**；手机时间 API 与 Library 时间 API 返回同一值，日期部件为 2030-05-08 22:28。
- 唐索手机状态栏显示 **00:00**，在多次页面读取和截图中保持如此。已确认显示差异；未在本轮定位根因或修复。
- 备团依据为 `records/memory/campaign-state.md` 的 S11 收尾与下一话时间。不能仅用操作系统时区转换替代游戏日历的日期部件。

### 银行与商城

- 引资银行已有 6 位角色的账户组，共 7 个账户；唐索有两个。
- 当前生效的货币定义来自 GlitchSmith Library：`currency` 为人民币，符号 `￥`，对应 `system.details.currency`；`bucks` 为电子货币。
- Smartphone 自己的旧 `currency-settings` 中仍有「元」「刀」配置，它不是当前生效定义，不能仅据此断言全局货币映射损坏。
- Stylish Shop 目录实际返回 11 家商店：SHADOW、威格广场、拾荒站、沃可佳、燧明科技集团、玄盾国际后勤部、白桦树、芙龙兴盛、赛博诊所、重黎工业集团、黑市技术掮客。
- 以唐索作为购买角色调用只读商品列表接口，成功返回 100 个列表条目，样例价格为 `1,500￥`、`1,200￥` 等。100 是本次返回的列表长度，不是全部库存数量。
- 本轮未开放手机商城入口，未执行购买、扣款、转账、赠送、库存更新或场景移动。
