# 第 11 话 · 陵寝杯地下拳王

> 2026-09-03 重整｜现行大纲。这里是故事梗概，不替玩家预定行动。

风格：地下体育与名声争夺。主要组织：义胜盟、阿奎拉家族、玄盾国际。

## 梗概

地下拳赛提供奖金、名声和进入更深工程区域的引荐，但不是一张只有冠军才能拿到的主线通行证。杨振邦主持赛事，纪小刀想证明自己，柳拂衣看重参赛者是否守约。艾德礼关心技术与交战底线，西尔维娅则不愿异常者再次被当作测试材料。

重黎曾向相关场地购买动作和适配数据，比赛的公开记录与未经同意的采集形成冲突。邢九重就是旧稿所称的陵寝带路者：他是有经验的地下领班，不另造一位无所不知的守门人。郁垒的旧卜府经历让他对被当成资产的拳手格外敏感。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 杨振邦 | 记录报名、赌注与赛果，保证能兑现自己承诺的部分。 |
| 纪小刀 | 作为主要决赛对手争取认可，胜负不决定他是否值得尊重。 |
| 柳拂衣 | 检验承诺与行动，不为主角无条件作担保。 |
| 艾德礼·霍华德 | 提供训练和安全意见，反对把竞技变成失控试验。 |
| 西尔维娅 | 关注受伤拳手与异常者的待遇。 |
| 邢九重 | 说明进入陵寝层的现实风险与施工条件。 |
| 郁垒 | 面对自己过去被筛选的经历，可与参赛者交换有限信息。 |

## 各方冲突

拳手求名，组织要利益，研究采购要可用数据。闵三元查的是义胜盟交出的押金，杨振邦管的是赛事收支，不合并成同一个人。

## 结果与下一话

主角可参赛、协助赛事或查数据交易。输了比赛仍可用其他行动争取邢九重协助；不拿旧谭渊的半模因化强加给纪小刀。

第三章反派已经通过设备与行为研究影响各话。各人的选择进入第十二话机甲事故，而不是所有人只为终章打架。
