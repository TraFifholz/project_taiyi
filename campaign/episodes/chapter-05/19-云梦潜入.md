# 第 19 话 · 云梦潜入

> 2026-09-03 重整｜现行大纲。这里是故事梗概，不替玩家预定行动。

风格：有限接入与家庭重逢。主要组织：云梦科技、ARP、资办。

## 梗概

主角沿已保住的通路进入朱蘅所处的镜像空间。郜白担心接入扩大危险，翟明珠与凌渡维护退出条件，许承钧只能使用实际送达的设备和取得的数据。安保对抗来自真实的岗位分歧，不另设被第十六话杀死后复活的数字工程师。

三个记忆线索帮助核对朱蘅是否是仍有连续经历的本人：她在 2021 年抱过婴儿阿瑶的记忆、与许承钧组成家庭的经历、后来选择与启示录合作的理由。它们不是必须依序收齐才开门的三把钥匙。主角可交叉核对、跳过不愿窥看的私人记忆，或改用本人能够回答的问题。

这才是母女与夫妻有条件进行完整对话的地方。朱蘅既解释自己的囚禁，也面对协助夺取设施的责任。她不宣布三种未来都对自己有利，更不能替阿瑶决定。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 朱蘅 | 说明亲历、误判与实际行动，争取退出锚定。 |
| 朱瑶光 | 追问父母与自己失去的生活，表达当前意愿。 |
| 许承钧 | 承认隐瞒与维护责任，给出可检验的过渡读数。 |
| 沈漫 | 核对旧友经历，决定怎样帮助而不掩盖伤害。 |
| 郜白 | 要求接入受控，可谈判也可能阻止危险操作。 |
| 翟明珠 | 以实际维护片段核对连接，不让公司口径替代事实。 |
| 凌渡 | 测试退出和备用连接，记录无法保证的部分。 |

## 各方冲突

亲情、技术责任和城市风险同时存在。郑启明与萧烬的压力只能来自前文仍保有的实际人手、设备或权限，不凭空把他们送到客厅。

其他参与者：红皇后只能提供此前验证过的接口说明，不掌握一把能够覆盖所有隔离层的钥匙。

## 结果与下一话

公开城市过渡窗口、阿瑶身体稳定性与主角生命绑定三组检查结果。绑定未解除时须维持持续连接并告知风险，不因选择某一阵营自动解除或致死。私人和解不是推进机制的必要条件。

第二十话在已知条件下行动。朱蘅的肉身不会自动复生。若本人同意，先保持原锚定反馈，测试 ARP 现有隔离设备的承载与小范围连续迁移、回接能力：须能稳定交谈、保留连续记忆，并实测受控退出与重连；复制出的文件不算她获救。预检通过后，仍需在第二十话先使抑制设备接管谐振，才开始过渡计时并完成本人迁移；成功时她可暂留有持续供能的承载会话，由她决定继续、暂停或退出。未通过时先维持原连接、补测或明确告知解除后会消散，不能以假定成功代替她的决定。
