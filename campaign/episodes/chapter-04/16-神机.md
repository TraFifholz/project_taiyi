# 第 16 话 · 神机

> 2026-09-03 重整｜第四章结算。这里是故事梗概，不替玩家预定行动。

风格：深层恐怖与被困者的反抗。主要组织：云梦科技、21-35联合研究所、ARP。

## 梗概

此前接入事故、旧研究与维护片段指向纪崇吾。2000 年他把自己接进控制与协议转换层，此后三十年无法退出；2027 年侵入的模因放大了他的痛苦与控制欲。他开始扣留相连会话中的维护者，要求后来人留下补好系统。

郜白划定现实侧安全边界，翟明珠和凌渡维持有限连接，文小篆负责现有隔离设备。许承钧要检验退出条件，朱蘅只能从自己的维护范围提供短片段。主角进入的是受限区域，不是随意操纵全城的后台。

神机保有纪崇吾的一部分人格，也正在伤害别人。理解其遭遇与阻止其扩张必须同时进行，不能以讲一段女儿近况强制他自杀来结束战斗。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 纪崇吾 | 争取离开，又试图扣住别人替自己修补。 |
| 郜白 | 守住安防边界，防止救援扩大失控区。 |
| 翟明珠 | 保留真实维护片段，支持有限而可核验的操作。 |
| 凌渡 | 维持连接与退出通道，不能用一句话保证全员安全。 |
| 文小篆 | 守现有隔离装置，保护里面与外面的工作人员。 |
| 许承钧 | 检验人类意识退出的工程条件，反对换一个人永久困住。 |
| 朱蘅 | 提供自己能接触的片段，仍受锚定岗位限制。 |

## 各方冲突

安防要隔离、研究要资料、被困者要离开。三个组织共同工作不代表他们对可接受的损失看法相同。

## 结果与下一话

剥离、隔离、终止失控区或切断扩张均可尝试。不同办法影响资料完整度、维护成本与纪崇吾存续。获得的是有限深层通路，不是 TAIYI 全权限；朱蘅仍不能自由离开。

若保住连接，第十七话据此安排现实进入；若已切断，第十七话先由工程队核对物理入口、修复受控连接，再取得基准采样。无法恢复时不能宣称深层方案仍可照常实施，须转向现有连接上的维护与疏散。身体稳定检查仍可在现实侧进行。纪崇吾没有自动结束献祭，也不会在第十九话作为另一位安保官复活。
