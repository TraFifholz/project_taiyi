# 第 14 话 · 启示录方舟

> 2026-09-03 重整｜现行大纲。这里是故事梗概，不替玩家预定行动。

风格：避难生活与政治分歧。主要组织：启示录、飞廉速运、玄盾国际、阿奎拉家族物流。

## 梗概

物资流向和居民的主动迁居把众人带到方舟。这里确实有食物、床位和正在相互照顾的人，也有人不知道领袖准备推动更大危机。萧烬要守住避难所，同时利用朱蘅给出的有限维护信息计划夺取设施。朱蘅把丈夫暂停危险试验误认为再次拖延，经萧烬合法接触的低权限外包接口提供一次维护安排，希望施压；她明知工作人员可能受伤。

货物在地面与弃置层中转点交接，再由方舟成员搬入地下避难所，普通物流人员不因此进入深层维护区。单小鹿和田进财核对自己送过的东西，宋远拒绝让运输变成人口交易。玄盾巡逻接近时，夏满弓想确认武装风险，伊莱恩的报告可能让上级只看见武装成员而看不见居民。苏晦试图劝阻学生，朱蘅也不愿合作被扩展成无边界伤害。

本话冲突来自有限资源、相互恐惧和真实的夺取计划，不使用安保队长一言不合炸死全体居民的固定机关。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 萧烬 | 争取让方舟保有独立性，准备借危机扩大自己的方案。 |
| 田进财 | 对照街面送货与入住者情况，不替组织决定所有骑手参战。 |
| 单小鹿 | 说明自己实际调度的物资，决定是否继续提供运力。 |
| 宋远 | 坚持不运输被迫迁居的人，与萧烬产生交易分歧。 |
| 夏满弓 | 调查眼前武装与居民处境，可谈巡逻方式与临时停火。 |
| 伊莱恩·莫罗 | 决定向上级呈报哪些真实部分，影响但不直接指挥行动。 |
| 苏晦 | 反对学生把救助变成推动灾变的理由。 |
| 萨布里娜·费雷拉 | 帮助居民表达是否自愿迁居，协调现实安置。 |

## 各方冲突

四组织为物流、避难与巡逻所需。银行的何凌和陈志远在外侧核对招募与资助，白鸢可争取调整辖区行动；各自只影响所掌握的事。

其他参与者：沈漫通过现有互助关系接触迁居者，核对他们是否受到强迫。朱蘅只以有限维护片段影响萧烬，尚不能在方舟召开一次完整的家庭谈话。

## 结果与下一话

告发、帮助迁居、制止夺取设施或分开安置都可成立。保全方舟居民不等于认可萧烬的计划；拒绝加入也不自动使居民成为敌人。

朱蘅在本话承担协助夺取设施的责任。维护争夺使许承钧、云梦与卜府不得不正面回应；言璞的公馆邀请不是下一话唯一的开场方式。
