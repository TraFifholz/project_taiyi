# 第四话新增 C 场：断香与血账

这是一份全新的义胜盟场景稿，用于替换原有的“守卫赌场-反攻车场”线性流程。本稿将义胜盟作为一个有自己规矩、生意和内部矛盾的活体势力展开。玩家不再是单纯来“领装备”，而是卷入了一场关乎黑道道义与生存的堂口危机，并在血火中赢下这支生力军。

## 场景 C：断香与血账

**场景起因**：方泰安利用义胜盟的地下灰色物流网络处理了失踪服务的“耗材”，如今他要赖掉尾款，并把经手过此事的蓝衣（外围小弟）全部物理清理。玩家寻找卫铁生时，义胜盟内部正因为“是否要和官方背景的方泰安开战”而处于分裂边缘。

**地点**：黄区“义字头”复古茶楼地下——白虎堂的灰产物流枢纽。这里不仅是堂口，更是一个连接着地下管道的非法神经接口交易与走私集散地，充满霓虹灯、茶香和机油味。

**出场 NPC**：
- **卫铁生（白虎堂红衣）**：主战。他的几个蓝衣小弟被方的私兵杀了，他绝不接受销账。
- **闵三元（总舵账房）**：主和。认为方泰安代表管委会权力，帮派不该为了几个外围去撞铁板，主张切断物流线，咽下这口血亏。
- **柳拂衣（剑阁执行者）**：盟主派来的中立监视者。觉醒者，手持数据刀，负责维持“讲数”的规矩，确保内部分歧不用枪解决。

**正在发生的事（玩家入场）**：
茶楼地下的关公像前，香炉里的香只烧了一半。卫铁生和闵三元正在进行“讲数”（江湖谈判）。周围站满了紧张的红衣帮众，柳拂衣安静地坐在太师椅上擦刀。闵三元将一叠物流账单扔进火盆，宣布这笔账“断香”（作废）。卫铁生一拳砸碎了茶桌，按规矩提出“过手”（无枪械决斗）来夺回行动决定权。

**场景推进与变数**：

- **第一段：堂口讲数与破局**。玩家带着对付方泰安的决心步入这场剑拔弩张的谈判。玩家可以选择直接代替卫铁生下场“过手”（与柳拂衣或闵三元的高级打手进行一场限制级肉搏/骇入决斗）；也可以直接拍出从 A 场或 B 场拿到的情报（证明方泰安已经失去官方庇护，现在只是一条疯狗）。无论是用江湖规矩打赢，还是用情报说服，玩家都在介入帮派的政治。
- **第二段：烈火破门**。就在局势即将倒向卫铁生时，方的私兵（可能是玄盾的黑活小队或没标识的重装雇佣兵）根本没打算等他们谈完。两辆装甲厢车直接撞穿了地下枢纽的薄弱墙体。雇佣兵没有警告，直接投掷高精度白磷燃烧弹。他们的目标不是杀某个具体的人，而是烧毁整个物流中心、物理服务器和所有的知情者。
- **第三段：火海护堂**。战斗在燃烧的赛博茶楼中爆发。这不再是简单的掩体射击，环境在崩塌，浓烟阻挡视线。
  - **救人与救账**：玩家需要在火海中掩护帮众撤离，同时协助柳拂衣切断或抢出存放着方泰安犯罪走私记录的物理服务器。
  - **剑阁的锋芒**：柳拂衣展现出觉醒能力（例如局部数据屏蔽或信息流具象化斩击），玩家可以配合她对抗敌方的重火力和机械猎犬。这是玩家首次直观看到“剑阁”清理麻烦的手段。
- **第四段：以牙还牙（反推装甲车）**。敌方发现强攻受挫，留下一地燃烧弹试图乘坐装甲厢车撤退。卫铁生红了眼，拒绝让他们跑掉。玩家与卫铁生、柳拂衣一起冲出火海，直接跳上或骇停敌方的装甲车，在地下隧道的出口处将这支灭口小队彻底全歼。

**战果与结算**：
- **血账结清**：看着满地狼藉和死去的敌人，闵三元不再阻拦。卫铁生正式接管了堂口的武装调动权。
- **实打实的资源**：玩家不仅缴获了敌人的一辆重型装甲厢车，卫铁生还点齐了两组全副武装的红衣精锐（不再是简单的后勤协助，而是愿意去拼命的兄弟）。
- **关键证据**：抢出的地下物流服务器记录，补齐了方泰安利用灰产运输受害者的证据链。
- **江湖人情**：柳拂衣对玩家的实力表示认可。她留下了一句“剑阁记下各位的规矩了”，为后续章节的帮派剧情（如第五话）埋下伏笔。

## 简评（致 Codex 与 GM）

**新 C 场对跑团走向的改变**：
1. **势力质感**：不再把义胜盟当成一个发放装备的“提款机”。通过“断香”、内部分歧和剑阁的引入，展示了龙散市黑道的规矩、生意与底线。
2. **连接主线**：方泰安抹除地下物流线，逻辑上比单纯袭击堂口更紧密地扣住了“销毁失踪服务证据”的主轴。
3. **战斗体验**：引入了火场救援、保护数据和反制装甲车的复合目标，避免了与 D 场（灾备厅）可能产生的“单纯据点攻坚”体验同质化。
4. **无需强制顺承**：如果队伍已经有了足够的火力和盟友跳过 C 场，义胜盟内部的这场火并仍会在暗中发生。卫铁生可能会在 D 场外围带着残兵加入，或者在余波中成为玩家的新联系人。柳拂衣和纪小刀的登场也自然而不突兀。
