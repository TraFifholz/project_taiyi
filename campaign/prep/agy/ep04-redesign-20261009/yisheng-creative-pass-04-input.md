# 第四话：义胜盟的新创作

接着刚才的整话场景稿。用户的新反馈比旧 C 场任务优先，请把它当作创作方向的调整。

## 用户原话

用户此前也强调：场景内的事情比场景间的连接重要；别消耗额度询问临场很可能改掉的小事。Codex 负责辨认真正影响走向的要点，你负责大胆写新的、有劲的内容。创意优先，下面的材料不是铁则。

## 这轮请直接创作

上一稿 C 还是堂口遇袭、反攻车场、领装备的旧内容。这轮不要以修好这个顺序为任务。请把义胜盟当作正在办自己的事、与别人争夺东西的势力，为第四话写一段有实质篇幅的新故事。

你可以新增人物、矛盾、事件和场面，也可以重新使用现有人物。写出他们为什么此刻行动、彼此有什么不一致、玩家入场后能动手改变什么。让人记得住他们的生意、规矩和人情，也能在这里经历一件有分量的事。场景要有局面变化、对手的行动与玩家的机会。交易、争斗、仪式、城市生活、违法生意都可用；不用围绕既有堂口和车场打转，也不必把每个场景都写成枪战。

选一个你觉得最有意思的主意，充分展开成能跑的内容。不要只给选项菜单、创意点子或设定百科。你可以增加不直接服务于扳倒方泰安的内容；Codex 会判断如何放进本话。篇幅以写好它为准，约 2000—3000 汉字即可，不要堆多套备选。

用户没有要求替他们选定每个演法。直接选好用的默认写法；GM 临场可换。只有真缺了一个影响本话走向的作者取舍才提出问题。材料已有的内容由 Codex 查答，未知现状就标未知；你仍可以提出未来创作，不用因未知而停笔。

## 有用的既有材料

- 义胜盟是武侠与香港古惑仔混合的现代黑道。保护费、赌场、高利贷、娱乐洗钱、灰色物流都是它的生意，也有老城区居民靠它的管线和运输过日子。宣称不碰硬毒品与人口贩卖，仍经营入梦贴片等软性精神药物。会讲道义，也会为全盟安全切割危险的兄弟。
- 蓝衣是外围，红衣是正式成员，白衣是分舵主，金衣是盟主。晋级决斗也可比骇入、走私、拿客户。内部公开决斗有见证，不准用枪，败者认罚、胜者收手。关公、拜码头、三十六义胜规、讲古佬都能写成活的场面，不必挨个塞进稿。
- 总舵在故城区青龙堂茶楼。旧城地下有灰色物流，居民未必都有身份码。剑阁是直属盟主的觉醒者单位，专处理江湖之外的威胁。
- **卫铁生**：欲子旧相识，白虎堂在黄区的一个分点负责人，红衣，管十来个蓝衣；不是整个义胜盟的老大。跟欲子合作每次重新结算，无旧欠账。他守谈好的条件，但讲义气也要保住自己与手下。
- **铁手（李铁牙）**：既有堂口执行人，与玩家发生过收费交涉。关心兄弟不被系统甩锅，他并不知道兔子洞全貌。
- **闵三元**：总舵账房，想收回坏账、维持资金，担心新项目失血。不是神通广大的全知情报商。
- **柳拂衣**：剑阁行动者，重承诺，也不愿旧规矩要求自己一味牺牲。**纪小刀**：剑阁预备，想证明自己。二人原本安排后续出场，可提早引入，但明确这是新创作，尚未发生。也可完全不用。
- 后续第五话原有帮派奥运会，围绕地盘、债务和货物；本话可以留下有趣的关系与后果，不必把下一话整个提前演完。
