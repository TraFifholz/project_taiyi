# 写一个义胜盟自己的故事

这是一次独立创作，目标是给跑团第四话增加一段值得亲自参与的新内容。

用户原话：

> 而且我感觉好像现有的内容都是在修补已有的预定。我觉得可以考虑新写更多的内容，尤其是现在义胜盟的部分空白偏多，应该鼓励agy做一些新的创作，而不是做一些简单的修修改改

请直接写一个有开头、变化和可争夺结果的义胜盟故事。选你觉得最好玩的主意，充分展开。义胜盟自己的人要有所求，玩家进来能插手、谈条件、冒险、得罪人或改变结果。允许大胆的新人物、新局面。道具、场地、仪式、玩法由你自由创造。少写设定说明，多写眼前具体的事。完整正文约 2000 汉字，回复中直接给全文。

这次不用阅读旧第四话稿，也不需要调查全仓库。已知世界材料如下，作为种子而非铁则：

- 龙散市，2030 年，赛博都市。义胜盟有香港古惑仔和武侠的味道，经营保护费、赌场、娱乐、高利贷和灰色物流。旧城居民常靠它的运输、非法供电与不要求身份码的生意活着。
- 会讲兄弟道义，也可能为了生意和全盟安全切割自己人。宣称不碰人口贩卖和硬毒品，有入梦贴片等擦边生意。
- 蓝衣外围，红衣正式，白衣分舵主，金衣盟主。晋级能比拳脚、骇入、走私、拿客户。内部公开决斗有见证，不用枪，败者认罚，胜者收手。也有讲古佬、关公像、拜码头。
- 觉醒者归剑阁，专处理异常与大势力威胁。剑阁也是有个人想法的人，不是自动发奖励的上级。
- 卫铁生是玩家欲子的旧相识，黄区白虎堂分点负责人、红衣，十来个蓝衣跟他。守已谈妥的条件，严厉，也保自己和手下。两人与过去的合作没有旧欠账。他可以出场，也可用新人物。
- 闵三元是总舵账房，铁手是堂口执行人；剑阁柳拂衣重承诺又不想一味牺牲，纪小刀想证明自己。这些都是可用素材，没必要全部出场。

第四话另有城市大战机器人与梁文川救场、银行档案室突围、最后扳倒地方恶徒方泰安的地下决战。你写的新故事可以与这些发生关系，也可以有独立的内容与余波。场间连接由 Codex 办，不占你的篇幅。无需替玩家预定接受雇佣或加入帮派。
