# 第四话：现在值得定什么

2026-10-09。主代理依据用户本轮纠正整理。是本轮工作判断，不是临场必须照读的规则。

## 用户原话

> 感觉这些也不关键啊，都可以吧。咱可不要把额度花在讨论这种事情上面。说实话，你在这里规定了这些东西，我临场的时候也可能不照着这个执行的。你思维强度比agy高，它比较有创意，但想得不深。跑团剧本的哪些是影响剧本走向的要点，哪些是现在规定了临场大概率也会被推翻的要素，你得想清楚

## 重要，不等于需要询问用户

先问：换掉这个设计，玩家值得追求的目标、能够改变的局势、得到的信息和后续关系会不会改变？如果不会，就不把它作为下一轮偏好问题。场景的具体玩法仍值得创作，作者给可用方案，GM 随时可以换。

| 现在要做的工作 | 第四话的具体内容 | 处理方式 |
|---|---|---|
| 把走向想清楚 | 方为什么还在反击；玩家如何使他失去地方控制；特工何时由保护转灭口；胜利保留什么、追查断在哪里 | 主代理梳理，以当前作者决定为基线。只有确实缺少、且会改变这些事的取舍才向用户提问 |
| 把场景做出戏 | 机器怎样改变街道与战术；档案室怎样同时抢人、抢资料、开路；义胜盟自己正在争什么、玩家介入后怎样改变局面；终战争夺哪些有价值的东西 | 给 AGY 创作空间。提供具体可用场面，留玩家操作空间，不逐项询问喜好 |
| 留给临场 | 梁是喘着跑还是沉着操作；特工具体招式；陈志远表情、伤势与台词；见面路口；队伍何时汇合；谁先开第一枪 | 不继续访谈，也不预写成必然结果。可以选一个示例演法，现场更换不影响整话 |

若要把陈志远之死用作整话的主要转折，或让它改变后续银行线，才需要另作结构判断。当前问卷只是在预选受害者的演法，用户已说都可以；无需再追问牺牲或吓破胆，也不因他退出就取消已经抢出的材料。

## 第四话的任务

**让玩家亲手结束方泰安制造的地方灾难，保住具体的人与证据，并在共同作战中认识梁；更高层的责任仍未查明。**

当前作者安排见[融合骨架](../../sessions/ep04-融合骨架.md)。它已经回答了方的死亡、特工弃子、梁的幕后位置和不完美胜利，不重复询问。

| 真正影响走向的事 | 本轮采用的判断 | 在场景中怎样体现 |
|---|---|---|
| 玩家为什么现在行动 | 本轮敌方行动稿：方正在清理审计材料、旧帮手和地下现场，保住钱、权与免于追责的机会 | 档案室、帮派与灾备厅都有正在被人抢走或毁掉的东西；不只靠 NPC 催玩家去下一个地点 |
| 玩家怎样从被追杀变为主动 | 打掉具体追杀力量，保住审计材料，取得实际盟友、设备或入口 | 城市大战可以夺走敌方控制与交通；银行、帮派提供不同但可混用的助力。无需先完成全套调查才有资格行动 |
| 银行与帮派的作用 | 银行材料让方的公权力庇护变得难以维持；义胜盟有自己的生意、利益与争端。玩家可在介入后谈成支援，也可留下别种关系与后果 | 帮派故事先有自己值得参与的事。它形成的关系和实际助力可以带进终战与第二章，不把帮派部分只写成领装备的前置步骤 |
| 玩家必须打败的是什么 | 方的私兵、异常设施与本人仍有抵抗能力；撤掉公权力保护不等于胜利 | 玩家可以夺阵地、救援、取证、反击，怎样造成败局跟实际行动走，不要求某个预写招式 |
| 特工灭口为什么成立 | 他前段在维护方的可用价值；玩家造成不可挽回的败局后，他切断活口向上追问的可能 | 保护转灭口回应方的败局，不用另一名 NPC 代替玩家打败方。具体发生在哪一处由战斗局势决定 |
| 第一章要给出什么答案 | 能具体确认方对旧案与失踪服务的责任；白念秋等受害者的遭遇获得真实印证 | 内容放在可救的人、可夺的原件与现场操作中。资料事先有内容，不在玩家拿到后写成全空白 |
| 第一章要留下什么缺口 | 方经手的上游接触与交易秘密随其断线；特工成为记住的新敌人 | 已获本地证据继续有效；不以一个上游地址在谢幕后马上开下一场追杀 |
| 梁与第二章的关系 | 本话帮助是真的，采购责任不向 PC 公开；玩家看见他愿意冒险、重视保住记录与失去的人 | 城市战救场与灾备厅协作都提供可相处的经历，不预写玩家必然信任，也不把技术职位变成犯罪自白 |
| 玩家的行动要留下什么 | 救出的人、保住的意识残留、带出的记录、夺取或拆毁的设施与实际资源 | 这些状态带进余波及第二章；结尾灭口不清空成果。陈培安恢复多少联系取决于救援，不自动肉身复活 |

上表中的敌方清理动作是本轮准备，不是 S13 已发生的事实。来源分别为[方](../../../npcs/stories/方泰安.md)、[梁](../../../npcs/stories/梁文川.md)、[陈培安](../../../npcs/stories/陈培安.md)和[既有流程](../../sessions/ep03尾声-ep04-流程与事件卡.md)。

## 留给创作的空间

现状接续仍用 [S13](../../../../records/memory/session-13.md)。何凌的判断不是终局承诺；第二批 PMC 的雇主未点名，不把实跑中未知的雇佣关系补成已查明。此类资料边界说明故事目前有什么，不限制提出未来场景。

A 的价值是连续城市作战与梁救场；B 是带劲的档案室突围；义胜盟部分按用户最新反馈重新创作，旧 C 的堂口保卫与抢车场不再作为任务范围；D 兑现复仇、救援、保全与弃子。顺序可以换，方法可以换。重点准备场景中的人正在做什么、玩家能改变什么，以及留下什么结果。

这轮不再把梁的脆弱程度、特工的闪现或防御、陈志远的预设死法发回用户选择。交给 AGY 作一份有创意的场景稿，由主代理检查它是否支撑上述任务，而不是再次生成问卷。

## 新增内容的方向

用户后续原话：

> 而且我感觉好像现有的内容都是在修补已有的预定。我觉得可以考虑新写更多的内容，尤其是现在义胜盟的部分空白偏多，应该鼓励agy做一些新的创作，而不是做一些简单的修修改改

整话初稿已保存为[第三轮 AGY 场景原文](creative-pass-03-AGY场景原文.md)。其义胜盟段仍沿用旧 C，不能靠润色解决内容空白。另发[义胜盟集中创作任务](yisheng-creative-pass-04-input.md)，允许新人物、新事件与不直接服务于击败方的内容。

主代理审核新增内容时看三件事：场内争夺是否具体而有趣；玩家的行动是否能改变结果；新增关系与后果能否继续生长。道具、规矩、动作和见面地点都可以换。这里没有要求 AGY 只能补原来四场的空格，也不为所有新设定另开一轮批准问卷。
