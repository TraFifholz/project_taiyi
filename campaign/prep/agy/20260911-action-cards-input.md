# 第三话收尾与第四话：事件设计

用户最新要求：

规划第三结束+第四话的内容：
1、大纲已定，核心结构成为不可变的龙骨（细节可以微调）
2、一条原则：只有利益和武力可以说服别人。坏人不会被一次所谓的合规调查给逼到绝境。犯罪事实只能劝阻官方不出手保护体系内的恶人，但他依然可以用自己其他的关系自救。
3、方泰安是穷凶极恶之徒，与暴力神秘组织有合作，自身也是觉醒者。
4、不知道怎么办的时候就打，调查和交涉永远没有打架重要。暴走机械、神秘超人组织、黑帮……打就完事了
请你按照以上原则进行设计，重点是设计故事流程和场景卡。这里的场景卡【不是指镜头/CG/一次聊天/翻房间的调查】，而是一段连贯的、在游戏中大约持续数个小时的事件——比如PMC设局袭击欲子/管委会利用权限围捕李好……只是单纯的什么，何凌与李好碰头啦、梁文川遇到欲子啦，这种发展几句话就能概括！核心就是怎么见的、哪里见的、要说什么，这就是全部。
刺激的事件不知道怎么触发的就不写触发原因！不需要有那么多逻辑，事情就是会有很多巧合，很突然。我们可以有深层原因，但不需要有直接原因。
最后就是：现在已经出场的NPC，整理一下。万一玩家想找他们，写一张反应表。
总之就是狂野一点！这个狂野一点的意思不是指你写一堆没头没尾、没有逻辑的话，也不是把场景或者环境塑造的很狂野，而是故事要在满足框架的基础上，放弃以那些合规/调查/锁定真相/面馆监控与旧账怎样对应之类的细节，而是直击关键。比如何凌要吐露的真相，关键不是面馆监控与旧账怎样对应，而是这里究竟是有什么黑料，指向谁！

请你专注故事流程与4—5张事件卡的创作，主会话另外核对S1—S12已出场NPC并整理反应表。不是让你在一次聊天上套一个场景标题：每卡应是一场2—4小时连续事件，里面有推进、变局、敌人的行动与可打出的战果。短碰头用几句带过。不需要大量规则数值或新造管理流程。你可自由创作，用工具查阅背景。
