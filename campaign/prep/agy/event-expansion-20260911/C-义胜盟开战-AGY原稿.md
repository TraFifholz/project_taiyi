## 事件前五项
1. 传言黄区的几个地下赌场最近突然关门歇业，说是惹上了不能惹的大老板。
2. 卫铁生正因为一笔迟迟未结的“清退尾账”在堂口发脾气，手下人都躲得远远的。
3. 如果玩家在此前未能修复车辆，他们抵达堂口时只能步行或搭乘不可靠的黑车。
4. 铁手带着阿三和阿七刚完成一票小买卖，正在堂口后厨分钱。
5. 若玩家从其他渠道提前打听到袭击计划，可在厢车撞门前三分钟进行一次短暂的战术布置。

## C｜义胜盟开战

**概览**
本场事件围绕一场突发的黑吃黑灭口行动展开。方为了掩盖过去的肮脏交易，雇佣私兵清剿义胜盟堂口，连人带账本一并销毁。玩家将在这场突袭中与帮派结盟，从被动防守转为主动出击，最终拿下敌方的车场，将下一场（进攻灾备厅）所需的重火力、载具与人力支援掌握在自己手中。整个事件预计持续2至3小时游戏内时间，战斗烈度高，地形互动丰富。

**上桌就发生**
不需要冗长的寒暄和新场景介绍。当玩家通过铁手或周凛的线索找到义胜盟位于黄区那栋破旧的三层堂口建筑时，刚推开门或者刚和接头人说上半句话，暴力就直接降临。
一辆经过粗糙加固的厢式货车轰鸣着撞碎了门厅的玻璃卷帘门，半个车身卡在屋子里。车厢门猛然踹开，枪手们跳下车，端起自动武器对着二楼的回廊就是一通无差别扫射。木屑、水泥碎块和惨叫声瞬间填满空间。
在二楼，义胜盟的老大卫铁生没有坐以待毙，他抄起一把霰弹枪，正借助楼梯拐角的掩体向下压制门厅。而在一楼后方，铁手正护着阿三、阿七和几个堂口小弟，试图从狭窄的后门通道撤离。

**第一阶段：抢住堂口**
敌方首发兵力：6名受雇的私人枪手（装备轻型防弹衣、突击步枪）、1名部署在门外街道或皮卡车厢里的重火力手（操控通用机枪，覆盖堂口正面）、2辆突击车（一辆撞入门厅，一辆在外接应）。

战术环境与敌人变招：
- **纵火逼退**：枪手小队受过专业训练，他们不会在一楼死磕。发现卫铁生在二楼反击后，两人会点燃停在门厅和一楼通道里的废弃摩托车与杂物。刺鼻的黑烟迅速向上蔓延，逼迫楼上的人必须在窒息前突围下来。
- **封锁后门**：两名枪手已经绕到了建筑后巷，试图用交叉火力堵死后门，把铁手等人困在死胡同里。
- **重火力压制**：外面的机枪手将任何敢于靠近正门破洞的人压制在掩体后，形成火力封锁区。

玩家介入与选择：
玩家可以选择多种方式破局，无需遵循单一战术。
- **解围后巷**：打通后门，救下铁手。铁手获救后不会发呆，他会听从玩家的简短指令（如“守住楼梯口”或“去切断外面的机枪手”），带着剩下的小弟执行，为玩家分担一路压力。
- **侧翼包抄**：从建筑内部的通风管道或破坏墙壁绕到厢车背面，近战解决一楼的枪手。
- **制高点反制**：技术型或敏捷型角色可以翻窗跳向隔壁楼栋的防火梯，从上方对外部的机枪手进行精准狙击或投掷爆炸物。
- **正面强突**：如果是重装路线，可以直接顶着火力冲进门厅，与二楼的卫铁生形成上下夹击，快速绞杀室内的敌人。

**第二阶段：敌方弃卒与情报获取**
随着室内枪手被清理或伤亡过半，带队的雇佣兵领队意识到硬啃会赔本。他不会死战到底，而是果断抛下还在室内缠斗的几名手下，提着装满酬金的钱箱，跳上外面那辆未受损的接应突击车，一脚油门向着几个街区外的临时车场据点撤退。

留下来的枪手发现自己被卖了，且尾款无望，士气会立刻崩溃。
- 如果玩家将枪管顶在他们的脑门上，或者承诺给一条活路并允许带走重伤的同伴，他们会毫不犹豫地出卖领队，直接报出车场的具体位置和内部防御布置。
- 如果玩家选择全部击毙，在撞入门厅的厢车导航仪里，或者死者身上的战术终端中，也能直接提取到车场的GPS定位。不需要进行繁琐的密码破解判定，拿到定位就直接推进。

此时，卫铁生从楼上走下来，虽然挂彩但眼神凶狠。他拍出那本藏在暗格里的“清退尾账”——上面清清楚楚记录了方如何利用职权和黑金雇佣他们干脏活，以及现在打算杀人灭口的账目流水。这份黑料足以在后续让官方切断对方的公权力保护网。

**第三阶段：反攻车场**
车场位于一片废弃的工业区内，周围是用波纹钢板和铁丝网围起的院子。
敌方剩余兵力：车场内有4名看守（装备散弹枪和冲锋枪）、1台原本用于搬运货物的工业装卸重机（被改装成了临时防线）、此前撤回的领队（守在二楼调度室），以及停在车库里的一辆装甲运输车。

战术环境与潜入/突击路线：
- **正门强攻**：驾驶刚缴获的厢车或其他载具，直接撞开铁丝网大门，强行突入院子。
- **高空压制**：爬上车场旁边的废弃冷却塔或厂房水管，到达屋顶。从天窗或边缘对院子内的看守进行居高临下的射击，压制调度室。
- **地沟潜行**：通过工业区的排水沟，可以避开外围视野，直接摸到车库底部的维修地坑，从敌人脚下发起突袭。

重机变招与互动：
一旦战斗爆发，看守会立刻启动装卸重机。这台庞然大物没有挂载远程武器，但它会挥舞粗壮的机械臂，将院子里的废旧轿车像炮弹一样扫向玩家，或者直接迈着沉重的液压腿试图踩扁掩体。
- 玩家可以使用重火力或破甲武器打断其脆弱的液压关节（拆腿）。
- 敏捷型PC可以借助地形跳上机甲背部，击毙或揪出驾驶员，夺取控制权。
- 技术型PC可以黑入其未加密的工业控制模块。
- 夺取机甲后，玩家可以驾驶它直接撞烂车库厚重的卷帘门，甚至用机械臂将躲在调度室的领队连人带墙一起扯下来。

**第四阶段：在战利品旁定合作**
战斗结束后，领队的尸体旁散落着那个钱箱，里面装着方预付的 ¥60,000 现款。车库里停放着一辆完好的装甲运输车（或一套可拆卸的重型武器系统），以及若干弹药补给。

卫铁生带着包扎好的弟兄赶到现场。他现在急需这笔钱来安抚死伤的兄弟和填补堂口的窟窿，同时他也看到了方必须要死，否则义胜盟永无宁日。而玩家需要的是通往灾备厅的通道，以及能替自己吸引火力的炮灰。
- **成交条件**：玩家只需将钱箱分出 ¥30,000 给卫铁生，或者承诺打下灾备厅后这座车场连同剩余装备归义胜盟所有，即可达成同盟。剩下的 ¥30,000 战利品由玩家自由支配。
- **战力兑现**：作为回报，卫铁生会指派两组敢打敢拼的帮派成员（由铁手或阿三带队）归玩家指挥。玩家可以把他们安排为进攻灾备厅时的外围佯攻、撤退时的接应车队，或者直接跟着装甲车一起冲锋。

**衔接与延续**
- 如果玩家在前面的环节（B）已经抓住了方的把柄或导致其受损，本场的账本将作为决定性证据，彻底剥夺方呼叫官方增援的权限。
- 若玩家未能在本场夺下车场并全歼守军，那些存活的私兵和未损坏的装甲车，将有可能在终局（D）中作为外围游动哨或增援部队出现。
- 战斗中夺取的车辆、重武器、伤势和弹药消耗将直接带入下一场。

## 事件后五项
1. 卫铁生安排手下连夜清理堂口的尸体和血迹，并把账本的复印件交给了玩家。
2. 逃跑的雇佣兵领队如果存活，会立刻关闭通讯终端并逃离这座城市，不再为方卖命。
3. 如果玩家将装卸重机破坏得太彻底，他们只能从废墟中搜刮出几件防弹插板作为补偿。
4. 铁手对玩家的战斗力表示钦佩，并在接下来的行动中自告奋勇担任向导。
5. 若玩家选择独吞全部六万现金不给帮派留活路，卫铁生会带人冷眼撤离，不再提供任何后续支援。
