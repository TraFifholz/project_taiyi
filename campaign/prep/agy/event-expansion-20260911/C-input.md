## C｜义胜盟开战

**这场在干什么：** 方想把旧帮手连人带账清掉。玩家与帮派共同打退来人，再端掉对方车场，把下一场的重火力抢到自己手里。

**上桌就发生：** 玩家经铁手或周凛找到堂口时，一辆厢车冲进门厅，枪手向楼上扫射。也可以在双方谈合作的半句话之间开打。地点用既有黄区堂口，不另花半小时介绍新赌场。

**敌人与盟友：** 六名私人枪手、一名重火力手、两辆突击车；车场内还有四名看守与一台装卸重机。铁手正把阿三、阿七和堂口的人往后门带；卫铁生亲自在楼上压住门厅，不等着玩家从椅子上救他。

**连续推进：**

1. **抢住堂口。** 枪手先堵后门，再点燃停放车辆，逼楼上的人下来。玩家可以清后门、绕到厢车背面、从隔壁楼压制机枪手，或直接冲门厅与卫铁生夹击。铁手受命后会带一组人执行玩家安排，不抢走全部战斗。
2. **对方扔下自己人撤。** 领队带着钱箱和接应车辆退向附近车场。留下的枪手发现拿不到尾款，不想继续卖命。给退路、允许他们带走伤员，或把枪顶到领队面前，都能换来车场位置。搜车也直接有导航，不跑密码链。
3. **反攻车场。** 车场有装甲车、弹药和方付给私兵的现款。正门能开车撞；屋顶能压住院子；排水沟能摸到维修坑。看守启动装卸重机甩车砸人，玩家能拆腿、夺驾驶位，或让其替自己冲破车库门。车辆开到手就能带走，不把每台车做成一轮单独搜索。
4. **在战利品旁定合作。** 卫铁生要欠款和堂口活路，玩家要通道与人手。给他一份缴获现款、重装备共同使用，或承诺攻下后由帮派接收车场，都能成交。他派两组人，由玩家安排佯攻、接应或突击。

**直接黑料：** 堂口留着方欠下的清退尾账；来袭领队知道是方出钱清场。结合 B 的抓人，官方看见的是方把职权与私兵用来灭口。材料的作用是削掉他的保护，不让他在电话里被处分后原地缴械。
