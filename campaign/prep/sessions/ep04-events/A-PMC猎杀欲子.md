# A｜PMC猎杀欲子

> 独立 AGY 扩写，主会话已核对衔接与前后事项；[主持衔接页](README.md)｜[AGY 原稿](../../agy/event-expansion-20260911/A-PMC猎杀欲子-AGY原稿.md)。

## 事件前五项

1. 【传言】街头有人出高价打听欲子的落脚处，但接活的人说不清雇主在哪一层公司里。
2. 第三话剩余休整已补结，队伍带入实际治疗结果与现有装备。
3. 按约应补结的 ¥34,830 尾款在尾声处理，已经到账的钱不会被本场重新扣住。
4. 梁文川正从附近经过准备回家，此时仍只是欲子认识的夜宵摊熟人。
5. 三名拿钱带路的混混守着一条步道出口，开始后悔接了这票有机械猎犬随行的活。

**这场在干什么：** 对方要取欲子的命，玩家要打掉咬住她的队伍。梁的重逢发生在这个事件里，占几分钟，不单列一场。这是一场典型的遭遇战反打，玩家从被动接敌到主动撕裂包围圈，并在连续的战斗中收获关键盟友与物资。

## 场景概述与触发机制
**触发时机：** 上桌即发生。第三话结束后，玩家带着欲子离开落脚处（若旧SUV已坏且未弄到新车，则发生步行街口或停车楼；若已有车，则发生在驶出街区的第一条主干道）。
**基本环境：** 一条正在进行管线改造的狭窄街道。一侧是两层楼高的连排旧商铺，另一侧是连绵数十米的施工围挡，围挡后是堆满水泥管和脚手架的工地。
**敌方编组：** 
- **步战组：** 两组各三人的外包枪手（携带突击步枪，穿戴轻型防弹衣；带队头目包含在这六人里）。
- **特种单位：** 两台机械猎犬（四足仿生，装备高频切割颚与液压扑击腿），一台重型自走机（双足/履带底盘，前部重装甲，挂载区域压制火炮）。
- **指挥节点：** 一名位于装甲指挥车内的操控员。操控员兼任驾驶，六名枪手中的第二组负责护车，不能在后半场另补三名新枪手。
- **外围杂鱼：** 三名持土制枪械与铁棍的街头混混。

## 连续推进

### 1. 拆开伏击
玩家队伍刚刚进入狭窄路段，一辆无牌厢式货车突然从前方辅路倒车横停，死死卡住车道。与此同时，路边施工围挡的预留孔洞里伸出三支黑洞洞的枪管，第一组枪手直接开始交叉扫射，试图将玩家压制在路中央。从队伍后方，两台机械猎犬凭借极高的爆发力冲向玩家车辆的轮胎或队尾成员。而那三名混混则在远处的一条退路巷口探头探脑，随时准备敲闷棍。

**战术与破局：**
- **正面硬刚：** 玩家驾驶重型车辆直接撞开横停的厢车（需要驾驶检定及车辆强度支撑），或者重火力强行压制围挡后的枪手。
- **侧翼反打：** 钻入两侧的旧商铺二楼抢占高位，压制工地里的枪手；或直接冲毁围挡，进入建筑工地利用复杂掩体（水泥管、土堆）与枪手近战。
- **瘫痪协同：** 机械猎犬由指挥车实时微调战术。如果玩家通过电磁手雷、骇入手段干扰，或者直接干掉/逼退了负责协调的操控员，两台猎犬将失去协同能力，降级为本能模式——它们各自追逐最后锁定的目标；玩家可以利用遮挡、诱饵或接口改写制造反咬的机会。
- **混混溃散：** 巷口的混混只是拿钱办事，一旦看到玩家动用重火力、或者外包枪手出现伤亡，他们会立刻丢下路障逃跑，不会死战。

### 2. 换一个战场
如果玩家突破了第一层伏击圈（无论是撞开路障还是穿过工地），战场将顺势转移至相邻的废弃露天停车场或半拆迁街区。这里掩体众多，但视野开阔。
此时，外包队发现常规火力无法啃下这块硬骨头，幸存的枪手开始向一辆停在街区尽头的重装指挥车方向退却。伴随着砖墙倒塌和汽车被碾碎的巨响，一台重型自走机被投入战场。它犹如一座移动的金属碉堡，毫不顾忌地撞穿废弃车辆。

**敌方变招：**
- 幸存的枪手改变战术，不再主动露头，而是将自走机当作移动的防弹盾牌，跟在机器后方缓慢推进。
- 自走机不具备极速追击能力，但火力骇人。开火前，其光电探测头会射出明显的红色激光引导线，锁定一片区域几秒钟，随后重武器（如多管机枪或榴弹发射器）将覆盖该区域。玩家有充分的反应时间进行飞扑、翻滚或转移。

**战术与破局：**
- **诱导与破坏：** 玩家可以利用建筑物的承重柱诱导自走机开火，让坍塌的楼板砸毁它；或者集中精确火力击碎它脆弱的顶部光学探测头，使其变成只能盲目开火的瞎子。
- **物理切断：** 胆大的角色可以利用掩体死角贴近自走机，用切割武器破坏其腿部液压件或履带，迫使其瘫痪。
- **系统接管：** 懂得技术的PC可以在队友火力掩护下，冒着枪林弹雨冲到自走机侧面，强行扯开装甲板接入本地维护接口进行底层覆盖。

### 3. 梁出手
在穿过停车场向相邻街道转移的几分钟里，玩家队伍在街角猛然撞见了提着几个零件袋、正准备回家的梁。
无需冗长的寒暄，梁第一眼认出了队伍中的阿玉（欲子），随后立刻注意到了那台正在咆哮开火的重型自走机。他原本疲惫的神态瞬间被极其专注的冷峻所取代。

**干预过程：**
- 梁向玩家大喊请求掩护。他不需要任何密码破译工具，他知道这台机器的物理弱点。只要玩家帮他压制住枪手，他能直接滑铲到自走机视网膜盲区，掏出一根随身的维护接头插入机器底部的紧急维护口。
- 如果技术型PC想要自己动手，梁会快速报出几个内存地址和覆写指令，指导PC完成操作。
- 随着指令输入，自走机的炮塔发出泄气的嘶嘶声，红光熄灭，系统面板弹出绿色的“维护停机权限已通过”，整个钢铁巨兽瞬间死机。没有长篇大论的职位介绍，只有实打实的技术碾压。
- 如果玩家在此之前就已经用暴力摧毁了机器，梁也会上前检查残骸，徒手拔掉尚在转动的炮塔供电线和隐蔽的定位上报模块，同样展现出他对这批硬件的绝对熟悉。不追加新敌人来抹杀玩家的胜利。

**梁的三句话：**
战斗间隙或机器瘫痪后，梁只快速交代三句话，其中第三句在玩家自己谈及找方算账后再说：
1. “这铁疙瘩的底层逻辑我熟，以前给追风的外包项目做过这块的设计。”
2. “这帮人冲谁来的、为啥咬这么紧，咱们脱险了找个安全点细说。”
3. “你们要找方算账？算我一个，那混蛋动过我最看重的原始记录。”
先拿瘫痪机器的人情，再谈共同应对“方”的立场。他绝不交代采购关系，也不装作初次见识异常力量。

### 4. 反过来追
重型自走机一旦宕机，残存的人类枪手士气瞬间崩溃。机器不仅是他们的盾牌，更是他们抗衡觉醒者和重火力的底气。

**敌方溃退与变招：**
- 枪手们开始往脚下投掷烟雾弹，不再试图击杀欲子，而是拼命向街区尽头的指挥车撤退，试图抢回正在车里的操控员并逃离。
- 当枪手伤亡过半，或者指挥车被玩家的重火力堵住去路时，带队的头目会果断举起双手要求谈条件：“我们只是拿钱办事的！放我们走，追杀队驻点的位置和剩下的装备全给你们！”

**战果与选择：**
- **追击与截杀：** 玩家可以抢夺路边的车辆追击指挥车，或者技术PC骇入交通灯强行拦停；也可以直接用火箭筒或炸药把指挥车炸上天，彻底结束这场围猎。
- **收降与情报：** 如果玩家接受谈钱放行，将获得敌方在外围的驻点坐标以及通信记录。这并非让死人复活，买通这一组不代表追风撤销其他委托，这支追杀队按实际谈妥的条件停手。
- **直接撤离：** 如果队伍状态极差或只想脱身，已经打穿包围圈的他们完全可以借着烟雾直接离开。留下的指挥车只能带着幸存的残兵败将灰溜溜地离开，以后若再出现，也只有这几个残兵。

## 战果统计与跨卡延续
- **物资缴获：** 一台可拆用的重型自走机残件（高爆弹药、高级传感探头或动力核心）、一辆夺来的厢车或指挥车（如果未被摧毁）、几把外包枪手的突击步枪及弹药。
- **情报获取：** 指挥车的通信记录将暴露本地追杀部署的网络节点。打掉指挥车会破坏这支队伍的协同与持续定位；已经逃脱的人仍保留亲眼见过的信息，不能瞬间召来同样数量的新兵。
- **快收办法（GM提示）：** 若玩家在第一阶段的伏击战中发挥极其出色（例如一回合内炸毁厢车并全歼枪手），GM可直接省去后续的长距离追逐，将重型自走机和指挥车直接摆在工地后方作为最终决战点。战斗带来的疲惫感通过交火的紧张节奏体现，不强制预扣玩家全部弹药或硬性安排重伤。

## 事件后五项

1. 【传言】若追杀队被打垮，街头会传开有人把追风外包武装连机器一起拆了。
2. 若队伍拿到指挥车通信记录，他们能看见这支外包队的本地部署，但其中没有方的上游关系。
3. 若操控员带着可用指挥车逃脱，后续仍可能出现跟踪，队伍可以根据已见过的车辆反制。
4. 梁愿意在脱险后的短谈里听队伍讲方的事，他展现的权限暂时没有附带职位说明。
5. 若队伍夺走可用车辆、枪支或机器零件，下一张卡直接继承这些战利品。
