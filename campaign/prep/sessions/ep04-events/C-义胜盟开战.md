# C｜义胜盟开战

> 独立 AGY 扩写，主会话已核对衔接与前后事项；[主持衔接页](README.md)｜[AGY 原稿](../../agy/event-expansion-20260911/C-义胜盟开战-AGY原稿.md)。

## 事件前五项

1. 【传言】黄区最近有些堂口关门歇业，街坊猜测是欠账的老板准备翻脸。
2. 卫铁生正在为方拖欠的清退尾款发火，铁手却更关心最近是谁在打听兄弟的去向。
3. 阿三和阿七正在堂口帮忙，旧伤与本轮是否受伤按已经发生的结果处理。
4. 队伍抵达时沿用前面真正保有的车辆和装备，不因换了事件地点就失去交通工具。
5. 若玩家提前察觉来车或布置了外围哨，他们可以在袭击撞进门前抢占位置。

**概览**
本场事件围绕一场突发的黑吃黑灭口行动展开。方为了掩盖过去的肮脏交易，雇佣私兵清剿义胜盟堂口，连人带账本一并销毁。玩家将在这场突袭中与帮派结盟，从被动防守转为主动出击，最终拿下敌方的车场，将下一场（进攻灾备厅）所需的重火力、载具与人力支援掌握在自己手中。整个事件预计占用桌上2至3小时，战斗烈度高，地形互动丰富。

**上桌就发生**
不需要冗长的寒暄和新场景介绍。当玩家通过铁手或周凛的线索找到义胜盟位于黄区那栋破旧的三层堂口建筑时，刚推开门或者刚和接头人说上半句话，暴力就直接降临。
一辆经过粗糙加固的厢式货车轰鸣着撞碎了门厅的玻璃卷帘门，半个车身卡在屋子里。车厢门猛然踹开，枪手们跳下车，端起自动武器对着二楼的回廊就是一通无差别扫射。木屑、水泥碎块和惨叫声瞬间填满空间。
在二楼，义胜盟黄区分舵的卫铁生没有坐以待毙，他抄起一把霰弹枪，正借助楼梯拐角的掩体向下压制门厅。而在一楼后方，铁手正护着阿三、阿七和几个堂口小弟，试图从狭窄的后门通道撤离。

**第一阶段：抢住堂口**
敌方首发兵力：6名受雇的私人枪手（含领队）（装备轻型防弹衣、突击步枪）、1名部署在门外街道或皮卡车厢里的重火力手（操控通用机枪，覆盖堂口正面）、2辆突击车（一辆撞入门厅，一辆在外接应）。

战术环境与敌人变招：
- **纵火逼退**：枪手小队受过专业训练，他们不会在一楼死磕。发现卫铁生在二楼反击后，两人会点燃停在门厅和一楼通道里的废弃摩托车与杂物。刺鼻的黑烟迅速向上蔓延，逼迫楼上的人必须在窒息前突围下来。
- **封锁后门**：两名枪手已经绕到了建筑后巷，试图用交叉火力堵死后门，把铁手等人困在死胡同里。
- **重火力压制**：外面的机枪手将任何敢于靠近正门破洞的人压制在掩体后，形成火力封锁区。

玩家介入与选择：
玩家可以选择多种方式破局，无需遵循单一战术。
- **解围后巷**：打通后门，救下铁手。铁手获救后不会发呆，他会听从玩家的简短指令（如“守住楼梯口”或“去切断外面的机枪手”），带着剩下的小弟执行，为玩家分担一路压力。
- **侧翼包抄**：从建筑内部的通风管道或破坏墙壁绕到厢车背面，近战解决一楼的枪手。
- **制高点反制**：技术型或敏捷型角色可以翻窗跳向隔壁楼栋的防火梯，从上方对外部的机枪手进行精准狙击或投掷爆炸物。
- **正面强突**：如果是重装路线，可以直接顶着火力冲进门厅，与二楼的卫铁生形成上下夹击，快速绞杀室内的敌人。

**第二阶段：敌方弃卒与情报获取**
随着室内枪手被清理或伤亡过半，带队的雇佣兵领队意识到硬啃会赔本。他不会死战到底，而是果断抛下还在室内缠斗的几名手下，提着装满酬金的钱箱，跳上外面那辆未受损的接应突击车，一脚油门向着几个街区外的临时车场据点撤退。

留下来的枪手发现自己被卖了，且尾款无望，士气会立刻崩溃。
- 如果玩家将枪管顶在他们的脑门上，或者承诺给一条活路并允许带走重伤的同伴，他们会毫不犹豫地出卖领队，直接报出车场的具体位置和内部防御布置。
- 如果玩家选择全部击毙，在撞入门厅的厢车导航仪里，或者死者身上的战术终端中，也能直接提取到车场的GPS定位。不需要进行繁琐的密码破解判定，拿到定位就直接推进。

此时，卫铁生从楼上走下来，虽然挂彩但眼神凶狠。他拍出那本藏在暗格里的“清退尾账”——其中能看出方经手的旧清退差事与拖欠款项；刚刚来杀人的枪手及其通信才说明这次灭口。两者让官方继续替方遮掩的风险变高，不会让他的私人军队自动缴械。

**第三阶段：反攻车场**
车场位于一片废弃的工业区内，周围是用波纹钢板和铁丝网围起的院子。
敌方剩余兵力：车场内有4名看守（装备散弹枪和冲锋枪）、1台原本用于搬运货物的工业装卸重机（被改装成了临时防线）、此前若成功撤回的领队（守在二楼调度室），以及停在车库里的一辆装甲运输车。

战术环境与潜入/突击路线：
- **正门强攻**：驾驶刚缴获的厢车或其他载具，直接撞开铁丝网大门，强行突入院子。
- **高空压制**：爬上车场旁边的废弃冷却塔或厂房水管，到达屋顶。从天窗或边缘对院子内的看守进行居高临下的射击，压制调度室。
- **地沟潜行**：通过工业区的排水沟，可以避开外围视野，直接摸到车库底部的维修地坑，从敌人脚下发起突袭。

重机变招与互动：
一旦战斗爆发，看守会立刻启动装卸重机。这台庞然大物没有挂载远程武器，但它会挥舞粗壮的机械臂，将院子里的废旧轿车像炮弹一样扫向玩家，或者直接迈着沉重的液压腿试图踩扁掩体。
- 玩家可以使用重火力或破甲武器打断其脆弱的液压关节（拆腿）。
- 敏捷型PC可以借助地形跳上机甲背部，击毙或揪出驾驶员，夺取控制权。
- 技术型PC可以黑入其未加密的工业控制模块。
- 夺取机甲后，玩家可以驾驶它直接撞烂车库厚重的卷帘门，甚至用机械臂将躲在调度室的领队连人带墙一起扯下来。

**第四阶段：在战利品旁定合作**
战斗结束按实际控制范围清点战利品：领队未带走的钱箱内有方预付的 ¥60,000 现款，车库里未被打坏的装甲运输车或重武器与剩余弹药也能带走；领队可能投降、死亡或逃脱，不预定留下尸体。

卫铁生带着包扎好的弟兄赶到现场。他现在急需这笔钱来安抚死伤的兄弟和填补堂口的窟窿，同时他也看到了方必须要死，否则义胜盟永无宁日。而玩家需要的是通往灾备厅的通道，以及能分担战线并负责接应的人手。
- **成交条件**：玩家只需将钱箱分出 ¥30,000 给卫铁生，则其余 ¥30,000 由玩家支配；也可以谈好把已夺车场和约定装备交给帮派，以资产代替现金分成，不能既付现金又自动把车场算作免费额外收益。
- **战力兑现**：作为回报，卫铁生会指派两组敢打敢拼的帮派成员（由铁手或阿三带队）归玩家指挥。玩家可以把他们安排为进攻灾备厅时的外围佯攻、撤退时的接应车队，或者直接跟着装甲车一起冲锋。

**衔接与延续**
- 如果玩家在前面的环节（B）已经抓住了方的把柄或导致其受损，本场旧账能增加官方继续保护方的风险；他们只撤自己的保护，方仍能花钱叫私人援兵。
- 若玩家未能在本场夺下车场并全歼守军，那些存活的私兵和未损坏的装甲车，将有可能在终局（D）中作为外围游动哨或增援部队出现。
- 战斗中夺取的车辆、重武器、伤势和弹药消耗将直接带入下一场。

## 事件后五项

1. 若堂口守住了，卫铁生会安排人清理现场，并把自己经手的清退尾账交给愿意合作的队伍。
2. 若雇佣兵领队活着逃走，他只带走实际抢到的钱和装备，未带走的战利品仍留在现场。
3. 若队伍拿下车场，未损坏的车辆、重武器和补给可以用于进攻灾备厅。
4. 若双方谈妥份额，铁手会带两组实际可用的人按玩家安排牵制或接应。
5. 若未谈妥合作，卫铁生保留自己的兵力，但不会收回玩家已经合法分到或凭本事夺得的物资。
