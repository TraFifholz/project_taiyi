## 使用顺序

先按 [总流程](../ep03尾声-ep04-流程与事件卡.md) 补结第三话尾声，再使用下面的事件卡；人物临时求助查 [NPC 反应表](../ep04-已出场NPC反应表.md)。

| 卡 | 正文 | 进入时接什么 | 结束时交给下一场什么 |
|---|---|---|---|
| A | [PMC 猎杀欲子](A-PMC猎杀欲子.md) | 已结休整，欲子旧 SUV 仍按实际修理状态处理 | 梁已重逢、仅露权限；夺车、伤势与追杀队残部按实际结果留存 |
| B | [管委会围捕李好](B-管委会围捕李好.md) | 何凌可在这里首次吐露黑料；若已说过便不重演 | 灾备厅位置明确；被救职员与车有实际去向；方与特工受伤不刷新 |
| C | [义胜盟开战](C-义胜盟开战.md) | 经已有帮派联系人到堂口，不要求老王账簿或新密码 | 两组帮派人手、缴获装备、钱与伤员交代清楚；车场残部是否能增援 D |
| D | [灾备厅决战](D-灾备厅决战.md) | 带入前面真正获得的人手、入口与装备 | 方死、特工撤离；获救者、原始资料与战利品归属明确，留出余波 |

## 可变顺序怎么接

- **A 后 B：** 梁可以留在落脚处修缴获机器，也可随队；他只控制接触到的追风设备，不能一句话撤销管委会围捕。
- **B 先发生：** 何凌先给地点与黑料，梁尚未出现，机器与技术任务由 PC 自己处理；接着跑 A，脱险后的短谈直接接已有复仇计划。
- **B 打完紧追方：** A 已跑便直接进 D，C 可省去；A 尚未跑时，将重型自走机与梁重逢那一段放在追击途中的街口，保留同一追击事件，A 的完整包围战不再强插回去。
- **先去帮派：** C 可以先跑，何凌用一次短碰头给出关键黑料；帮派的车与人随实际战果进入后续 A、B，不扣回去让原伏击重演。
- **跳过 C：** 可以出钱借通道或自行找入口；D 没有免费的两组帮派援军，车场尚存的守军才可能来救方。
- **玩家准备好自己的路：** 地点和敌方意图沿用，入口和第一枪由玩家决定；不把成功侦察或潜入换算成必须补打同样数量的战斗。

## 跨事件只记这六项

| 状态 | 主持记录 | 对后续的实际影响 |
|---|---|---|
| 人员与伤势 | 谁在队、谁留守、谁受伤或已撤出 | NPC 不瞬移到下一场，方与特工在 B 的伤会带到 D |
| 交通与重装备 | 原车是否修好，夺走哪辆车、哪些炮与机器 | 战斗毁掉的不能完整领取，修好的也不再无故报废 |
| 追风追杀队 | 指挥车和操控员是否仍能组织人手 | 与方的私人军队分开，A 残兵不换制服无限刷新 |
| 方的武装 | B 抓人队、C 车场守军各剩多少 | D 固定守军之外，只增加实际活着且能赶到的车场人员 |
| 盟友承诺 | 卫铁生派了几组，钱和战利品怎样分 | 一组人一次负责一处牵制或撤离，不同时替玩家守住所有出口 |
| 已知与已带出 | 地点、黑料、救出的人、资料载体在哪 | 已知路线不重新加密，带出去的资料不因终局灭口消失 |

## 防止连接错位

**何凌的情报一次说清。** 方花钱购买失踪服务、陈培安被害、地下灾备厅是去处；不要求依次打完 A、B、C 才凑齐这三句话。她对前辈的感情留在救援行动里展开。

**梁的两次显露分开。** 初见只显示懂机器和权限高，追风技术高管身份在后续安定片刻自然揭晓；他是间接上游属于 GM 真相，本话不给 PC 采购签名或相关自白。

**B 是交锋，D 才是整场决战。** 方在 B 有看得见的撤离路线，特工提前护主；若玩家追上并继续交战，直接把 D 的围堵、救援与终局接到当前行动，不打一遍重置满血的方。前段不额外赠送免伤或无敌来保住演出。

**灭口与撤离遵守已定结局，其他战果照常成立。** 玩家打出败局才让特工弃方；特工负伤、丢装备、没来得及毁材料都能保留，不把他的离开写成所有攻击无效。

**前后五项是投放材料。** 传言可以被听到，可能事件要到相应条件才发生，NPC 现状随顺序更新；这些短句不各自扩成另一套必跑支线。
