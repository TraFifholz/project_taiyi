## 遭遇 A：后院拦车（首选，能避战）

**目标：**人走出西门并抵达有工作人员的接待处；材料保全或确认去向。敌方要把指定原件带走、阻止于留下说明；不是全体死战。谈妥、隐身取走、正常核单都能结束，不为测试战斗强制触发。

### 动手后每人做什么

- 第一轮领班要求交箱，优先夺箱或运动擒抱拦路者；非致命短棍保护自己。拔枪仅在遭致命攻击或队伍持械强逼且谈判破裂时，先描述掏枪；真实已拔枪则按先攻正常射击，不补免费威胁回合。
- 两名手下一人拿箱，一人拦路。未受阻的取箱者靠近→拿箱→向车移动，移动与操作照实际预算，不能一个动作完成全图装车。
- 车要有驾驶员到座位、钥匙到手，并各用一个行动发动和启程。整轮未受阻的启程行动才能离开东口。门已闭则必须处理障碍；关闭按钮不是遥控全城车辆。
- 一个手下倒下且领班失去箱子：其余停止推进，领班提议放人、带自己人走。领班无力化：手下撤离或投降。玩家放行后不背刺奖励他们。
- 一个手下倒下、但箱子已运开：领班先到车上准备撤，另一个人放下箱子去带伤员，停止追于；允许PC撤走。搬运伤员需两人或核负重，不能单人一轮拖过全图。若玩家要求以箱换伤员，领班愿意谈，不为了档案牺牲手下。
- 领班被纠缠会先挣脱。撤出近战的自由攻击照规则，不把“投降”当免费逃离近战；愿意放行就不攻击。

### 常见裁定

| 行动 | 裁定 |
|---|---|
| 护于走／拿着已解封的箱子撤 | 用真实移速；于跟随时自己移动，不占PC搬运负重；要抱着他则核负重 |
| 擒抱领班 | 运动对抗运动；赢为纠缠，优良束缚；不能以格斗对格挡代替 |
| 用短棍击昏 | 正常近战对格挡；非致命。爪刀不是自动可用刀背的钝器，先确认武器有可用平面 |
| 用话令对手分神 | 选适合技能与关联属性作考验；成功分神或脆弱，优良附动摇／合适效果；不是免费群控 |
| 黑暗、隐身 | 依实际能力范围与状态照明规则；敌人没有盲视或电磁视觉。记住同伴能否看见，控制目标与逃路仍存在 |
| 抢钥匙／偷手机 | 未被察觉时贼活对察觉；正在紧握争抢按力量对抗或适当缴械，不用一次无风险潜行直接夺走手中物 |
| 锁车／拉闸 | 到控制点，修理或电子学TN4一个行动完成干预；失败可再试，有敌人行动作为代价，大失败才造成具体故障 |
| 念动力提箱／搬人 | 符合现卡能力即有效；是否需施放检定、维持、对抗按现卡，不临时增加剧情重量 |
| 手机备份 | 已拍内容正常发送；无对抗不骰，短讯可简单操作，边打边整理整批文件才占行动 |

### 遭遇 B：装卸坡道救档案（互斥备选）

仅当玩家选择放车走并跟到演示厅外围，或错过交接后主动追货。与 A 同场最多用一个完整战斗，避免第二波惩罚避战者。原件已被提前救出则不用该目标。

用一条12×4格装卸坡道替代后院：西端(0,2)街面，档案车(4,2)，待卸箱(6,2)，东端货梯(12,2)，断电开关(8,4)，支撑柱(7,1)提供中掩蔽。坡道正常地面，货梯当前开门；货梯承载正常，不是碾人机关。沿用当前活着的领班与随行人员，不刷新死者，最多加一名未参战的龙套卸货工并提前显示。

卸货工接指令将侧门附件送销毁区。三次**未被阻止的卸货行动**才会完成“箱送入→按键→门闭并下行”，不是三轮自动消失；夺走箱、断电、堵门都停止推进。每次公开描述进展。箱下行只意味位置变化、后续追回更难，不是瞬间化灰。于若已被救出不再传送成这里的人质。

可谈判：出示存档调拨单，卸货工拒做销毁；可潜入：跟装卸人员进入并拿箱；可战斗：阻止领班夺回箱子；可放弃：拍下送达处与接货岗位，带证据离开。英雄救下已经被抓的人时，给他完整生还，不用新增绝症消除成果。
