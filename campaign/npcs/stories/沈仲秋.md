# 沈仲秋

> LS-NPC-089｜沈漫堂弟，事务所日常成员｜不是另一位幕后知情者。

## 他走到今天的经历

沈仲秋有自己的工作和绩效压力，也愿意来帮堂姐搬东西、管设备、看顾阿瑶。事务所逐渐成了一群人的家，他承担的事却常被当成理所当然：电够不够，钥匙在谁手里，孩子今晚跟谁吃饭。

他并不反对众人冒险，只是不愿所有人回来时才想起生活需要有人维持。他与沈漫的分歧不是谁更勇敢，而是谁有权替留下的人决定承担多少。

## 二十话里的故事

| 章节 | 行动与变化 |
|---|---|
| 第一章·落脚 | 保留电竞房、发电机、照看阿瑶和搬迁交钥匙等实跑经历，帮助事务所真正住下来。 |
| 第二章·扬名 | 与程雯商量阿瑶的适龄学习，管理新增设备和来客；要求主角提前说明带阿瑶离开的时间与风险。 |
| 第三章·风云 | 事务所受到各方关注后，他规划临时落脚点与日常物资，不凭普通人身份突然学会处理全部异常。 |
| 第四章·深渊 | 在线身份与通信受干扰时，维持线下联络，让冒险者与家属仍能找到彼此。 |
| 第五章·终焉 | 负责事务所及熟悉居民的安置交接；他可以拒绝陪主角进入深层，这不是背叛。结尾仍有人需要回家，而非所有人都站在祭坛旁。 |

## 关系与结局

他与阿瑶的关系靠日常相处建立，与程雯、林彬、谢翠莲形成的是照料网络，不是秘密组织。故事结束后，他应当有权继续自己的工作与生活，而不是永远做没有回报的后勤。
