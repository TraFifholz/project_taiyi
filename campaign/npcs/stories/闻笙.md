# 闻笙

> LS-NPC-N3｜棍木会测量者、李好的木签联系人｜玩家已知代称“棍木女”。

## 她走到今天的经历

闻笙在异常的余响中讨生活，也相信其中有尚未被人理解的意义。棍木会给了她能交流这些经历的同伴，没给她一套不会出错的解释。她把李好与神子预言联系起来，主动留下木签；这个判断是她的信念，不是主持人保证为真的结局说明。

她能测定接触到的异常余响，却不能只看一眼就还原事情经过。金色单瞳和喉部义体是已经确定的形象，不替她增加预言必中的能力。

## 二十话里的故事

| 章节 | 行动与变化 |
|---|---|
| 第一章·落脚 | S7 接触与木签保留。第 3 话作为青梢队四人之一检查芯片余响、参与 M-3 三方混战。她可以认出木签，却不能宣布交管7号已经觉醒或替人证明凶手是谁。 |
| 第二章·扬名 | 第 7—8 话帮助何凌辨别接口扰动，为司机与居民指出已测到的危险区。她须面对自己对李好期待过高的问题，不能把这些帮助作为李好接受预言角色的交换条件。 |
| 第三章·风云 | 经归城与接口试验的代价，她更清楚测量并非没有风险。她更愿说明结果的不确定，而不是用术语迫使别人听从。 |
| 第四章·深渊 | 与贺梦琪、老井支持线下联络，阻止普通人因在线系统失灵而失去求助渠道。 |
| 第五章·终焉 | 提供自己真正测到的危险区信息，参加有限撤离。预言没有实现也不使她失去人物价值；她可以选择站在人身边。 |

## 关系与结局

贺梦琪给她活动据点，老井维护物理线路，李好则可能质疑她的解释。三人的合作有能力边界，不构成随时提供完整答案的情报组织。
