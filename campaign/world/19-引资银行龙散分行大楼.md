# 引资银行龙散分行大楼

2026-10-09 建立，2026-10-25 依据已采用的 2026-10-15 剖面图更新的 GM 建筑正典。**地上 30 层，地下另有 3 层**；屋顶设备和停机坪不另算楼层。楼层与通行安排以本次采用图为准；玩家见闻仍以实跑记录为准。

分行兼管本地营业、企业融资、重建资金及天穹钱包的银行侧清算。楼内有客户、真人员工、远程操作员和在服务器上工作的赛博员工。白天低层人声嘈杂，中段是工单与会议，上段部分楼层只有机器运转声。

2026-10-25 第二章定位：本文的现用分行楼位于**楚岸区老租界**，与[企业名录](14-企业名录与商业生态.md)所记 1923 年旧银行历史总部地标分开。第八话 A 阶段在本楼发生；B 阶段的第三水站位于毗邻故城区的已清场旧区，押品须经车辆实际转运，不能由两地相邻直接接入。

正式图稿与源工程见[剖面图资产包](../../assets/maps/引资银行-剖面图-20261015/README.md)，其中[夜景合成图](../../assets/maps/引资银行-剖面图-20261015/combined_night.png)为无人物标注展示版；GM 人物位置见本页与日景图。原版文字快照仅作历史依据，楼层安排已由重排图替代。

## 地上楼层

| 楼层 | 用途 | 空间、设施与人员 |
|---|---|---|
| 1F | 营业大厅 | 正门安检、导引台、智能柜台、人工兜底窗口及现金与凭证自助机，处理开户、存取和普通咨询。大厅挑高，二楼能看见楼下；玻璃正门朝广场，侧门通后巷。后部设员工入口、访客电梯及独立押运通道。 |
| 2F | 个人金融与争议处理 | 贷款、保险、继承、身份变更与支付争议柜台；隔音调解室、家庭接待室和客户资料补录间。常见被系统误判、急需真人处理的客户。调解室有报警按钮，柜台后方能直接进入员工区。 |
| 3F | 企业营业与商户服务 | 企业开户、工资代发、商户结算、跨境汇款和大额业务面签。设文件核验室、企业代表等候区与小型签约厅。金舸常在此接待客户，也会到 11F 办理后台业务。企业访客需有人带领才能继续上楼。 |
| 4F | 贵宾与私人银行 | 独立接待间、资产配置室、贵重物寄存交接室和预约制贵宾厅。客户可从车库乘专用电梯抵达。这里暂存待交接物品，长期保管物送地下金库。陶景衡常在此接待本地合作方。 |
| 5F | 招聘与业务培训 | 面试间、新员工教室、仿真柜台、操作考核间及远程培训舱。训练使用模拟工单，不影响真实账户。白天常有临时证访客和培训人员；教室、隔断与备用工位经常调整。 |
| 6F | 人事与行政后勤 | 人事、薪酬、岗位调动、工牌办理、会议室预约和物资采购。设工服库、耗材仓与员工服务台。这里能查人员调动和临时驻楼记录。工牌权限在此申请，机房、金库与武装库另需对应部门批准。 |
| 7F | 安保指挥中心 | 监控大厅、门禁与电梯调度台、报警处理室、访客复核室、保安休息区和独立通讯室。值班人员查看公共区域及库区外围，分区封闭通道并派出安保，与押运车和巡逻机器人联系。办公室内的业务录音另行保存。 |
| 8F | 武装库与战备室 | 武器库、弹药库、防护装备库、领用柜和清点间分开设置。储有手枪、冲锋枪、少量步枪、盾牌、防弹衣、束缚器、烟雾与震撼器材，以及针对失控义体和机器的电磁干扰装备。领用需身份核验与人员复核；旁设封闭试射间、枪械维修台和出动集合室。 |
| 9F | 安保机器人整备 | 巡逻机、机械警犬、室内拦截机和侦察无人机的充电、维修与控制校准区。重型押运护卫机锁在独立机位，需要人工授权出动。地面有承重轨道和货梯口，周围是打开的装甲、挂起的机械臂与测试障碍。失控机器可在此断电或重新接管。 |
| 10F | 审计部 | 何凌的日常工位、审计会议室、资料复核间和证据封存室。查询终端与独立留存设备可比对本地业务、总行镜像及纸质材料。被审计部门不能修改已封存的副本。何凌从这里报告普通审计发现，对信息空间的经历仍有保留。 |
| 11F | 企业信贷 | 企业授信、贷款审查、抵押评估与贷后管理。设项目讨论室、工程图工作台及远程律师会谈室。金舸在这里处理后台业务。可查项目由谁经手、为何获批、抵押资产后来去了哪里。 |
| 12F | 重建与公共项目金融 | 专管旧城重建贷款、援助资金、公共工程付款及地方单位账户。设工程资料室、资金拨付席和政企联络室。方泰安与管委会的业务在此留痕。陶景衡维护本地客户关系，裴秉钧要求查清实际收款人与项目用途。 |
| 13F | 投资与资产管理 | 机构客户投资、银行代管资产、研究押品和破产接管项目。设评估间、投资会议室与交割工作台。保存设备、专利、研究材料等押品的权属和流转记录；实体物件按体积送金库或银行外仓。可承接后续研究押品被挪用的事件。 |
| 14F | 风险与异常交易 | 风险分析、异常支付复核、贷款预警和反欺诈调查。系统筛出异常，真人决定进一步处理。设客户联系间与可疑业务复核台，经授权可暂停银行业务。若有人替方泰安压下告警，能查到操作者、时间与理由。 |
| 15F | 法务与合规 | 合同审查、诉讼、监管联络及正式举报受理。设律师会谈室、保密谈话间和向总行提交材料的终端。负责将调查发现整理成正式追责材料，也处理赔偿、停职与客户通知。 |
| 16F | 当前业务档案 | 近年合同、盖章原件、抵押凭证、审计底稿和仍使用的纸质资料。设密集架、盖章原件库、阅档室、扫描间与暂存区。调阅记录经手人，移出原件需交接。更早、尚未整理完的旧城账目仍在 B3。 |
| 17F | 通讯、密钥与网络安全 | 总行专线、钱包网关、内网调度、加密设备与安全值班室。另设密钥操作间、入侵取证台和机房登记口。可在银行网络内切断异常连接、隔离终端、追查来源；修改业务仍需业务权限。紧急断联会阻碍远程命令，也使部分实时业务停摆。 |
| 18F | 主数据中心 | 主业务服务器、交易数据库、文件存储和实时处理设备。冷热通道分开，机柜有标号，技术人员沿检修通道作业。指定人员持权限进入，外来维修需陪同。设备保存银行侧记录和交易状态，停机或损坏会触发备用系统切换。 |
| 19F | 数据设备保障层 | 冷却泵、分区配电、UPS 电池间、灭火控制设备与硬件备件库，另有维护用神经接口诊断室。粗管道、承重地板和窄检修廊遍布本层。冷却失效会报警并迫使机房降载。接入设备服务正常工作连接，进入异常信息空间仍依既有剧情条件。 |
| 20F | 备用数据中心与恢复室 | 与主机房分区供电、防火，设复制机群、历史快照、离线备份柜和恢复控制台。承担主系统故障接管，并向城外灾备点发送备份。总行审计副本经此同步，删除一处记录难以抹去所有痕迹。楼内两套设备均受损时由城外灾备恢复。 |
| 21F | 赛博员工与自动业务 | 自动柜员、工单分派、合同初审和常规客服程序的运行区。服务器列柜、维护终端与少量人工观察席构成主体，通常没有普通员工。屏幕显示工单与赛博员工状态。程序停用、改派或异常接入会改变业务，故障时 22F 的真人工单迅速堆积。 |
| 22F | 业务工单中心 | 李好与陈志远及团队的主要办公区。李好的独立办公室、团队开放工位与主管办公室同在本层。开放工位、短会室、主管办公室与交接台围绕工单大屏布置。真人负责沟通、现场核验及系统不能处理的异常，常规自动业务交由赛博员工。 |
| 23F | 外勤与项目协作 | 设临时项目室、外勤工位、外勤装备柜、视频联络间与资料收发处；李好的日常办公室在 22F。处理企业现场核验、管委会往来和跨部门任务。柜中有未结工单、路线安排及待签收资料，夜间也可能有人回来交材料。 |
| 24F | 天穹钱包银行接口 | 支付接入、账户核对、商户对账、银行侧身份对应与故障升级。云梦技术人员在此协作，客户资金与银行审批由引资掌握。设接口测试间与故障会商室。错误扣款、账户异常或结算中断时，两家人员在此共同排查。 |
| 25F | 资金调度与清算 | 资金头寸、机构结算、大额支付复核及现金调拨。交易员与系统操作员轮班，设总行联络室与押运计划席。这里决定哪些付款真正执行，哪些仍停在审批阶段，并协调地下金库出入、柜台补款及分行间调款。 |
| 26F | 员工生活与应急避难 | 餐厅、夜班食堂、休息舱、洗浴更衣室与内部医务室。应急集合区备有饮水、急救包和备用通讯。不同班次的员工在此碰面，消息经常先在饭桌上传开。靠窗有露台，能望见城市和下方楼层。 |
| 27F | 高层会议与重要接待 | 高层会议室、大型视频会议厅、媒体接待间和政府、企业代表候见区。会谈室可分隔，适合联合审查、正式质询与签约。行长与特派副行长的争执可在此当着其他决策者发生；普通员工多因汇报而来。 |
| 28F | 特派副行长与专项督导 | 裴秉钧办公室、督导组工作间、保密会议室与独立总行通讯间。设封存调查资料柜和证人等候室。审计、法务及安保按任务汇报。裴在此签发专项调查和人员保护安排，指令同时留存总行。 |
| 29F | 行长办公室 | 陶景衡办公室、秘书处、本地项目会谈室与私密接待间。墙上陈列本地项目，内侧会谈室可绕开公共候见区。保存高层批示、合作往来及个人留存材料。郑启明等合作者可乘贵宾电梯来访，门禁仍留下到访记录。 |
| 30F | 空中接待与紧急指挥 | 顶层贵宾厅、总行来访人员短休套间、应急指挥室及屋顶出入口。局部封楼时维持对外联系，并可组织屋顶撤离。外侧有高空露台；屋顶设押运与公务垂直起降机停机位，起降受天气、空域和驾驶员状态影响。 |

## 地下楼层

| 楼层 | 用途 | 空间、设施与人员 |
|---|---|---|
| B1 | 车库与押运交接 | 员工车位、贵宾停车区、银行车辆整备、货物安检和封闭押运装卸间。押运车从后街坡道进入，库区货梯送货至 B2；一般送货检查后走服务货梯。员工车道与押运区隔开，可分别封闭。 |
| B2 | 金库与贵重物保管 | 现金库、保管箱区、贵金属库、抵押实物库和出入清点室。[沈折琼](../npcs/roster/全城NPC名单.md)在此守库。客户到保管箱接待区，主库由库管与授权人员共同开启。库区另有资办委托代管、未列入普通保管箱目录的无编号密室，第八话候选名册存于此处。厚重库门、清点台、运输笼车与独立通讯是主要设施。 |
| B3 | 旧档案与基础设备 | 前半层保留未完全数字化的旧档案，保存旧城贷款、历史交接及工程原件，是第四话档案室突围的地点。后半层隔开设置总配电、应急发电、消防水箱和污水泵房，设备间各有出入口。档案架道狭窄，货架、搬运车与喷淋可用于现场。 |

## 通行与人员

- **客户电梯**：服务 1—5F；其他业务楼层按预约改走对应员工梯，并由员工接待。
- **员工电梯**：低区停 B1、1—10F；中区停 B1、1F、10—17F；高区停 B1、1F、22—26F，可从 1F 直达 22F。工牌按岗位开放，审计证据室、档案原件库仍需单独登记。
- **技术电梯**：服务 17—21F，并接入 7F 安保中心与 B1 装卸区。机房入口另有门禁，技术与安保权限不同。
- **贵宾电梯**：连接 B1、4F、27—30F，秘书与安保核验访客。高层可从办公室召来电梯。
- **货梯**：库区货梯服务 B1—B3；重载服务货梯连接 B1、8—9F、16F、18—21F、26F。机器人、机柜和库区物品按指定路线运送。
- **消防楼梯**：两座独立楼梯贯通全楼，设防烟前室。人员能进入楼梯疏散，返回受限楼层需权限；消防状态开放逃生出口。

陈志远与李好以 **22F** 为主，何凌以 **10F** 为主，金舸往返 **3F、11F**，沈折琼在 **B2**，裴秉钧在 **28F**，陶景衡在 **29F**。会议、吃饭、外勤与突发事件会使他们离开工位。

## 图中空间关系

楼板按 48 × 32 m 绘制，核心筒居中；各层主要房间、功能分区与竖向连接采用轴测图的安排。1F 营业大厅挑高，2F 对应位置留有挑空；B1 押运坡道通后街，屋顶有电梯机房、楼梯出屋面及停机位。家具和房间比例为示意，楼高按普通层约 4.2 m、1F 约两层估算。

22F 团队脚下的 18—21F 为连续四层机房段，17F 是网络安全与机房登记口；高区员工梯穿过机房段不停。李好办公室与陈志远主管办公室各自独立，同处 22F。B2 展示图只标普通库区，无编号密室及名册继续依本文 GM 设定。

## 跑团时有用的变化

- **武装出动**：日常是保安与轻型机器人巡逻。8F 取枪、9F 调机器、7F 下令封区是不同动作。裴秉钧能调安保，陶景衡也能以分行安全名义发令；两人冲突会落实到值班人员接到哪道命令。
- **调查地点**：经手关系在 11—12F、22—23F，原件在 16F 或 B3，付款结果在 25F，系统记录在 18F、20F，高层往来在 28—29F。根据要查的事选有用地点，不要求逐层收集。
- **停电与降载**：B3 发电和 19F UPS 支持关键设备，普通照明、空调和电梯未必全部供电。机房降载后自动工单延迟，真人收到大量紧急任务。
- **局部控制**：7F 管门禁与安保调度，17F 管网络，25F 管支付执行。占住一处会影响对应系统，其余部门仍会根据现场危险行动。
