# 框架总览

> 2026-09-03 同步。剧情与角色以[二十话重整](../episodes/20-episode-outline.md)和[设计定案](../decisions/二十话重整-设计定案.md)为准。话数不是实跑 S 场次。

## 世界设定总览

| 维度 | 设定 |
|---|---|
| 系统名称 | T.A.I.Y.I.（盘古智能尧级基础网络） |
| 城市 | 龙散市（长沙），2030 年 |
| 风格 | 近未来赛博朋克 × 古代神话赛博化 |
| 表层 | 高效便捷安全的 AI 管理都市 |
| 里层 | 数字泛意识场与信息模因战场 |
| 三大势力 | 巨型企业（肉）、卜府（骨）、义体帮（血） |
| 能力体系 | 觉醒者从太一网络下载信息模因，以信息法则覆盖物理因果 |
| 威胁分类 | Ⅰ型失控模因、Ⅱ型畸形模因、Ⅲ型异界模因 |
| 城市分区 | 绿区（凝视）、黄区（眨眼）、红区（背过身）、黑区（离线） |
| 地下层级 | 运营层 → 弃置层 → 陵寝层 → 太一之肠 |

## 主线框架

| 要素 | 设定 |
|---|---|
| 开篇 | 普通人被卷入事件，死亡，被阿瑶复活 |
| 阿瑶 | 白发红眼的神秘女孩，有明确"方向感"使命，PC 觉醒的触发者和共生者 |
| 觉醒 | 复活后获得扰动太一网络的能力 |
| 据点 | 黄区边缘"随缘事务所"，沈漫的旧据点，日常身份是信息咨询公司 |
| 经营 | 章间休整按实际时间——情报网、安全屋、太一接口、阿瑶恢复 |
| 主线 | 二十话五章单元剧结构。追随阿瑶指引，逐层向下深入龙散市地下 |

## 城市空间与游戏循环

| 区域 | 地面分区 | 地下分层 | 主要玩法 | 威胁来源 |
|---|---|---|---|---|
| 绿区 | 监控全覆盖 | 运营层（有权限） | 社交/潜行/情报 | 企业安保/TAIYI |
| 黄区 | 日常边界 | 运营层/部分弃置层 | 均衡玩法 | 帮派/企业安保 |
| 红区 | 监控失效 | 弃置层为主 | 战斗/探索 | 义体帮/觉醒者/殄 |
| 黑区 | 完全离线 | 弃置层/陵寝层/太一之肠 | 高回报探索/高危险战斗 | 所有类型殄/Ⅲ型模因/发狂机器人 |

## 企业生态

| 企业 | 领域 | 关键游戏功能 |
|---|---|---|
| 重黎工业集团 | 重工/机器人/安保 | 工业遗迹探索、安保对抗、泥人计划 AI（刑天/步行机） |
| 云梦科技 | 信息技术/天穹钱包 | 身份伪装、数字生活界面、TAIYI 深层（纪崇吾/神机） |
| 河图科技 | 外地竞争性 AI 系统 + 游戏 | 替代支付管道、《九域》入口（第13话 封神事件） |
| 飞廉速运 | 物流/地下管道 | 物资获取、情报物流 |
| 燧明科技集团 | 消费电子/芯片/智能汽车 | 硬件升级、后门风险、车机追踪、神经接口芯片 |
| 丰隆工业集团 | 机动平台与防务（陆/空/军工） | 巡逻对抗、机甲回收 |
| 九渊建设集团 | 建筑/地下工程 | 地下地图、陵寝入口 |
| 龙腾轨道交通 | 地铁运营 | 运营层入口、觉醒者碰头点（第2话 地铁幽灵） |
| 追风出行 | 网约车平台 | 城市情报网、移动监控、AI 觉醒（第3话 交管 7 号） |
| 引资银行 | 金融/信用体系 | 经济身份维护、灰名单风险、地下金库（第8话 锚点名册） |
| 玄盾国际 | PMC/军事承包 | 雇佣兵资源、被清理风险、白鸢（第18话有条件协助或阻拦） |
| 楚风传媒集团 | 文娱/直播/网剧 | 文化地标、直播情报、大楚 AI（第6话 真人秀） |
| 云鲤互娱 | 二次元手游（霜月会白手套） | 《妖刃计划》ARG、霜月会线索 |
