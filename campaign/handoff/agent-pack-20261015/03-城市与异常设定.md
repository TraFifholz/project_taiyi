# 城市与异常设定

本篇是 GM 可读的城市常识与基础设定。它包含普通市民不知道的异常原理，不能整篇作为玩家已经掌握的情报。

## 日常社会

诸夏自 2020 年起以技术特区推动芯片、AI、义体和神经接口发展。龙散是试验城市，企业参与公共治理，地方利益与中央收权之间存在摩擦。自动化带来失业与反机器暴力；移民、本地人、夏人之间的身份张力又被资源分配放大。

**T.A.I.Y.I.** 是全城管理网络，官方称盘古智能尧级基础网络。它管理交通、公共服务与大量设备，也承载数字泛意识场。**天穹钱包**集支付、身份、通行和信用于一体。CPI 是完全权限识别码，LPI 是限制权限识别码；评级影响医疗、教育、贷款、就业和能否进某些区域。街头看起来井然有序，个人却可能因记录、权限与身份变化突然失去正常生活。

早期社会设定写过纸币完全消失，实跑却反复使用现金、金条与离线交易。写当前剧情时保留这些真实交易；数字支付是主流，不用旧设定抹掉主角经历。

## 地面与地下

绿、黄、红、黑主要表示系统覆盖、监控与秩序状态，可随街区和事件变化。绿区覆盖严密，黄区存在缝隙，红区管理失效，黑区离线或被隔离。行政区名称与安防颜色要分别理解。

| 地区 | 剧情中的用途 |
|---|---|
| 深中新区 | 企业、金融和严格管理的城市门面 |
| 文星区 | 龙散大学、21-35 联合研究所与学术线 |
| 楚岸区 | 老租界、商业传媒、引资银行龙散业务 |
| 故城区 | 老街、黄区生活与义胜盟；事务所现址 |
| 铁山区 | 工业、铁铺和废弃设施 |
| 望津区 | 港口、物流和阿奎拉家族 |
| 北岭区 | 居住区、白念秋住所调查与霜月会相关街区 |
| 旧城灰区／旧城区 | 2027 大塌陷留下的封锁、重建与深层异常 |
| 云麓镇、窑湾村 | 山地考古、郊外废弃设施与离线区域 |

**故城区与旧城区是两个地方。** 旧地理稿的岸别、相邻关系与新地图有调整，具体坐标应回项目核对已采用地图。此包不冻结一张未确认的新地图。

地下由地铁、人防、物流、市政管廊、工业设施和塌陷废墟交错组成。运营层、弃置层、陵寝层、太一之肠可用来理解探索深入的程度；工程形态以较新的《地下空间形态与示意图设定稿》为准，各类设施并非整齐连续的楼层。

乘客只使用地铁公共区。工作人员在有限工作区活动，物流交通区默认由机器运行。图上线路相交不表示人员可通行，货物能过去也不保证人能走。废弃是使用状态，黑区是管理与连接状态。神响之地在黑区深处，地下图不标具体位置，也不以隐藏坐标或专线暗示终点。

## 组织与各自的利益

| 组织 | 主要资源与行动 |
|---|---|
| 云梦科技 | 城域 AI、天穹钱包、数据与 TAIYI 维护；深层研究牵涉纪崇吾 |
| 重黎工业 | 工业机器人、重型义体、安保与泥人计划；韩铸、同舟、刑天各有意志 |
| 卜府 | 借神策进行因果建模与行政裁量的秘密权力网络；主流派、观察与变革立场并存 |
| 旧城管委会 | 重建、工程与采购权限；方泰安借此牟利并替上游办灰活 |
| 玄盾国际 | 旧城安保合同、PMC、重装备与现场控制；内部人物、合同与外包行动要具体区分 |
| 追风出行 | 车辆、路线、记录与移动监控；梁文川、交管7号和承包商的权限与命令来源不同 |
| 引资银行 | 钱款、身份与项目记录；李好的日常工作使他进入调查，机构内部权力并不统一 |
| 义胜盟 | 保护费、债务、赌场和灰色物流；武侠与本地帮派传统，黄区分舵和剑阁各有职责 |
| 霜月会 | 企业间谍、数据与神经接口，云鲤互娱为白手套之一 |
| 阿奎拉家族 | 港口、走私、赌博与人口生意；罗马神话及家族传统，宋远、马铁鹰是已有接点 |
| 棍木会 | 觉醒者、测量与线下联络；闻笙、贺梦琪、老井提供有限帮助，也有自身信念 |
| 龙散大学、21-35 所 | 学术、接口、信息场和 ARP 研究；普通师生不自动知道秘密项目 |
| 楚风传媒 | 节目、公众形象、传播与 AI 大楚；白念秋的职业关系由此展开 |

河图、飞廉、燧明、丰隆、九渊、龙腾等企业分别提供替代系统、物流、芯片、机动平台、地下工程和轨道交通。写具体工作时查企业名录，优先沿既有资源与岗位设计。

## 关键术语

| 名词 | 在本团中的意思 |
|---|---|
| 信息场／太一网络 | 连接信息与现实的异常环境；古老文化模因在此获得新的承载 |
| Spirit | 实跑中对异常数据流、模因网络和能力现象的常用称呼；具体能力仍按规则结算 |
| Sprite | 部分设定对赛博世界及其中空间的称呼；保持来源中的拼写，不能只凭相似字形合并所有现象 |
| 觉醒者 | 能让信息模因影响现实的人，常通过自身文化记忆呈现能力 |
| 数据因子 | 可影响奇能与阿瑶补完的异常数据；归属、是否干净及使用结果逐次结算 |
| 兔子洞 | 红皇后开发的数据化与接入程序，已出现版本 `rh06.1x1`；创建时间戳 `1970-01-01` 是线索 |
| 迷失者 | 数据化后自我认知难以保持、在信息洪流中被稀释的人；老王是已跑实例 |
| 殄 | 本地信息场中带地域文化特征的Ⅰ、Ⅱ型模因统称 |
| Ⅰ／Ⅱ／Ⅲ型模因 | 分别概括失控文化残影、系统错误或扭曲生成的数据生命、外来信息场模因 |
| 神策 | 卜府借 TAIYI 做的大规模因果建模；觉醒者成为预测难以控制的变数 |
| 碳铀 | 信息场渗漏形成的异常结晶，古代祭祀使其进一步积累；承载谐振与锚定问题 |
| 锚点 | 在具体研究与业务中维持某种状态的对象；朱蘅的全城谐振岗位、白芷秋稳定的事故记忆和归城实验条件需分别说明 |
| ARP | 许承钧等人推进的替代锚定研究，成果有限，需验证意识能否退出及过渡条件 |

异常可以让小说人物、神话与 AI 出现现实作用，但每次出现都应交代已有载体、权限和条件。AI 也可能形成独立意愿；“系统下令”“个人批准”“派生证书被承包商使用”是不同事实。
