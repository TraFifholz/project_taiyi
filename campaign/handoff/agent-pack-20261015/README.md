# 龙散战记 Agent 剧情与设定包

这是给协助 GM 的 agent 阅读的完整剧透版。整理日期为 2026 年 10 月 15 日；实跑覆盖 S1—S14，最新原始记录录制于 2026 年 10 月 9 日。包内包含快速认识本团所需的正文，以及保留原目录结构的资料快照。

## 怎么交给其他 Agent

只传一个文件时，传 **[龙散战记完整导读](龙散战记完整导读.md)**。它合并了下面五份导读，脱离项目也能建立基本认识。

需要 agent 继续备团、查人物或核对剧情时，传整个 ZIP，要求先读本文件，再按任务查 `sources/`。原始逐字稿也在包内，但不用一开始通读。

| 阅读顺序 | 文件 | 用途 |
|---|---|---|
| 1 | [本团与主角](01-本团与主角.md) | 团的风格、六名 PC、事务所和阿瑶 |
| 2 | [已发生剧情与当前现场](02-已发生剧情与当前现场.md) | 从序章读到 S14，知道下一场从哪里接 |
| 3 | [城市与异常设定](03-城市与异常设定.md) | 社会、组织、地下、能力与关键名词 |
| 4 | [GM 真相与后续故事](04-GM真相与后续故事.md) | 幕后因果、家庭年表、五章方向与终局条件 |
| 5 | [资料使用与查证](05-资料使用与查证.md) | 按任务找原文，处理版本冲突和角色知情范围 |

可直接复制以下说明给接手 agent：

> 你正在协助我主持《龙散战记》，请先读《龙散战记完整导读》，建立对城市、六名主角、已跑剧情及 GM 暗线的认识。当前跑到 S14：第四话已开始，停在周六凌晨欲子获梁文川送医、在医院醒来之后。铜锅护卫与银行查档尚未完成。请区分实际发生、NPC 口述或推理、GM 设定、未来预案，并按任务查 sources 中的原文。讨论当前行动时，不把你知道的幕后真相当成 PC 已知；创作时优先使用已有 NPC，延续他们的动机和关系。你提出的新内容请标作建议，等我采用后再作为设定使用。

## 快照范围

`sources/` 收入世界设定、现行定案、二十话梗概、重要 NPC 故事与名录、当前第四话准备、S1—S14 摘要及原始逐字稿、公开人物页与项目工作流。`manifest.json` 逐项记录源路径和 SHA-256；`原文索引.md` 可直接点击查阅。

原文按字节复制，保留其中的历史说法；导读说明怎样选择当前版本。原文链接可能通往未收录的立绘、地图、Foundry 文件或历史审阅，详见 `原文未随包链接.json`。这份包以文字认识与剧情协作为用途，不包含这些大型资产。

包是固定快照。收到 S15 或新的设计决定后，先回项目核对最新资料，再更新导读；不要只改快照里的源文件。
