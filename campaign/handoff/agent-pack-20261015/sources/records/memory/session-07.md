# S7 摘要：地铁幽灵·白昼调查

## 本场结论

第七场是"地铁幽灵"话的第一次推进——PC 兵分两路：李好在面馆门口守株待兔，其余五人（含凯芙拉）带阿瑶前往钢阳街地铁站白昼调查。面馆线出现了一位金色瞳孔的地雷系女性，自称"不存在的存在"、隶属于"棍木"，预言"神子已经降临"并称 PC 身上沾染了神子的气息；她给了李好一根木签护身符后离开，随后明星白念秋联系李好表示要做灵异探秘节目。地铁站内，PC 通过社交和白昼观察几乎一无所获，但阿尔坎骇入站内网络后发现了大量关键情报：摄像头深夜间歇离线、服务器中存在疑似赛博世界数据实体的沙箱陷阱、以及 L7-四段在 2027 年大塌陷日停工并被 5月23日写入终止记录。下午黑崎欲子在地铁站自导自演"幽灵"骚动被小孩目击，意外促成了流言的传播和白念秋的兴趣。夜探延至下一场。

## 关键场景

### 第一部分：分兵与面馆调查（S7:L1-L1126）

1. GM 开场交代：沈曼和沈仲秋周末在搬家（从莲花路搬往文侯庙），不看手机（S7:L97-L109）。

2. PC 决定分兵——李好独自去老王头面馆守株待兔；其余五人（含凯芙拉）带阿瑶去钢阳街地铁站调查幽灵（S7:L461-L513）。李好晚上还要加班两晚（S7:L433）。

3. 李好开车到面馆附近，看到墙缝中一个可疑人物：过膝长靴、白色风衣、帽子墨镜口罩全副武装，对着面馆探头探脑（S7:L719-L729）。李好问"块头像不像河狸"（河狸=何凌），GM 确认"像的挺像的"（S7:L737-L739）——面馆人影即何凌。

4. 何凌以白雾遮蔽视线并变成猫脱身；这是她已经展示的变形能力。逐字稿只清楚记录了白雾与人影消失，猫形态由 GM 后续校正确认。李好从后门潜入面馆，踩碎碳化凳子腿发出巨响，听到楼上紧急关抽屉的声音。上楼后发现窗开着、人已走——烧毁的监控室中监控设备的硬盘幸存（电脑烧了但硬盘分离）（S7:L839-L869）。

5. 李好拆下硬盘（SATA 口机械硬盘），在抽屉中发现一台白色手机（视网膜解锁）。离开面馆去电器铺买转接线后，回到车里发现：**硬盘变成了红砖，白色手机变成了充电宝**（S7:L1039-L1113）。GM 提示"每次都说房间乍一看是怎么怎么样，你也不搜索一下"——李好未曾仔细搜索过房间（S7:L1083-L1087）。

6. 李好继续守株待兔，以停车费不断跳表度日（S7:L1125-L1127）。

### 第二部分：地铁站白昼调查（S7:L1127-L2820）

7. PC 进入钢阳街地铁站：正常运营中，人不多但有客流量。十字路口西北为临街商铺（小炒店等），东北为半死不活的小型商业综合体（楼上幼教/机器人班），东南为居民小区（S7:L547-L595）。

8. 唐索去便民窗口询问幽灵事件——被工作人员笑着敷衍"世界上没有鬼"（S7:L1287-L1311）。

9. 黑崎欲子假扮记者持笔记本随机采访——被正式员工阻止，得知龙腾员工纪律极严：曾有新媒体记者恶意剪辑导致舆论危机，此后任何采访需上级审批。奶茶店店员透露：因为这个幽灵传闻，站点的下班时间从晚上10点提前到9点，工资也降了（S7:L1563-L1695）。

10. 雷武龙尝试以"九域"游戏搭讪大爷大妈，对方不愿深入交谈（S7:L2071-L2170）。

11. 黑崎欲子通过塞名片约到一位劳务派遣的阿姨中午吃饭。中午询问"正式员工中是否有适婚对象"——对方只推了一个微信名片，发消息后**被拉黑**（S7:L1893-L2411）。

12. 唐索在网络搜索——"钢阳街地铁站幽灵"搜不到任何信息；搜"地下铁幽灵"的结果被 GM 玩梗指向 COD 的 Ghost（S7:L2461-L2491）。

13. 唐索检查月台：只有两个检修口可进入地铁线路，其余被隔开。强电井和弱电井被防火材料堵死无法通过（S7:L2497-L2621）。

### 第三部分：骇入与发现（S7:L1499-L3639）

14. 阿尔坎通过手机连接地铁站设备 WiFi（SHA-256 加密但配置简陋），成功骇入并接管网口节点（S7:L1499-L1561）。

15. **服务器一**（基本服务/NGINX）：资源占用异常高。发现嵌套文件夹（红军长征历史 → 过雪山 → 过草地 → 四渡赤水 → 葫芦娃），深层全是 RNVB 视频文件。文件总体积恒定（约 30GB），但单一文件大小不断变化——**活物般的思维活动特征**（S7:L3037-L3571）。

16. **服务器二**（虚拟机/沙箱陷阱）：管理员账户 inhuman 操作——同时并发使用四个鼠标、输入速度超人类极限。该虚拟机具有**捕获和逆向追踪入侵进程**的能力，日志中充满"活物感"和情感痕迹。阿尔坎判断这是赛博世界布下的钓鱼节点（S7:L3490-L3569）。

17. 阿尔坎向 VM 发送关键词（兔子洞 / 老王面馆 / 幽灵 / 追风 / 天海信息科技），服务器返回乱码。部分可解码内容指向：**"封闭 L7-四段"**（S7:L3623-L3639）。

18. **数据库**（凯芙拉攻破）：包含市民地铁卡充值数据，可修改实现免费出站。设备使用日志揭示：**L7-四段**位于 **6号线延长段**，**2027年1月31日**动工，**2027年5月12日**因大塌陷停工、5月10日执行封闭流程。关键：**终止记录的写入时间是 2027年5月23日**——大塌陷后 11 天（S7:L3639-L3657）。

19. **安保服务器**：控制地铁站各类闸门——包括检修口——可在夜间远程开启（S7:L3451-L3461）。

20. **摄像头日志**：深夜 10:00 至凌晨 4:00 间歇性离线（每次约半小时），离线期间无记录（S7:L2207-L2217）。

### 第四部分：下午动作（S7:L2820-L3757）

21. 黑崎欲子在卫生间激活隐身，身披白布、戴破碎面具，在地铁站内制造"幽灵骚动"——运行中推挤乘客、发出惨叫——随后丢弃白布撤离。安保持 U 型棍赶到，将白布扔进垃圾桶，地铁站**未停运**（S7:L2820-L2895）。

22. 一名小女孩看到并大喊："大姐姐为什么不穿衣服？" 父母教育她："离那种人远一点，很危险的"（S7:L2867-L2917）。唐索试图向小孩打听，被家长严厉阻止。

23. 唐索在地铁口附近听居民闲聊。听到有人讨论"今天下午地铁闹鬼"，并提及**每天下午准时会出现的一个女人**——每周六日下午手持白花到地铁站停留约半小时，最初摆花被工作人员赶走，后来改成手持。**但最近两周没来了**（S7:L3663-L3733）。

24. 唐索支付 ¥100 获取更详细情报，但居民描述的该女性外貌"模棱两可、不太可靠"。AI 生成的模拟画像对不上（S7:L3705-L3751）。

### 第五部分：棍木女与白念秋（S7:L3759-L3993）

25. 李好在面馆对面车内蹲守时，驾驶侧车窗被敲响。一名**地雷系穿搭**的女性：遮一只眼的眼罩、黑色口罩、黑色美甲——**唯一露出的眼睛是金色的**（S7:L3785-L3793）。

26. 她以**空灵、近乎无机质的电子合成音**询问："上周白雾蔓延的时候你在这里不在？" 随后开口：**"预言中的神子已经降临了。而你们身上沾染了神子的气息。"**（S7:L3803-L3841）她递给李好**一根木签**：**"这是保护你的东西。"**（S7:L3849-L3853）

27. 询问身份，答：**"我是不存在的存在"**。问："我是答案，但问题是什么？" 答：**"如果我告诉你问题的答案，你也会说你是不存在的存在。"** 她给出名称：**"你可以用棍木来称呼我们。"**（S7:L3865-L3879）

28. 问预言内容，答："预言即是对未来的展望，神子的事到时候预言中的事情只停留在预言之中。" 随后**"先从滚出你的视野开始"**——消失（S7:L3891-L3899）。

29. 她走后，李好手机微信弹出消息——**白念秋**发来："今天晚上有空吗？" 并说从可靠朋友处听说了地铁站闹鬼（包括当天下午裸奔女人的传言）。他计划做灵异探秘节目，希望李好开车并**带一个胆大一点的小朋友**一起去"采点"（S7:L3901-L3993）。

30. GM 宣布：晚上回合留到下一场。额外提示："不是地铁站有（幽灵），是地铁站里面那**延长段**"——GM 一直暗示幽灵不在站内而在封闭延长段（S7:L4005）。

## 已确认事实

- 钢阳街地铁站是正常运营的换乘站，幽灵传闻集中在**延长段（L7-四段）**，而非站内。
- 龙腾轨道交通员工纪律极严（曾经被恶意剪辑媒体坑害），拒绝一切非审批采访。正式员工在休息室摸鱼，站内可见的都是劳务派遣人员。
- 该站因幽灵传闻将下班时间从晚上10点提前到9点，工资小幅下降。
- L7-四段（6号线延长段）2027年1月31日动工，2027年5月10日执行封闭流程，2027年5月12日（大塌陷日）停工。**终止记录在5月23日才被写入**——时隔11天。
- 摄像头在深夜10:00至凌晨4:00间歇离线，每次约半小时。
- 地铁站内网中存在一个虚拟机——管理员操作 inhuman（4鼠标并发、超人类速度），有捕获入侵进程和逆向追踪能力，日志充满活物感。疑似赛博世界数据实体布下的陷阱节点。
- 文件存储中大量 RNVB 文件——总体积恒定但单文件大小动态变化，表现出类似思维活动的特征。
- 安保服务器可远程控制站内闸门（含检修口通道）。
- 每周六日下午有一位女性手持白花到地铁站（疑似悼念），但最近**两周没来了**。
- 棍木（棍木会）是自称"不存在"的组织——地雷系穿搭、金色瞳孔的女性成员主动接触李好，提出"预言中的神子"已降临，并认定 PC 身上有神子气息。她给了李好一根木签护身符。
- 白念秋（明星）因当天下午地铁站"幽灵骚动"的流言产生兴趣，联系李好计划当晚夜探——需要李好当司机并带一个"能看到鬼的小朋友"（目标显然是阿瑶）。
