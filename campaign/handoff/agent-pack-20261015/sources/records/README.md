## 整理约定

- 原始逐字稿不修字、不裁剪、不覆盖。
- 结构化记忆统一写在 `records/memory/`，优先更新：
  - `campaign-state.md`：当前实跑状态。
  - `session-XX.md`：单场摘要。
  - `entities.md`：人物、组织、地点和名称校对。
  - `rules-and-rewards.md`：实跑中已经生效的规则奖励。
- 引用原始记录时使用 `S1:L2451`、`S2:L7469` 这样的行号标记；需要更精确时再补时间码。
- 将内容分为“已发生”“推断”“待确认”。逐字稿自动识别错误很多，尤其是人名，不能把误识别直接当标准名。
- `campaign/` 中保存预案和 GM 设定；当它与逐字稿冲突时，`records/memory/` 记录实际发生版本，并在待办里标注是否需要回填设定文档。备团入口见 [备团索引](../campaign/prep/README.md)。

## 发布边界

这些记录默认不进入 VitePress 站点。若后续要把某些内容整理成玩家可见战报或设定书，需要先做脱敏、剧透分层和语言重写，再移动或复制到 `src/`。
