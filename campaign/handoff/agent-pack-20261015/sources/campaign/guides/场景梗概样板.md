# 场景梗概样板

样板正文：[《铜锅煮局》](../prep/sessions/ep04-义胜盟-新故事.md)。保留用户认可的开场句、内容密度与栏目；人物已按最新要求换用现有 NPC。[用户示范原文](../prep/agy/ep04-redesign-20261009/copper-user-sample-before-recast-08.md)保留查阅。

梗概写几百字，保留有意思、会改变游戏内容的信息，参照样板的内容密度。

- **开场句**：一句话突出刺激之处。
- **事件、地点、环境**：说明在哪里、眼前有什么。
- **参与人员**：每个人的动机，加少量鲜明的性格或外观。
- **可能的发展**：人物会怎样争，场景可能怎样变化。
- **要点**：玩家能介入的事、能发现的异常、有用的场景要素。
- **危险中的行动**：局面变化后，各人会想做什么。
- **场景标签**：概括核心体验。

有用的项才保留。具体演法留给临场；例如白爷只需写“尝试稳住局面”。数值在故事通过后设计。新故事优先复用已有 NPC。
