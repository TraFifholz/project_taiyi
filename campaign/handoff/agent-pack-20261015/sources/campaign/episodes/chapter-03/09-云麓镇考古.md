# 第 9 话 · 云麓镇考古

> 2026-09-03 重整｜现行大纲。这里是故事梗概，不替玩家预定行动。

风格：楚地恐怖与联合调查。主要组织：龙散大学、21-35联合研究所、重黎工业。

## 梗概

云麓镇山体变化暴露祭祀遗址，异常让部分工作人员反复做出古老动作。许承钧推动跨专业调查，苏碧城负责神经与同步影响，杜若负责地形结构；考古工作由普通专业队员承担，不把既有 NPC 随意改成考古老教授。

燕尺素带着重黎需要样本的任务来，也看见受影响的人不该只被当成数据。LR-07 的采样、薄晚的模型和罗鸣谦的研究接触分别服务卜府的不同岗位。祭祀坑里的巫祝是受害者残余与碳铀场形成的群体异常，不是一个知道现代阴谋的古人。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 许承钧 | 寻找可检验的基准资料，必须说明采样风险。 |
| 苏碧城 | 区分现场的生理变化与外来同步，不提前使用潜在能力。 |
| 杜若 | 安排现实安全措施，保护学生与调查人员。 |
| 燕尺素 | 在取得样本与保护受试者之间承担选择。 |
| 卓近火 | 检查通电芯片是否存在异常写入，只给专业范围内结果。 |
| LR-07 | 采集与交接实际样本，保留自己发现的差异。 |
| 凌渡 | 维持有限研究连接，解释接入的退出条件。 |

## 各方冲突

研究队要信息，企业要可用技术，现场人要脱离异常。来自卜府的薄晚、罗鸣谦是附带研究与观察，不给主角强制征召令。

其他参与者：阿瑶可以协助确认与自己有关的片段，也可以拒绝测试；她不是整支调查队的免费仪器。

## 结果与下一话

应对巫祝、救回工作人员与保全样本是不同目标。没有取到样本时，既有记录仍能支持后续调查，但 ARP 需要在第十七至十九话补足关键测量。

苏晦可解释自己的旧误判，文小篆在研究所接收样本。临时减载和抑制的研究方向由本话奠基，不自动宣布永远不需要锚点。
