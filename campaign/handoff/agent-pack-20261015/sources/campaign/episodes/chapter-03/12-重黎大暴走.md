# 第 12 话 · 重黎大暴走

> 2026-09-03 重整｜第三章结算。这里是故事梗概，不替玩家预定行动。

风格：巨型机甲与城市救援。主要组织：重黎工业、丰隆工业、玄盾国际。

## 梗概

韩铸明知安全评估未通过，仍批准新一轮步行机部署，宣称制造共同威胁能换来团结。现场没有能力承担他准许的风险。刑天带领的机器进入红黄区边界，员工与居民必须在回收命令之外自救。主角可以从丰隆设备圈的求助、工人的联系或既有研究线进入，不再另造一位万能副总裁发任务。

周清梅、霍云骧和雷小鼓分别提供维修、设备状态与同步操作建议。白鸢安排辖区撤离，党怀沙奉命优先回收核心。燕尺素让同舟看见报告之外的人，万祁连拿出自己保存的试验记录。刑天则面对是否继续执行、停火或反抗回收的选择。

同舟在 2027 年写给韩铸的历史消息与实际试验记录相互印证，揭开高风险部署、保护机制旁路和碳铀共振事故的责任。那不是刑天穿越时间新发的消息，也不证明所有 AI 觉醒都要以灾难发生。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 韩铸 | 推进部署并推卸责任；员工、同舟或刑天拒绝配合都能削弱其执行能力。 |
| 同舟 | 决定是否继续支持旧理论，交出自己参与过的真实记录。 |
| 刑天 | 在命令与现场经历之间作出自主判断。 |
| 燕尺素 | 解释受试者与机器的反应，争取保住其意愿。 |
| 党怀沙 | 回收核心，必须面对队员伤亡与任务后果。 |
| 万祁连 | 提供原始试验与回收文档，避免证据只靠一个 AI。 |
| 周清梅 | 组织可行的维修与停用，承认无法当场修好的部分。 |
| 白鸢 | 部署撤离与阵地保护，不让所有人只顾抢核心。 |

## 各方冲突

核心八位承担决策，苗铁城、陆文青、霍云骧、雷小鼓、艾德礼、方见按专业支援分散行动，不要求同时站在一个场景里讲话。

## 结果与下一话

先分别结算伤亡、机体控制、意识连续性与证据。韩铸、同舟和刑天都不是必死或必悔改；毁掉核心也不能使员工原始记录自动消失。

许承钧改用允许退出的试验方式。城市更注意主角，既有关系决定后续能得到什么保护；不强制全体被某组织抓走。
