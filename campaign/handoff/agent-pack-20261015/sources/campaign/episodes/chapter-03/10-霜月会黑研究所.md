# 第 10 话 · 霜月会黑研究所

> 2026-09-03 重整｜现行大纲；不预定主角已被植入。这里是故事梗概，不替玩家预定行动。

风格：身体恐怖与研究伦理。主要组织：霜月会、重黎工业、燧明科技。

## 梗概

阿岛俊的社群招募与接口患者的求助把众人引向霜月会的地下实验。鹿岛绫提供场地和业务保护，重黎购买神经与行为数据；何夜白是看见失败后果的校准技师，不把他换名写成疯狂的全能医生。

主角可通过救人、送医、调查或与霜月交易进入。若实际受制或自愿接受测试，再按发生的事处理植入与身体风险；不使用上一话平安、这一话默认全员醒在手术台的跳过。

九条千寻想控制实际实验记录，党怀沙准备回收重黎资产。苏碧城、燕尺素与甘采蓝各有能保护患者的一部分知识，却无法单独保证全身接口安全退出。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 鹿岛绫 | 争取控制事故损失与本地生意，承担实验责任。 |
| 九条千寻 | 保护、夺取或销毁自己能接触的实验记录。 |
| 何夜白 | 处理实际接口问题，反对把患者交回失控试验。 |
| 甘采蓝 | 联系转介与康复，要求把风险告诉使用者。 |
| 苏碧城 | 检验神经同步，不把理论直接当作安全保证。 |
| 燕尺素 | 争取受试意识表达自己的选择，并把经历带给同舟。 |
| 党怀沙 | 回收设备、数据与人员，可能与救援目标冲突。 |

## 各方冲突

霜月生意、重黎试验与医疗救助彼此牵制。黑川的组织指令只影响本方责任处理，不现场替所有人脱罪。

其他参与者：阿岛俊提供自己经手的招募内容，面对承诺与患者遭遇之间的差异。巫明烛按认证命令争夺实验资料，不受白鸢临时指挥；救助一方需避让、阻止或另行取得权限。黑川只决定霜月会如何处理暴露的业务。

## 结果与下一话

患者是否被救出、记录归谁、接口能否移除分别处理。燕尺素把受试经历交给同舟，苏碧城将接口伤害与无法退出的记录交给许承钧。二者分别面对后果；许承钧暂停以受试意识模拟锚点、却不能保证退出的试验，继续减载和被动抑制研究。

方见与卓近火可检验器件，陈斌处理实际伤情。旧研究把竞技适配与泥人项目联系起来，进入第十一话；不得以身体控制永久剥夺玩家操控角色的权利。
