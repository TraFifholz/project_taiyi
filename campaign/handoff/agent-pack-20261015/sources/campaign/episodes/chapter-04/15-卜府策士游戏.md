# 第 15 话 · 卜府策士游戏

> 2026-09-03 重整｜现行大纲；不预定成功绑架。这里是故事梗概，不替玩家预定行动。

风格：密闭谈判与反制实验。主要组织：卜府、21-35联合研究所、阿奎拉家族。

## 梗概

言璞以资料交换为由邀请不同利益方到公馆，再试图限制离开，观察人在有限时间与资源下如何互相对待。卢卡来谈交易，凌渡来查研究，纪慎微质疑同意程序；不新造一对与故事无关的研究员夫妇。

罗鸣谦组织邀约并记录承诺，薄晚保留被模型排除的例外，玄圭必须面对自己经手的授权。苏晦以原始资料换取受监督的远程对质，不因为需要登场就走进通缉者的控制区。

主角可以入场、拒绝邀约后从外部协助，或在发现限制后夺回控制。没有必须按照言璞的题目伤害一组人才能证明人性的规则。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 言璞 | 想让新结果证明自己仍然正确，必须面对强迫实验本身的偏差。 |
| 薄晚 | 公开被剔除的样本与实际例外，不替模型伪造一致性。 |
| 罗鸣谦 | 对邀请内容与实际限制之间的差异作出选择。 |
| 玄圭 | 复查自己签发的授权，能撤回自己经手的限制。 |
| 纪慎微 | 帮助当事人厘清同意与责任，没有直接审判权。 |
| 凌渡 | 以研究者身份争取真实资料和安全退出。 |
| 卢卡·阿奎拉 | 保护本方谈判者与交易，不愿成为研究耗材。 |
| 苏晦 | 远程对质旧模型，并承认自己也曾误判。 |

## 各方冲突

各方对资料、承诺、安全的需求相互牵制。LR-07 和何问舟可提供自己经历过的机构做法；不因他们露面就让全案自动成立。

## 结果与下一话

言璞可以停试验、失去控制或继续顽固。主角的选择只证明这些人在这个处境做了什么，不自动推出整个人类必定选择某个结局。

得到的旧研究指向纪崇吾的维护岗位；言璞后续只能撤回自己能控制的限制，不替郑启明、全部卜府或玄盾同时投降。
