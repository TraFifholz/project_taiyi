# 第 7 话 · 旧城寻宝

> 2026-09-03 重整｜现行大纲。这里是故事梗概，不替玩家预定行动。

风格：废墟探索与社区生活。主要组织：九渊建设、重黎工业、灰区居民、归城项目。

## 梗概

甘棠与老井对一处旧工程的记忆并不相同，葛兆康留下的现场照片使调查有了现实入口。废弃库房中的旧服务器保存着约十二万居民的户籍资料。灰区居民要用它证明自己的生活与财产曾经存在，梁文川则想用它补全复现实验的环境。

重黎要回收旧设备、避免项目资料外流；周清梅和苗铁城却更关心设备还能否安全使用。主角面对退化的 SR-7，也面对活人之间的分配：数据属于研究者、保管者，还是被记录的人？这不靠击败机器就自动解决。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 甘棠 | 核对旧图纸与工程归口，面对自己曾忽略的异常。 |
| 老井 | 说明实际施工和后来变更，与前徒弟相互校验。 |
| 葛兆康 | 带人找到自己确实见过的施工点。 |
| 周清梅 | 检查回收机器，提出现场停用或修复办法。 |
| 苗铁城 | 辨认产线来源，保护可能被回收责任牵连的工友。 |
| 萨布里娜·费雷拉 | 帮助居民表达权属与安置诉求，按康复状态行动。 |
| 梁文川 | 以技术与资金争取使用档案，开始隐瞒使用风险。 |
| 杜若 | 用土木专业核对建筑和通路，不冒充考古或异常万能专家。 |

## 各方冲突

四方数量是本话必要例外：工程档案、企业回收、居民权利和归城采购确实指向同一批资料。居民不是等着送宝物的背景群众。

其他参与者：万祁连辨认旧设备归属，于正清协助核对居民权属。沈漫追索失踪者在旧城留下的实际关系，阿瑶问起自己失去肉身后的那三年；红皇后只说明旧接口支持哪些操作，不代替居民授权。

## 结果与下一话

可以保全、分权使用、复制经同意的部分资料或失去一部分设备。梁文川得到多少取决于行动；实验若缺资料会更不稳定，不在下一话凭空补齐。

田进财、苏小晚、秦时雨提供自己走过的路线，宋光明和贾红负责实际维修，邢九重验证更深的通路；闻笙测到的只是危险区域，不替所有人决定档案用途。
