# 第 5 话 · 帮派奥运会

> 2026-09-03 重整｜现行大纲。这里是故事梗概，不替玩家预定行动。

风格：荒诞竞技与黑市交易。主要组织：义胜盟、霜月会、阿奎拉家族。

## 梗概

地下赛事既是热闹，也是三家谈地盘、债务和货物的场合。卫铁生邀请主角参赛或做见证，杨振邦负责报名和赌注；拒绝参赛也可以从接头、护送与交易侧进入。卢卡代表家族谈仓储，不再另造太子爷和无名大佬。

梁文川的接口与旧设备采购抬高了部分货物价值。九条千寻为霜月争夺交易记录，马铁鹰若从第三话脱身，还要面对自己撕毁交易的后果。比赛中的胜负会改变名声，场外谁肯履约则改变关系，两者不绑定。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 卫铁生 | 争取有分量的参赛者，维护黄区利益。 |
| 杨振邦 | 处理报名、押金与赛果，不保证主角获胜。 |
| 纪小刀 | 想靠比赛证明自己，既可竞争也可结识主角。 |
| 卢卡·阿奎拉 | 以顾问身份谈交易，拒绝不稳定的货物和夸大的担保。 |
| 鹿岛绫 | 争取医疗接口与娱乐区生意的主动权。 |
| 九条千寻 | 行动目标是夺取实际交易材料，不用读心能力替代调查。 |
| 闵三元 | 查赛事现金与押金去向，担心有人抽走帮众周转钱。 |
| 西尔维娅 | 救助受伤帮众，反对将所有异常者当作可售资源。 |

## 各方冲突

三家并非为了归城统一行动。赛事名声、现金流、接口技术和地方信誉会使同一组织内部也意见不同。柳拂衣与铁手处理各自承诺，宋远坚持不把人当货。

## 结果与下一话

比赛成绩、交易得失与个人承诺分开记录。没有强制刺杀成功或自动结拜。归城采购只露出实际需求，不直接解释梁文川的全部计划。

阿岛俊的活动导流、贺梦琪阻拦危险招募以及周凛的接头业务进入后续；章间由程雯、沈仲秋安排阿瑶的适龄学习。
