# 第 18 话 · 龙散大反攻

> 2026-09-03 重整｜现行大纲；多组织例外。这里是故事梗概，不替玩家预定行动。

风格：城市协作与多线行动。主要组织：资办、玄盾国际、ARP、城市互助与各既有组织。

## 梗概

郑启明推动封锁，主角需要把有限深层通路变成能送进人员和设备的现实行动。此时城市关系真正产生作用：有人愿意保护一段街道，有人只肯借设备，有人要求先安置家属，也有人坚持不合作。

沈漫与许承钧争取向白鸢说明人祭实情，并拿出可以检验的维护与撤离方案。主角可协助、旁观、反对或改提别的方案。玄圭只能处理自己签发的限制，伊莱恩提交的报告会影响上级，不决定所有队伍的想法。启示录也会争取相同的入口和设备；萧烬能动用什么取决于第十四话的结果。

上一话若测得身体仍依赖阿瑶，转移路线必须保留供能和持续连接；许承钧随设备到位继续测试，不能让六个人分散后才发现断链。

本话按救援、设备运输、证据公开和入口行动分散处理。只有前面真的建立过关系、当前有能力且愿意参加的人才提供帮助。不是把所有 NPC 召到同一个战场。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 郑启明 | 推进封锁，要求优先恢复旧锚定安排。 |
| 许承钧 | 组织过渡设备与基准核对，公开说明条件与局限。 |
| 沈漫 | 先安置受波及的人，再争取救出旧友。 |
| 白鸢 | 根据证据与可执行方案决定辖区行动，不控制全体玄盾。 |
| 玄圭 | 复查自己经手的授权，拒签越权限制或继续坚持。 |
| 沈仲秋 | 负责事务所与熟悉居民的实际安置交接。 |
| 萨布里娜·费雷拉 | 协调居民意愿、康复需求与运输安排。 |
| 萧烬 | 若仍有能力，争取控制通路与设备，使局势朝自己的方案发展。 |

## 各方冲突

本话有意超过通常组织数量，因为前文关系要在真实资源和行动中得到回应。援助不是善恶积分奖励，拒绝合作也不抹掉一个人的既有价值。

## 结果与下一话

分别确认入口、设备、人员和疏散成果。封锁控制的是人员与设备进出，不会挡住碳铀场失控；维持旧锚定可能争取时间，阻断抑制设备则削弱替代方案。即使未能突破全部封锁，也可采用较少人员、延后部分设备或重新协商，但过渡窗口与风险会随之变化。

第十九话只使用真正送达的设备和仍存续的连接。所有援助条件见本话下方表格，不写十八话所有朋友必然到场。

## 城市援助如何成立

下表是可争取的行动，不是全员自动到场名单。同一人可留在后方；关系恶化、受伤、死亡、物资耗尽都会改变可用帮助。缺少某一组时，先缩小行动范围、另付现实代价或争取其他组，不把全城合作当作进入第十九话的唯一门票。

| 要做的事 | 可能参与的人 | 援助成立的条件与限制 |
|---|---|---|
| 疏运居民与物资 | 赵明芝、苏小晚、交管7号、田进财、单小鹿 | 自愿司机、骑手与实际可用车辆；7号须仍存续且愿意提供有限协助，不替人类决定去留。 |
| 轨交疏散 | 秦时雨、钟月台、童司南 | 核实安全线路和班次后才能运行，不把废线当现成出口。 |
| 维修与地下施工 | 甘棠、杜若、邢九重、老井、于正清、宋光明、周清梅、霍云骧 | 有图纸、实测和设备；各人只保证检查过的部分。没有完整线路时先修局部。 |
| 辖区保护 | 白鸢、艾德礼·霍华德、伊莱恩·莫罗、郁垒 | 已取得可核查证据及现实救援方案；指挥只在各自权限内。巫明烛仍可能执行相反命令。 |
| 街面接应 | 卫铁生、铁手、柳拂衣、闵三元、鹿岛绫、西尔维娅 | 先前承诺、组织利益与当前能力都要成立；鹿岛绫还须面对实验问责，救人不能购买免责。 |
| 日常安置与医疗 | 沈仲秋、萨布里娜·费雷拉、林彬、谢翠莲、程雯、陈斌、周敏 | 按住处、餐食、家属、病情和熟悉辖区分工，先明确接收人数；不让失联者只剩登记数字。 |
| 基本兑付与身份保护 | 陈志远、金舸、何凌 | 使用经授权的资金与资料；何凌维持身份和家属联系，不取得全银行或全城的调度权。 |
| 证据、避险信息与复核 | 纪清商、向柳、秦有邻、纪慎微、薄晚、玄圭 | 核实来源、保护证人；报道不等于裁决，模型不等于必然预言，玄圭只复查自己经手的限制。 |
| 场外联络 | 闻笙及先前建立联系的社群 | 保持失联登记与现实联络点；异常预测只作风险提示，不保证每一次转移安全。 |

没有获得援助的组织仍在城市里行动：可能自保、撤离、阻挠或保持中立。不要把未被招募的 NPC 写成突然消失。
