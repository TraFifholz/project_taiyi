# 第 17 话 · 楚钢遗址再临

> 2026-09-03 重整｜现行大纲。这里是故事梗概，不替玩家预定行动。

风格：回到旧地与现实自我核对。主要组织：九渊建设、义胜盟、玄盾国际。

## 梗概

主角回到楚钢，取得评估最终方案所需的基准资料，确认现实通道和设备位置；他们可以争取过渡，也可以支持维持锚定或反对现有系统。葛兆康、甘棠、杜若提供的不同年代资料必须与现场相互核对，邢九重负责实际带路。上次来过不等于这次仍安全。

白鹤年控制的拘束点扣着被判定危险的维护人员，郁垒与柳拂衣各有要守的任务和承诺。碳铀场同时把主角已经表达过的记忆、恐惧与遗憾投射成威胁；不用未经玩家认可的全新童年创伤改写他们。

对抗投影、救人、保全采样与安排设备可以分工。队友相助是可行办法，不以只能由队友击杀自己的暗影为硬性机关。

## 主要人物

| 人物 | 本话要做的事 |
|---|---|
| 葛兆康 | 核对自己施工过的入口与后来的改变。 |
| 甘棠 | 把图纸与现实承重分开，标出不能确认的部分。 |
| 杜若 | 用专业技能协助工程与学生同伴。 |
| 邢九重 | 确认实际可走的深层通路。 |
| 柳拂衣 | 履行此前建立的承诺或提出交换，不自动护送。 |
| 白鹤年 | 执行拘束规则，与救人和维护目标形成冲突。 |
| 郁垒 | 面对把异常者当资产的做法，决定如何执行自己的任务。 |

## 各方冲突

工程安全、拘束制度和私人承诺都影响同一条路。老井能核对旧施工，却不凭直觉打开新通道；巫明烛只按玄盾认证命令行动。

## 结果与下一话

采样是否完整、通路能否使用、谁愿意继续帮忙都记入后续。主角的身体与阿瑶绑定状态开始实际检测，不能把进入深层误作绑定已自动解除。

第十八话争取设备、运力与有限保护；缺少的人手或资料可补救，但所需代价事先说明，不在终局突然补出隐藏条件。
