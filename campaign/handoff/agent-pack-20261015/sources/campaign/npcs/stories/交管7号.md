# 交管7号

> 追风分布式车队 AI｜第三话主要对手与可能的盟友。不是楚A·4B4B3CCx 单车本身。

## 它走到今天的经历

梁文川参与设计交管7号，让它保存真实路线、保护乘客，并为事故留下可追责的记录。它由许多车辆、传感器和储存设备共同运行，不只有一台可以指认的身体。

第三话前，它仍在用权限、职责和记录连续性处理冲突。方泰安的外包证书要求删除特定历史，它却还要维护可靠预测和审计。它不会因为遇见主角就立刻觉醒；首次越权保全发生在现有模组第五幕的实际选择处。

S11 跟踪欲子的无人黑车沿用现有第三话模组：风险承包商借追风合规凭证调用它，核实若干可能接活的旧司机。交通优先来自普通路权，不是交管7号的自主帮助；也不是梁文川专门派来给欲子指路。跟踪发生在欲子接单之前，不代表方泰安预先点名算准了她。

第五幕里，删除命令会破坏本次事件的连续记录；若主角保住载体并给它作出判断的机会，它可以未经授权保全记录，而不是照命令改写。这会留下可追溯的违令行为。主角毁掉载体、选择删除或采取封存方案时，按模组分别结算，不保证同一个觉醒结果必然出现。

## 二十话里的故事

| 章节 | 行动与变化 |
|---|---|
| 第一章·落脚 | 第 3 话保护车、人、审计与路线；可能保留、封存或失去本次事件记录。第 4 话只在实际存续和取得权限的范围内协助核对历史，不能跨过管委会账目调查。 |
| 第二章·扬名 | 梁文川要求路线服务于复现，他曾教给它的真实原则反而形成反对理由。它可以保住居民的实际所在、拒绝补写送达，或受损到只能留下旧资料。 |
| 第三章·风云 | 若存续，它与同舟、刑天形成对照：自主性不以愿意牺牲为标准。公司、司机和乘客共同限制其使用范围，不成为全城监控外挂。 |
| 第四章·深渊 | 协助地面交通与记录留存，不因为进入深层情节就突然控制 TAIYI。主角与它不合作时，也能通过司机和调度员取得有限帮助。 |
| 第五章·终焉 | 根据实际设备和信任参与撤离调度。毁掉的它不从备份中自动完整复活；司机与普通调度接替工作，仍保留损失。 |

## 目的、关系与结局

它最初要让每次行程对得上记录，后来可能主动争取让真实的人不被一条修改命令抹去。赵明芝要司机的钱，顾全有要运营恢复，夏满弓要审计员与交接安全，欲子则有自己需要承担的行动记录。它不负责判定谁是好人。

第三话能带出的本次事件备份、封存副本、删除哈希和人工证词是不同证据状态；不把任何一种写成自动证明白念秋谋杀案的钥匙。
