# 龙散战纪主线方案稿

状态：方案稿 v0.2  
用途：供后续 agent 扩写五条故事线与五个章节文件。  
保密级别：GM 剧透，不进入 `src/` 玩家手册。

## 0. 设计约束

已知开头：

- PC 在 5月24 上午码头事件中死亡或濒死。
- 阿瑶从照片/数据流中现身，修补并复活 PC。
- 沈漫随后登场。
- 下一幕从随缘事务所醒来开始。

已知结尾：

- PC 抵达电子祭坛前。
- 资办、ARP/济世计划、启示录、卜府、朱蘅、朱见微、阿瑶等立场摊牌。
- 结尾停在玩家做最终抉择前，不替玩家决定路线。

硬约束：

- 章节首尾相接。
- 第 1 章处理并完结故事线 1，同时滴渗线 2 和线 3。
- 第 2 章处理并完结故事线 2，同时滴渗线 3 和线 4。
- 第 3 章处理并完结故事线 3，同时滴渗线 4 和线 5。
- 第 4 章处理并完结故事线 4，同时滴渗线 5。
- 第 5 章处理故事线 5。线 5 基本确定为碳铀/人祭线。
- 所有既有组织/企业至少在一个章节中出现并发挥功能。

执行原则：

- 每章不要写成组织百科。每章用 5-7 个可跑场景承载组织。
- 每个组织只需要在一个关键场景发挥一次不可替代的功能。
- 阿瑶的“呼唤”是明面主线，五条暗线都必须解释她为什么会被更深处吸引。
- 现有实跑优先于旧预案。旧楚钢 Day 7 团灭预案已被 5月24 码头事件取代。

## 3. 第 1 章：旧城回声

章节目标：

- 处理 5月24 码头事件余波：黑骑士/乌鸦群、蓝色数据流、阿瑶照片、沈漫带回 PC。
- 接住“PC 在随缘事务所醒来”的开头。
- 让 PC 学会新状态：奇能显化、阿瑶共振、现实记录被改写。
- 完结旧城控制网；方泰安作为外围受益者或候选主使处理，不提前证明他理解深层真相。
- 给红区失踪者线和重黎/楚钢线留下明确物证。

阿瑶主线推进：

- 状态：虚弱、失忆、刚从照片/数据流中脱离。
- 感知：她能指出旧城公共系统方向，但会被黑骑士残响和乌鸦数据羽片干扰。
- 误判：她以为呼唤可能来自某个“还在码头的人”。
- 玩家影响：如果 PC 保护照片残壳并安抚阿瑶，她能稳定给出“向下”的方向；若忽视她，后续呼唤更混乱。

|---|---|
| 随缘事务所 | 醒来地点、短期据点、沈漫提供第一委托 |
| 旧城管委会 | 方泰安调动公共权限的外壳 |
| 云梦科技 | 旧城节点和 TAIYI 接口的技术来源 |
| 玄盾国际 | 封锁码头/旧城，提供现场武力压力 |
| 引资银行 | 旧城重建款和异常小额转账的证据来源 |
| 追风出行 | 提供码头前后人员/车辆行程空洞 |
| 龙腾轨道交通 | 提供封站和异常客流记录 |
| TAIYI/天穹钱包 | 记录改写与身份连续性的核心系统 |

| 方泰安 | 旧城管委会腐败节点，可能是外围受益者或候选主使 |
| 翟明珠 | 提供云梦旧城节点入口，但不完全知道深层真相 |
| 陈志远 | 从引资银行侧面给李好压力和审计入口 |
| 何林/何玲（待确认是否并入何凌） | 证明类似照片和记忆异常在银行线中已出现 |
| 白鸢 | 玄盾现场对手，可被事实动摇 |
| 黑骑士/乌鸦群 | 码头事件压迫源，本章只留下追踪残响，不解释真身 |

场景链：

1. 码头事件余波/醒来前十分钟
   - 地点：蓝色数据流空间残影、随缘事务所醒来前的碎片记忆。
   - 玩家行动：回忆死亡前最后画面，确认自己如何被带离码头。
   - 获得线索：黑骑士没有追进阿瑶展开的修补区域；乌鸦群留下黑色数据羽片；沈漫用紫火切断追踪，把 PC 带回随缘事务所。
   - 照片状态：暂定原件仍在李好处，但人物影像变淡，边缘有蓝色数据灼痕，成为锚点残壳。
   - 失败后果：若 PC 忽略碎片，黑骑士残响会在后续调查中以更危险形式出现。

2. 随缘事务所醒来
   - 地点：随缘事务所。
   - 玩家行动：确认身体状态、奇能变化、阿瑶状态，询问沈漫。
   - 获得线索：码头事件被官方记作普通治安事故；所有 PC 的死亡记录不存在；阿瑶能指出旧城方向。
   - 失败后果：PC 若不主动查，沈漫用“你们的身份正在被系统修补”制造时限。

3. 码头记录三线回查
   - 地点：引资银行、黄区住所、追风订单后台、地铁站、Spirit 邮件记录、龙门调度/铁铺委托来源。
   - 玩家行动：各自查自己的账户、行程、联系人。
   - 获得线索：码头前后数小时出现统一空洞；追风订单和龙腾封站记录被替换；天穹钱包流水存在异常补丁；Spirit 坐标、龙门调度任务和铁铺取货都被回填成普通委托。
   - 失败后果：方泰安控制网更快锁定 PC，后续潜入难度提高。

4. 引资银行审计线
   - 地点：引资银行龙散分行。
   - 玩家行动：通过陈志远和何林/何玲查旧城重建款、方泰安关联账户和类似照片线索。
   - 获得线索：旧城重建资金被拆成民生补贴、安保外包、临时救助项目，其中部分接向红区和望津港；何林/何玲提到港资背景老总处也有类似女孩照片。
   - 失败后果：银行系统标记李好异常，形成追踪压力。

5. 云梦旧城节点
   - 地点：云梦科技维护接口或旧城节点机房外围。
   - 玩家行动：通过翟明珠进入原始记录缓存。
   - 获得线索：码头存在异常设备和人员转运；黑骑士/乌鸦群在原始缓存中表现为无法分类的数据阴影；阿瑶靠近节点时听到“向下”的呼唤。
   - 失败后果：云梦安全系统触发，玄盾提前介入。

6. 玄盾封锁现场
   - 地点：码头/旧城边缘封锁线。
   - 玩家行动：潜入、交涉或绕过白鸢的巡逻。
   - 获得线索：玄盾收到的命令来自旧城管委会临时安全权限，但命令链不完整。
   - 失败后果：与白鸢正面冲突；白鸢后续更难被说服。

7. 旧城管委会应急控制中心
   - 地点：旧城管委会控制中心。
   - 玩家行动：切断旧城临时控制网，夺取原始账本，判断方泰安到底知道多少。
   - 高潮：方泰安用“公共安全”和“旧城稳定”压制 PC，试图把他们打成危险异常人员；若需要更深主使，可让控制网里出现无法归属的更高权限租用痕迹。
   - 获得线索：未清洗物流账本、失踪名单、走失儿童互助会/信浸会、望津港、重黎旧设备编号、楚钢步行机维护痕迹、龙门调度相关机械编号。
   - 失败后果：方泰安逃脱或只暴露为替罪羊，但控制网仍局部崩溃，PC 只能拿到残缺账本。

本章暴露：

- 城市记录可以被人为修正。
- 方泰安不是神秘终局，至少目前只是用公共系统掩盖腐败和异常转运的地方权力者；他背后可能还有更深权限租用者。
- 黑骑士/乌鸦群不是普通战斗敌人，其残响与阿瑶照片和旧城节点都有关。
- 阿瑶的呼唤和旧城公共节点有关，但源头更深。

章节结尾：

- 旧城控制网被击破，方泰安或其背后权限租用者暴露。
- 物流账本指向红区、望津港、走失儿童互助会/信浸会和港资老总类似照片，导入第 2 章。
- 机械步行声、龙门调度、重黎旧设备编号和楚钢痕迹暂时看不懂，作为第 3 章伏笔。

## 4. 第 2 章：红区失踪者

章节目标：

- 完结红区失踪人口和转运链。
- 把帮派、物流、诊所、公益组织收束成一条可跑链路。
- 接入宋远双头鹰、凯芙拉港口质检线、雷武龙铁铺到龙门调度任务。
- 让阿瑶听见“许多人的残响”，但确认真正呼唤还在更深处。

阿瑶主线推进：

- 状态：能短暂清醒行动，但对人群残响非常敏感。
- 感知：她听见许多失踪者的求救、空白记忆和被替换身份。
- 误判：她一度以为呼唤源就是失踪者转运链。
- 玩家影响：PC 若优先救人，阿瑶更愿意相信自己的力量不是灾难；若只追线索，阿瑶会更倾向把自己看成工具。

相关组织：

场景链：

1. ARP 接触
   - 地点：21-35 联合研究所外围或安全屋。
   - 玩家行动：见朱见微，理解替代锚点方案的表层逻辑。
   - 获得线索：资办准备提前献祭阿瑶；启示录也在同一时间行动。
   - 失败后果：ARP 信任不足，提供的资源更少，但坐标仍给出。

2. 九渊地下通道
   - 地点：旧城/九渊维护通道。
   - 玩家行动：进入地下终局层，避开或突破玄盾封锁。
   - 获得线索：九渊长期维护的不只是地基，而是祭坛物理设施外围。
   - 失败后果：玄盾追击压力上升，白鸢更晚动摇。

3. 楚钢/重黎旧层
   - 地点：楚钢遗址深层。
   - 玩家行动：穿过泥人计划残余和步行机旧层。
   - 获得线索：前四章的工业真相只是电子祭坛外围症状。
   - 失败后果：消耗资源，启示录推进更快。

4. 云梦/TAIYI 深层
   - 地点：TAIYI 深层接口、钱包/身份结算抽象空间。
   - 玩家行动：在数据流中保持自我，保护阿瑶。
   - 获得线索：TAIYI 是数字堤坝，城市身份、钱包、交通、安防都被用作稳定结构。
   - 失败后果：PC 身份出现临时崩解，最终谈判筹码减少。

5. ARP 封存区与替代锚点校准
   - 地点：21-35/ARP 封存设施或其深层接口。
   - 玩家行动：取样、校准、保护朱见微团队，确认替代锚点方案是否真的可行。
   - 获得线索：ARP 接近成功但不确定，短期窗口存在巨大风险；PC 可以拿到支持第三路线的技术筹码。
   - 失败后果：玩家对第三路线信心不足，但仍可选择，只是代价更高。

6. 祭坛外围三方阻断
   - 地点：电子祭坛外围控制环、祭坛隔离层、方舟网络接口。
   - 玩家行动：阻止郑启明启动提前献祭流程，争取白鸢或玄盾一线，拦截萧烬和启示录破坏隔离层，确认方舟网络是否真实存在。
   - 获得信息：资办路线的筹码是“献祭后堤坝会立即稳定，短期伤亡最低”；启示录路线的筹码是“方舟网络真实，部分失踪者自愿加入”。
   - 失败后果：阿瑶更接近被锁定，隔离层受损，云梦压力上升，最终选择时间变短。

7. 电子祭坛前摊牌与抉择前停顿
   - 地点：电子祭坛核心。
   - 玩家行动：面对郑启明、朱见微、萧烬、苏晦、朱蘅残响和阿瑶，整合三条路线的证据与代价。
   - 高潮：三方路线摊牌。
   - 获得信息：碳铀、云梦、数字堤坝、人类锚点、朱家血脉、朱蘅布局、三种结局。
   - 失败后果：这里不以失败进入坏结局，而是以信息不完整、筹码不足影响最终选择。
   - 结尾：阿瑶站在祭坛前，第一次完整知道自己可能成为祭品；玩家决定即将发生。

本章暴露：

- 碳铀是龙散地下“龙气”的真相。
- 云梦是碳铀失控后的灾害形态。
- TAIYI 是数字堤坝，但需要人类意识锚点。
- 朱蘅是上一代锚点，阿瑶是下一代祭品。
- 三种路线都有爱的逻辑，也都有代价。

三种抉择应保持：

| 路线 | 支持者 | 代价 |
|---|---|---|
| 继续轮回 | 资办部分正派/腐败派、卜府主流 | 阿瑶被献祭，城市继续运转，人祭体系延续 |
| 云梦降临 | 启示录、朱蘅的母性极端面 | 城市和现实秩序毁灭，方舟幸存者重建 |
| 赌上可能性 | ARP、朱见微、朱蘅最理想布局 | 杀死朱蘅暂停灭世，不献祭阿瑶，在短窗口内赌替代方案 |

最终抉择前，每条路线都应有可验证筹码和可行动阻碍：

| 路线 | 可验证筹码 | 可行动阻碍 |
|---|---|---|
| 继续轮回 | 资办能证明献祭后堤坝会稳定，且短期伤亡最低 | PC 可揭露资办腐败面、争取白鸢和玄盾一线拒绝押送阿瑶 |
| 云梦降临 | 启示录能证明方舟网络真实存在，且有部分失踪者自愿加入 | PC 可破坏启示录爆破/断锚步骤，或证明人类合作不需要毁灭来筛选 |
| 赌上可能性 | ARP 能完成一次短时替代锚点稳定测试 | PC 必须争取时间、保护取样/校准设备，并面对失败后云梦失控的风险 |
