# 主线梗概写作委托说明

用途：交给其他 agent 写五条故事线和五个章节梗概。  
优先级：本文件高于本目录其他主线设计文件。  
目标：产出创意种子，不产出跑团剧本、场景链或玩家行为反应树。

## 核心方法

先写世界正在做什么，再写玩家可能从哪里撞进去。

每条故事线和每个章节都必须先成立一个“事件发动机”：某些组织或 NPC 正在推进一件具体事务。这件事务要有目标、动作、资源、时限、阻力、默认结果。

写作顺序固定如下：

1. 先定义事件名：例如清淤、转运、测试、封锁、换锚、归档、招募、献祭。
2. 再定义参与方：每个组织/NPC 要写清目标、当前行动、可用资源、顾虑、下一步。
3. 再定义行动时钟：3-5 个阶段，写世界如何自动推进。
4. 再定义无人介入结果：玩家不出现时，这件事如何收束。
5. 再定义冲突点：组织之间如何互相抢时间、甩锅、交易、误判、背刺。
6. 最后才写玩家可能介入的位置；每章最多 3 条。

一个合格章节在删掉所有“玩家”字样后，仍然应该能看出世界会自己推进到坏结果。

## 故事线设计格式

每条故事线按以下结构写：

### 故事线X：名称

**内容**：这条线中，哪些组织/NPC 在长期推进什么事务。写具体事务，不写主题宣言。

**故事作用**：它在长篇战役中承担什么结构功能，例如引出城市控制系统、人口转运链、工业军事遗产、信息归档体系、碳铀/人祭终局。

**事件发动机**：这条线的长期行动机器。至少包括主导者、被利用者、受害者、资源、时限或升级机制。

**滴渗方式**：按章节列出暴露内容。暴露内容必须是具体东西：名单、货柜、合同、尸体、设备编号、账号、仪式残件、组织动作、NPC 失踪或倒戈。

**与阿瑶主线的关系**：写阿瑶听见什么、误判什么、确认什么、被什么争夺或定位。不要写情绪主题。

**完结状态**：这条线在哪章完结，完结后世界状态如何改变，留下什么后果。

## 章节设计格式

每章一个文件，按以下结构写：

# 第X章：章节名

建议等级段：X-X 级。  
章节事件一句话：某组织/NPC 正在某时限内完成某件具体事务。

## 相关组织与 NPC

| 组织 | NPC | 目标 | 当前行动 | 若无人阻止会怎样 | 本章一句话功能 |
|---|---|---|---|---|---|

要求：每个组织/NPC 都必须有主动动作。不能只写“提供线索”“知道真相”“作为背景出现”。

## 本章事件发动机

- 事件名：
- 主导者：
- 表面事务：
- 实际事务：
- 行动时钟：
- 无人介入结果：
- 组织间冲突：

## 章节故事梗概

用 6-10 段写完。每段必须满足：

- 有明确行动主体：组织或 NPC。
- 有正在执行的动作。
- 有动作对象：人、货、钱、设备、地点、账号、记录、仪式材料。
- 有后果：推进、拖延、转移、暴露、失控、灭口、抢夺、封锁。

不要按“场景 1、场景 2、高潮”写。不要按“玩家先做什么，再做什么”写。

## 冲突与冒险种子

写可扩展成长期冒险的素材：

- 可战斗的敌人或武装力量。
- 可探索的地点、地城、设施、交通线。
- 可争夺的资源、证据、人员、货柜、服务器、仪式材料。
- 会自行升级的支线威胁。

#### 故事线X进展

按实际涉及的故事线分别写四级标题。只写本章暴露了什么具体内容，以及这条线在本章结束后的状态。

## 阿瑶主线推进

写阿瑶的呼唤方向如何变化。内容必须具体：信号来源、误判对象、共振地点、被谁定位、获得或失去什么记忆碎片。

## 允许预设的玩家关键介入

最多 3 条。只写关键介入点，不写反应树。

## 禁写内容

禁止写场景链：

- 不写“场景 1 / 场景 2 / 高潮”。
- 不写“玩家行动”“成功后果”“失败后果”。
- 不把章节写成调查流程或线索清单。

禁止把世界写成等待玩家探索：

- 不写“NPC 知道某线索”就结束；必须写 NPC 正在做什么。
- 不写“组织用于提供线索”；必须写组织正在推进什么利益。
- 不写“如果玩家不查就没有事发生”；必须写无人介入时世界如何推进。

禁止写玩家行为反应树：

- 主文不要写“如果玩家做 X，组织就 Y”。
- 先写组织默认行动，再在最后列最多 3 个玩家关键介入点。

禁止写上价值废话和抽象评语：

- 不写“这不是 X，而是 Y”。
- 不写“本质上”“真正的危险是”“展现出”“象征着”“隐喻着”。
- 不写“让玩家意识到/认识到/面对”。
- 不写段末哲理句、主题升华句、城市评价句。
- 不写没有行动主体的概括段。

所有抽象判断都要改成具体行动。

坏例子：

> 旧城不是突然变坏，而是展现出它一直以来的运作方式。

改法：

> 旧城协管上午九点封楼，承包商十一点进场拆门，玄盾下午接管路口，天穹钱包在晚上冻结未登记居民的补偿入口。

## 自检清单

交稿前逐条检查：

1. 删掉所有玩家相关句子后，章节是否仍会自动推进？
2. 每个组织/NPC 是否都有目标、当前行动和无人介入结果？
3. 本章是否有明确事件名和行动时钟？
4. 故事梗概是否主要写组织/NPC 行动，而不是玩家查线索？
5. 是否避免了“这不是 X，而是 Y”“本质上”“让玩家意识到”等抽象句？
6. 故事线暴露部分是否使用 `#### 故事线X进展` 四级标题？
7. 每章玩家关键介入是否不超过 3 条？
8. 是否提供了足够的战斗、地点、资源争夺和支线威胁，能支撑长篇冒险扩写？
