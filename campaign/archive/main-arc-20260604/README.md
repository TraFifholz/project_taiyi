## 新方向

后续主线设计不写场景链，不写跑团剧本。核心产物是能支撑长篇战役的创意种子：

- 组织和 NPC 的动机。
- 他们正在做什么。
- 本章事件发动机：正在发生的大事、行动时钟、关键组织动作、无人介入结果。
- 章节故事梗概。
- 故事线在本章暴露什么内容。
- 阿瑶追逐“呼唤自己的声音”的推进。
- 可发展成战斗、地城、支线和长期威胁的冒险生态。

## 扩写要求

如果派其他 agent 继续写作，请把 `agent-writing-brief.md` 作为最高优先级执行依据，`campaign-arc-seeds.md` 只作为设定材料，并明确要求：

1. 禁止把玩家当演员。
2. 禁止把章节扩成场景链剧本。
3. 每章最多预设 3 条玩家关键介入。
4. 主要篇幅写世界局势、组织行动、NPC 动机、冲突升级。
5. 每章故事梗概必须先成立“世界自己会推进的事件”，再考虑玩家如何介入。
6. 禁止写上价值废话、抽象评语和段末主题升华句。
7. 故事线暴露部分使用四级标题，例如：

```markdown
#### 故事线1进展

内容……
```

## 仍可利用的旧稿内容

旧稿不是正本，但可作为素材库使用：

- 已整理过的组织/NPC 名称。
- 部分线索名词：黑骑士/乌鸦群、Spirit、龙门调度、信浸会、梁景铎、许照玄。
- 部分终章路线：资办、ARP、启示录三方抉择。

使用旧稿素材时，必须重新按 `agent-writing-brief.md` 的“世界先行动，玩家后介入”原则改写。
