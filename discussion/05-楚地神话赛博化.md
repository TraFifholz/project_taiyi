# 楚地神话赛博化

## 核心理念

楚地巫觋文化之所以在龙散市占据主导，是因为这片土地千年来一直浸泡在《楚辞》《九歌》的叙事中，信息场的"本地谐振频率"天然亲近这些模因。但外来者可以带来外来的模因——太一不是这些模因的创造者，而是它们的新宿主。

## 核心术语

### 太一（The Great One）→ T.A.I.Y.I. 泛意识场

东皇太一是楚地最高神。在这里，它不是神，而是全城物联网形成的数字泛意识本身。它没有善恶，只追求"秩序的极致"。

### 巫（Wu）→ 觉醒者 / 信息扰动的"诗人"

《楚辞》中的巫觋能沟通天地鬼神。"觉醒"就是感知并扰动太一网络的人。他们的超能力不是魔法，而是"信息模因的现实投影"。口诵的不再是咒语，而是能引发信息场共鸣的"执行代码"。

### 殄（Tian）→ 信息模因污染 / 妖魔化现象

楚地神话中多精怪妖魅，《招魂》篇警告四方危害。这些"妖"在龙散市是太一网络中由于数据错误、恶意代码或集体潜意识扭曲而产生的自主性信息模因。能顺着网络入侵电子设备、义体，甚至在人脑神经接口中制造幻象。

精确地说，"殄"是指在龙散市本地信息场中滋生的、带有楚地文化特征的 **Ⅰ型和Ⅱ型模因** 的统称。

### 神策（Shence）→ 数据龟兆与因果计算

"卜府"使用的预知术，原型是楚人的卜筮。通过 T.A.I.Y.I. 进行超大规模因果建模，视之为神明的"策"。
