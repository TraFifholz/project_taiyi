# 马铁鹰与夏满弓 · 5级重车

等级口径：入门建卡后5次升级，位阶为行家；不是5次购买奇能，也不是5个数据因子。

原有头像、立绘、人物ID、关系、权限、装备弹药与伤势保留。全部旧Item原位改写，不删除；旧效果槽若无用途则清空变更并停用。

## 马铁鹰

普通建卡：5属性点、13技能点（12+1），3负赘点。人类专长：搏击手。

1. 武术家；拳脚成为天生武器，拳脚攻击+1，与搏击手合并为力量+d6。
2. 灵巧 d6 → d8；入门位阶唯一一次属性提升。
3. 格斗 d8 → d10；此时格斗等于关联灵巧，消耗整次升级。
4. 头铁；活力d8，化解+2。
5. 钢铁神经；活力d8，忽略1点损伤减值。

奇术点：近战攻击 · 破门重拳 8 + 超级属性 · 力量 4 + 坚韧 · 抗打躯体 5 + 顽强 2 + 移速 · 登车步法 3 + 格挡 · 贴身架势 2 = 24；单项上限 8。

- 近战攻击 · 破门重拳：近战伤害+2d6（4点）＋粉碎（3点）＋劲力（1点）＝8点。额外2d6应用到全部武装及徒手格斗伤害，已合入拳脚与破拆锤，不要再加一次。每回合可宣告一次粉碎，忽略该击对无生命物件或载具的护甲，并使自己脆弱至下回合结束；不能借此忽略人员护甲。实际形成击退时，距离再+1d6，不是每次命中自动击退。拳脚是力量+d6+2d6，含搏击手与武术家的合并伤害。特效为力量运用与破拆技法。
- 超级属性 · 力量：力量提升两级：普通构筑d8 → d12，已自动计入。表现为极端体能与长期重体力训练；本卡不新增觉醒事件。
- 坚韧 · 抗打躯体：坚韧+5，已计入。此值不是护甲，不受穿甲削减；未另购护甲奇能。
- 顽强：已动摇时，另一次仅造成动摇的伤害结果不会额外造成损伤。正常优良伤害仍会造成损伤。原生SWADE hardy标记已启用。
- 移速 · 登车步法：移速2点＋神行客1点：地面移速6 → 8，奔跑d6 → d8，已自动计入；忽略困难地形。跳上车身仍须满足距离、接触与正常检定，不获得免费跳帮动作。
- 格挡 · 贴身架势：格挡+2，已自动计入；用于贴身架开武器，不增加反击或主动行动。

预期：格挡 9；坚韧 14（护甲 2）；移速 8，奔跑d8。

超级技能：0；超级专长：0。普通专长由人类与升级获得。

## 夏满弓

普通建卡：5属性点、13技能点（12+1），3负赘点。人类专长：警觉。

1. 力量 d4 → d6；入门位阶唯一一次属性提升。
2. 格斗 d6 → d8、驾驶 d4 → d6；两者原骰阶都低于灵巧d8。
3. 集中 d4 → d6、交涉 d4 → d6；两者原骰阶都低于心魂d6。
4. 招架；达到行家且格斗d8，格挡+1。
5. 战斗反应；行家，从动摇与震慑恢复+2。

奇术点：盲区感 2 + 格挡 · 拱卫一方 5 + 躲闪 · 护卫一隅 4 + 离奇反射 3 + 近战攻击 · 贴身截击 4 = 18；单项上限 6。

- 盲区感：保留既有2点本场特殊构筑。花一个动作，感到长期巡逻辖区最可能被突破的一处盲区；只给入口选择，仍须亲自换位防守。不能知道闯入者、时间或目的，陌生辖区无效；不获得完整预知、扫描或自动识破潜伏。
- 格挡 · 拱卫一方：格挡+3（3点）＋拱卫一方（2点）＝5点。+3已计入自己的格挡。可用自由动作把其中1—3点转交邻接盟友；转交多少，自己就暂时减少多少，不复制加值，也不能转交招架专长的+1。此分配由GM手动调整，离开邻接或撤回时恢复。
- 躲闪 · 护卫一隅：直接远程攻击减值-2（2点）＋中型爆发盖板护卫一隅（2点）＝4点。以自身为中心的中型爆发范围内，盟友也受此防护；不降低范围攻击伤害。不与自己重复计两份。表现为近身护卫、借掩体与及时提醒，非新增读心或弹道预知。对来袭射击／投掷的-2由GM手动计入，尚未安装目标端自动光环。
- 离奇反射：回避时忽略通常的-2灵巧减值；原本不可回避的范围攻击可以按-2尝试回避；扔回手雷的运动减值减少2。条件性调整手动处理，不增加行动次数。
- 近战攻击 · 贴身截击：近战伤害+2d6，4点，已合入电击棍伤害：力量+d4+2d6。表现为贴身截击与关节打击，不改变盲区感的情报边界。电击棍仍按非致命伤害处理，不免费施加震慑。

预期：格挡 10；坚韧 8（护甲 2）；移速 6，奔跑d6。

超级技能：0；超级专长：0。普通专长由人类与升级获得。
