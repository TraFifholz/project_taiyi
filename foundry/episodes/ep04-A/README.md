## 开场操作

在场景目录打开本场，按现场位置放入实际到场的PC；第三话尾声伤势和载具由实跑结算，本次没有改动玩家资产。逐组取消隐藏，载具不加入独立攻击行动，车内操机员是乘员标记。不要把16枚Token一口气全部加入战斗。

地图为1536×1024原图，在场景中铺为3072×2048；无网格，50像素=1战术英寸，约61×41英寸。场景采用明场展示、手动掩体，没有视野墙；屋顶、围挡和高度由GM裁定。施工围挡缺口与翻越、后巷、屋顶、停车场均可通行。16枚Token使用独立实例，受伤不会串到同模板其他敌人。

重机的预瞄、侧面弱点与停机是本场遭遇规则，写在卡内；这些数值用于先开起来，尚未经过整场平衡实测。梁文川支援卡只服务本场，正式人物卡、关系和隐藏身份均未更改。
